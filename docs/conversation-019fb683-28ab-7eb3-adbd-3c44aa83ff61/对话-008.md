## 141. 助手

一定要共地。

连接方式：

- `HC-05 GND → 主控板 GND`
- `HC-05 TXD → PB16`
- `HC-05 RXD → PB15`
- `HC-05 VCC → 按模块供电要求连接`

不共地时，PB16 无法判断 HC-05 输出的高低电平，典型现象就是已经配对、手机能发送，但 OLED 的 `RX` 始终为 0。
