# H题：车载平衡滚球运动控制系统 — 方案分析

## 题目核心解读

你需要做的是：**一辆循迹小车 + 车上装一个PPR水管做的摆杆，摆杆凹槽里放钢球，车的任务是在循迹行驶的同时保持钢球在摆杆上稳定不滚偏。**

这是**"循迹小车"+"球-杆平衡系统"**两个经典控制问题的融合，难点在于**车运动时对球产生的扰动补偿**。

---

## 一、循迹部分怎么弄

### 1.1 你的硬件已经够了

你已有**8路MCU循迹模块**（红外光电传感器阵列），这正好符合题目要求（"小车循迹模块只能使用红外光电模块"）。

### 1.2 传感器安装

把8路红外传感器安装在**车头底盘下方**，垂直于前进方向一字排开：

```
         车头
    [0][1][2][3][4][5][6][7]   ← 8路红外传感器
    ----+----+----+----+----
                |
             黑线(1.8cm)
```

关键点：
- 传感器阵列中心对齐车的中心轴线
- 安装高度约 **1-2cm**（调试确定最佳距离）
- 传感器间距保证至少有2-3个传感器能同时"看到"黑线

### 1.3 偏差计算（最重要的一步）

不要只判断"左偏/右偏"，要用**加权平均法**算出精确偏差值：

```c
// 8路传感器，每路赋予位置权重
// 传感器编号:  0    1    2    3    4    5    6    7
int weight[] = {-7,  -5,  -3,  -1,   1,   3,   5,   7};
// 返回值: 0=黑线, 1=白底 (根据你传感器实际电平调整)

int line_value[8];  // 读取8路传感器值
int active_count = 0;
int weighted_sum = 0;

for (int i = 0; i < 8; i++) {
    if (line_value[i] == 0) {  // 检测到黑线
        weighted_sum += weight[i];
        active_count++;
    }
}

// deviation 范围约 -7~+7，负=偏左，正=偏右，0=居中
float deviation = (active_count > 0) ? 
    (float)weighted_sum / active_count : last_deviation;
```

### 1.4 PID控制器设计（双环结构）

```c
// === 循迹环（位置式PD，控制转向）===
float tracking_PID(float deviation) {
    static float last_dev = 0;
    float P = KP_TRACK * deviation;
    float D = KD_TRACK * (deviation - last_dev);
    last_dev = deviation;
    return P + D;  // 返回转向修正量
}

// === 速度环（增量式PID，控制车速）===
float speed_PID(float target_speed, float actual_speed) {
    // 用编码器（MG513XP自带编码器）获取实际速度
    static float last_error = 0, integral = 0;
    float error = target_speed - actual_speed;
    integral += error;
    // 积分限幅防止饱和
    if (integral > I_MAX) integral = I_MAX;
    if (integral < -I_MAX) integral = -I_MAX;
    float D = error - last_error;
    last_error = error;
    return KP_SPEED * error + KI_SPEED * integral + KD_SPEED * D;
}

// === 最终输出 ===
void motor_output(float base_speed, float steering) {
    int left_pwm  = base_speed + steering;  // 左轮
    int right_pwm = base_speed - steering;  // 右轮
    // PWM限幅
    left_pwm  = constrain(left_pwm,  -MAX_PWM, MAX_PWM);
    right_pwm = constrain(right_pwm, -MAX_PWM, MAX_PWM);
    // 通过TB6612驱动电机
    motor_left_set(left_pwm);
    motor_right_set(right_pwm);
}
```

### 1.5 赛道分析与速度规划

你的赛道（图1）：
- AB = 1.5m 直线，CD = 1.5m 直线
- BC、DA = 半径0.5m的半圆弧
- 一圈 ≈ 1.5×2 + π×0.5×2 ≈ **6.14m**

要求2：一圈≤20s → 速度 ≥ 0.31m/s → **这是比较慢的速度，轻松实现**

建议分路段用不同参数：
- **直道**：高基础速度，低KP（不用剧烈转向）
- **弯道**：降低速度，提高KP（需要快速响应曲率变化）

用编码器做里程计，在A/B/C/D四个点做路段切换。

### 1.6 精准停车

题目要求停在A点，停车误差≤2cm。A点有一根5cm长的垂直黑线做启停标记。方案：
- 当8路传感器**同时检测到黑线**（横线），判定到达A点停车位置
- 立即刹车，利用电机短路制动快速减速
- 如果超调，可以加一点**低速反靠**微调
