## 3. 舵机控制

### 3.1 机械结构
- 采用**两个舵机分别控制平板X轴和Y轴方向的倾斜角度**。
- 舵机通过舵机臂→轴承→双头螺杆→金属球头→平板的连接方式传递力矩。
- 上电时舵机会有初始化抖动，需做好硬件限位保护措施。

### 3.2 控制方式
- 使用STM32的**高级定时器（TIM1/TIM8）输出PWM信号**（典型范围1000–2000μs对应0–180°）驱动舵机。
- 需处理舵机**死区补偿、响应延迟建模、机械限位保护**（软件硬限幅）、多舵机同步刷新等底层细节。

## 4. PID控制算法

### 4.1 控制架构
采用**双通道解耦PID**：X轴与Y轴各配置独立PID控制器，输出分别对应两个舵机的目标角度。

### 4.2 参数整定方法
1. **先固定一个方向**（如X轴），Ki、Kd设为0，调节Kp使小球在中间位置震荡。
2. **加入Kd**抑制震荡，使小球快速稳定。
3. **最后微调Ki**消除稳态误差（可加可不加，注意防积分饱和）。
4. 一个方向调好后，再调另一个方向。

### 4.3 优化策略
- **分段PID**：误差大时加大P增益，接近目标时启用I微调。
- **抗微分冲击**处理、设定值前馈补偿。
- PID计算周期建议**10–50ms定时中断**触发。

## 电赛循迹小车：STM32 + 红外光电传感器 + PID控制 算法实现总结

基于搜索到的资料，以下是电赛循迹小车在 STM32 平台下结合红外光电传感器和 PID 控制算法的完整实现方案。

---

### 一、硬件架构

#### 1. 主控芯片
- **推荐型号**：STM32F103C8T6（ARM Cortex-M3，主频72MHz，64KB Flash，20KB SRAM）或 STM32F103ZET6（更多I/O口）
- **选型理由**：拥有多个定时器可实现多路 PWM 输出，内置 ADC 模块可采集传感器信号，支持外部中断快速响应轨迹变化

#### 2. 传感器模块
- **红外循迹传感器**：TCRT5000 反射式红外对管阵列（或 QRE1113GR 阵列）
  - 工作原理：红外发射管发射红外线，经地面反射后由光电接收管接收。白色区域反射强→输出高电平，黑色区域反射弱→输出低电平
  - **关键设计要求**：传感器阵列间距必须 ≤ 赛道宽度的一半，以确保精准识别黑线位置
  - 常见配置：多路灰度循迹模块（如12路灰度寻迹模块），可精确判断小车相对黑线中心的偏差值

- **姿态传感器（可选）**：MPU6050 六轴陀螺仪+加速度计，用于坡道识别与倾角检测

- **电机驱动**：L298N 或 TB6612FNG H桥驱动模块，通过 PWM 控制电机转速与方向

#### 3. 编码器测速
- LM393 比较器测速模块或霍尔编码器，用于检测电机实际转速，实现速度闭环控制
- STM32 通过正交解码获取编码器位置信息，CNT 寄存器正转累加、反转递减

---

### 二、PID 控制算法

#### 1. 双环 PID 控制架构
循迹小车的核心控制策略是**双闭环 PID**：
- **外层（循迹环/位置环）**：以红外传感器检测的位置偏差 `e(t)` 作为输入，PID 输出作为速度调节量
- **内层（速度环）**：以编码器实测转速作为反馈，PID 输出 PWM 占空比，实现电机速度闭环

#### 2. PID 算法公式

**位置式 PID**（适用于循迹偏差控制）：
$$\\text{adjust} = \\text{val} \\cdot K_P + (\\text{error} - \\text{error\\_last}) \\cdot K_D + (\\text{error} + \\text{error\\_last}) \\cdot K_I$$

其中 `val` 为传感器检测到的偏差值。

**增量式 PID**（适用于电机速度控制）：
$$\\Delta u_k = A e_k - B e_{k-1} + C e_{k-2}$$

其中：
$$A = K_P\\left(1 + \\frac{T}{T_i} + \\frac{T_d}{T}\\right), \\quad B = K_P\\left(1 + \\frac{2T_d}{T} + \\frac{T_d}{T}\\right), \\quad C = K_P\\frac{T_d}{T}$$

当前位置输出：
$$u_k = u_{k-1} + \\Delta u_k$$

#### 3. PID 参数整定方法
- 推荐使用 **Ziegler-Nichols 法** 进行参数整定
- 先确定合适的采样周期，逐个调节 P→I→D 参数
- 对于速度超调问题：可对每次增量进行**限幅处理**，当速度差很大时限制单位时间内增量，保证平稳加减速
- 推荐使用上位机实时显示速度曲线，方便观察数据与调参

#### 4. 坡道速度补偿
通过 MPU6050 读取倾角，当检测到倾角超过阈值时：
- **上坡**：提高 PWM 占空比克服重力阻力
- **下坡**：降低 PWM 占空比避免超速
- 引入比例调节系数 k，根据坡度角度动态调整电机输出功率
