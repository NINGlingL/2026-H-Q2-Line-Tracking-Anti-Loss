## ⚡ 焊接前注意事项

1. **静电防护**: 焊接前触摸接地物体释放静电
2. **温度**: SMD用 300-320°C，插件大焊盘(DC1)用 350-380°C
3. **锡丝**: 推荐 0.5-0.8mm 有铅或无铅锡丝
4. **助焊剂**: 贴片IC建议使用助焊膏
5. **检查**: 每焊完一类元件，用万用表二极管档短接相邻焊盘检查是否连锡
6. **通电前**: 先检查电源到GND是否短路！用万用表量+12V/+5V/+3.3V 对 GND 的电阻

开始焊接吧！祝一切顺利 🎯

## 🔍 板子工作原理

根据网表分析，这块板子的电路结构如下：

---

### 1. 电源系统

```
DC电源座 (DC1) 或 接线端子 (CN1)
         │
         ▼  +12V
    ┌─────────────┐
    │ U7 (SS54)   │  ← 防反接二极管 (12V进来先经过它)
    │   肖特基     │     如果电源接反，U7截止，保护后面电路
    └──────┬──────┘
           │
    ┌──────┴──────┐
    │ U4 电源开关  │  ← 滑动开关，手动控制总电源通断
    │  YSSP2AG00  │
    └──────┬──────┘
           │
    ┌──────┴──────────────────────────────────┐
    │  U2 TPS5450QDDARQ1  5V 降压转换器        │
    │                                          │
    │  C1,C2(4.7μF) + C3(100nF) → 输入滤波     │
    │  C4(10nF) → 自举电容                     │
    │  L1(10μH) + U3(SS54) → 储能+续流          │
    │  R3(10K)/R4(3.16K) → 反馈分压决定输出5V    │
    │  C5,C6(100μF) + C7(100nF) → 输出滤波      │
    └──────┬──────────────────────────────────┘
           │  DC+5V
    ┌──────┴──────┐
    │ F1 保险丝    │  ← 500mA 自恢复，5V过流保护
    │ nSMD050-30  │
    └──────┬──────┘
           │  VCC+5V
    ┌──────┴─────────────────────────┐
    │  U6 AMS1117-3.3  LDO稳压器      │
    │  C8(10μF)+C9(100nF) → 输入      │
    │  C10(10μF)+C11(100nF) → 输出    │
    └──────┬─────────────────────────┘
           │  VCC+3.3V
    
    VCCA+3.3V ← R7(0Ω) ← VCC+3.3V  (模拟供电)
    AGND ← R8(0Ω) ← GND            (模拟地)
```

**输出端子：**
- H5 (2×3P)：3.3V 电源输出
- H6 (2×3P)：5V 电源输出
- H7 (2×3P)：12V 电源输出
- CN2, CN3：12V 接线端子输出

### 4. 蜂鸣器驱动电路

```
B08 → R13(560Ω) → Q1(SS8050)基极
                    ├─ E → GND
                    └─ C → BUZZER1(-)
                             BUZZER1(+) → 3.3V
                    D2(1N5819) 反向并联在蜂鸣器两端 (续流保护)
              R14(10kΩ) B-E 下拉 (防止浮空)
```

## ✅ 焊后检验步骤

### 阶段0：目视检查（通电前必须做！）

| 检查项 | 方法 |
|------|------|
| 所有焊点是否饱满光亮 | 肉眼 + 放大镜 |
| 有无连锡(短路) | 重点检查 IC 引脚、排针相邻脚 |
| 二极管/电容极性 | SS54阴极白线、铝电解负极灰条 |
| 芯片方向 | U2(SOIC-8) pin1 小圆点、U6(SOT-223)方向 |
| 三极管方向 | Q1 SOT-23 单脚端=基极 |
| 有无漏焊 | 对照 PCB 丝印逐个核对 |
