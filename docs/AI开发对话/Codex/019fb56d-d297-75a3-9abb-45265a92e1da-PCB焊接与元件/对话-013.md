# PCB焊接与元件（续）

## 助手


---

### 阶段1：短路检查（万用表 — 最关键！）

**用万用表电阻档/蜂鸣档，量以下各电源轨对 GND 的电阻：**

| 测试点 | 正常值 (近似) | 异常 |
|------|------------|------|
| +12V ↔ GND | > 几十 kΩ | 短路=0Ω → **绝不能通电！** |
| VCC+5V ↔ GND | > 几 kΩ | 短路 → 检查C5/C6/C7/C8/C9极性 |
| VCC+3.3V ↔ GND | > 几 kΩ | 短路 → 检查C10/C11/U6 |

> 具体方法：红表笔接地，黑表笔接各电源轨。蜂鸣器响 = 短路，必须排除！

---

### 阶段2：分步上电

#### 2.1 空载通电 (不插天猛星开发板)

1. **用可调电源设为 12V/限流200mA**，接到 DC1 或 CN1
2. 打开 U4 开关
3. 观察有无冒烟、异常发热

#### 2.2 测量各电源轨电压

| 测量点 | 期望电压 | 允许范围 |
|------|---------|---------|
| +12V (H7 pin1/3/5) | 输入电压 | 略低于输入 |
| VCC+5V (H6 pin1/3/5) | **5.0V** | 4.75V ~ 5.25V |
| VCC+3.3V (H5 pin1/3/5) | **3.3V** | 3.2V ~ 3.4V |
| VCCA+3.3V | **3.3V** | ≈ VCC+3.3V |

#### 2.3 检查指示灯

| LED | 说明 |
|-----|------|
| LED1 (绿) | 3.3V 上电即亮 |
| LED2 (绿) | 5V 上电即亮 |

> 如果 LED 不亮：检查 LED 方向是否焊反、R5/R6 限流电阻是否焊好。

---

### 阶段3：关键电路逐项验证

#### 3.1 U7 防反接

- 量 U7 阴极(有条纹端)对 GND = 应有 12V
- 量 U7 阳极(无条纹端) = 输入电压

#### 3.2 U2 降压 (TPS5450)

| 引脚 | 功能 | 期望值 |
|------|------|--------|
| Pin7 (VIN) | 输入 | ≈ 12V |
| Pin8 (PH) | 开关节点 | 可用示波器看到 500kHz PWM波形 |
| Pin4 (VSENSE) | 反馈 | ≈ 1.221V (内部基准) |
| Pin6 (GND) | 地 | 0V |

> 输出电压公式：Vout = 1.221 × (1 + R3/R4) ≈ 1.221 × (1 + 10k/3.16k) ≈ 5.08V ✓

#### 3.3 U6 LDO (AMS1117-3.3)

| 引脚 | 功能 | 期望值 |
|------|------|--------|
| Pin3 (VIN) | 输入 | ≈ 5V |
| Pin2/4 (VOUT) | 输出 | **3.3V** |
| Pin1 (GND) | 地 | 0V |

#### 3.4 蜂鸣器电路

用杜邦线将 B08 接 3.3V，蜂鸣器应发声。没有声音则检查：
- Q1 方向是否正确
- R13 560Ω 是否焊好
- BUZZER1 极性

#### 3.5 电池检测分压

- R1(33K) 上端接 +12V，中间接 ADC_battery(B25)
- 分压比：Vadc = +12V × R2/(R1+R2) = 12 × 10k/43k ≈ **2.79V** (安全在3.3V以内)

#### 3.6 按键

- 未按下：KEY1~4 ↔ GND 应为高阻/上拉
- 按下：KEY1~4 ↔ GND = **0Ω (短路)**

#### 3.7 电位器

- R9 两端 = 3.3V ↔ GND
- 中间脚(CODER)电压旋转时应在 0~3.3V 之间变化

---

### 阶段4：插入天猛星开发板

插入前确认：

- [ ] 所有电压正常
- [ ] 无短路
- [ ] **断电** 再插板

插入后：
1. 开发板应正常启动
2. OLED (U8) 可通过 I2C 扫描到地址 (0x3C)
3. 各 GPIO 可通过简单程序逐一测试

---

### 🔧 常见故障排除

| 现象 | 可能原因 | 检查 |
|------|---------|------|
| 5V 输出为0 | U4 开关未开 / U2 虚焊 | 量U2 VIN是否有12V |
| 5V 输出过高 | R3/R4 焊错阻值 | 核对10K和3.16K |
| 3.3V 为0 | U6 虚焊或短路 | 量U6 VIN=5V? |
| 某LED不亮 | LED方向反或虚焊 | 量LED两端电压 |
| 蜂鸣器不响 | Q1方向错 | 检查SOT-23方向 |
| 电源对地短路 | 电容极性反 | 逐个检查电解电容 |
| F1 发烫 | 后级短路 | 5V轨对地电阻 |

---

**总结检验流程：先看→再量电阻→上电量电压→逐模块验证→最后插入MCU。** 每步确认无误再进入下一步，可以避免烧毁芯片！
