### 5.5 替换 font.c 中的字模数据

打开 `D:\A嵌入式\32project\01_ide\Core\Src\font.c`

1. 翻到文件最后（大约第 415 行），找到这一行：

```c
const uint8_t zh16x16[][36] = {
```

2. 把从这一行 `{` 到匹配的 `};` 之间的 **4 行旧数据**（"波特律动"）删掉

3. 粘贴刚才从取模工具复制的 **19 行新数据**

修改后看起来像这样：

```c
const uint8_t zh16x16[][36] = {
/* 0 静 */ {0xe9,0x9d,0x99,0x00, ... 共36字节 ... },
/* 1 夜 */ {0xe5,0xa4,0x9c,0x00, ... 共36字节 ... },
/* 2 思 */ {0xe6,0x80,0x9d,0x00, ... 共36字节 ... },
/* 3 床 */ { ... },
/* 4 前 */ { ... },
/* 5 明 */ { ... },
/* 6 月 */ { ... },
/* 7 光 */ { ... },
/* 8 疑 */ { ... },
/* 9 是 */ { ... },
/* 10 地 */ { ... },
/* 11 上 */ { ... },
/* 12 霜 */ { ... },
/* 13 举 */ { ... },
/* 14 头 */ { ... },
/* 15 望 */ { ... },
/* 16 低 */ { ... },
/* 17 故 */ { ... },
/* 18 乡 */ { ... },
};
```

4. 修改下一行的字符数量 `len`：

```c
// 修改前：
const Font font16x16 = {16, 16, (const uint8_t *)zh16x16, 4, &afont16x8};

// 修改后：把 4 改成 19
const Font font16x16 = {16, 16, (const uint8_t *)zh16x16, 19, &afont16x8};
```

**保存** font.c（Ctrl+S）。

### 5.6 切换 main.c 到中文模式

打开 `main.c`，修改第 38 行：

```c
#define TEST_WITH_ASCII   1    // 改之前

#define TEST_WITH_ASCII   0    // 改之后 ← 切换到中文模式!
```

**保存** main.c（Ctrl+S）。

## 第 6 步：编译烧录 + 看效果

1. 点击 **🔨 Build** 编译
2. 如果编译报错，检查：
   - font.c 中数组大括号是否配对（`{` 和 `},`）
   - 最后一行数据末尾是 `},` 不是 `},` 后面还有内容
   - `len` 字段改成了 `19`
3. 编译通过后，点击 **▶️ Run** 烧录

## 🔧 常见问题排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 屏幕完全不亮 | 接线错误 / 没供电 | 检查 VCC=3.3V, GND=GND |
| 屏幕亮但无内容 | I2C 地址不对 | 换 `0x7A` 试试 |
| 屏幕亮但全是乱点 | SCL/SDA 接反 | 交换 PB6/PB7 试试 |
| 编译报错 `ssd1306.h not found` | 文件没加入工程 | CubeIDE 中 Refresh + 右键 Add |
| 中文显示乱码 | 字模顺序和 UTF-8 不匹配 | 确认取模工具中输入字符的顺序和 font.c 一致 |
| 中文显示空白 | `len` 没改 | 检查 `font16x16` 的 `len = 19` |
