## 🔄 v2 修正内容（基于你的原理图）

看了天猛星原理图后发现的关键修正：

| 修正项 | v1 (错误) | v2 (正确) |
|--------|-----------|-----------|
| **UART0** | 分配给相机 | ❌ **PA10/PA11 被板载 CH340 占用**，不可用 |
| **I2C0** | PA12/PA13 | ✅ **PA0(SDA) + PA1(SCL)** — MSPM0 的默认映射 |
| **I2C1** | PB6/PB7 | ✅ **PB2(SCL) + PB3(SDA)** — MSPM0 默认 |
| **相机** | UART0 | ✅ 改到 **UART1 (PA8/PA9)** |
| **循迹** | UART2 | ✅ 改到 **UART3 (PB12/PB13)** |
| **TB6612 PWM** | PA0/PA1 | ✅ 改到 **PB0(左轮) + PB1(右轮)** |

## 📋 最终分配速查

```
UART1 (PA8/PA9)    → 相机
UART2 (PB15/PB16)  → HC-05 蓝牙
UART3 (PB12/PB13)  → 八路循迹模块
UART0 (PA10/PA11)  → (板载CH340, 不接外设)

I2C0 (PA0/PA1)     → SSD1306 OLED
I2C1 (PB2/PB3)     → ICM-20948 陀螺仪

PB0(PWM) + PA12/PA13(DIR) → TB6612 左电机
PB1(PWM) + PB8/PB9(DIR)   → TB6612 右电机

PB10(STEP) + PB11(DIR) + PA14(EN) → TMC2208 步进电机

PB22/PB23 → 硬件编码器(左轮)
PA16      → 软件编码器(右轮, EXTI中断)
```

PDF 里每个引脚都标注了在 Arduino 排针上的位置，方便你插杜邦线。你看看有没有问题？
