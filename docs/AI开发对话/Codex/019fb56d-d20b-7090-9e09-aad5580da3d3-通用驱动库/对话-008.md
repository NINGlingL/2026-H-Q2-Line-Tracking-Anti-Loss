## 完整操作指南

### ⚠️ 前提：I2C1 初始化

你的 `main.c` 中还没调用 `MX_I2C1_Init()`。需要在 CubeMX 中确认 I2C1 已启用（PB6=SCL, PB7=SDA），然后**重新生成代码**。

---

### 步骤 1：复制驱动文件到工程

把以下 5 个文件复制到你的工程，然后在 CubeIDE 中右键文件夹 → Add existing files：

| 文件 | 复制到 |
|------|--------|
| `通用驱动库\ssd1306.h` | `01_ide\Core\Inc\` |
| `通用驱动库\ssd1306.c` | `01_ide\Core\Src\` |
| `通用驱动库\font.h` | `01_ide\Core\Inc\` |
| `通用驱动库\font.c` | `01_ide\Core\Src\` |
| `通用驱动库\hal_detect.h` | `01_ide\Core\Inc\` |

---

### 步骤 2：生成诗句的中文字模

内置字库只有 "波特律动" 4 个字，你需要自己生成：

1. 打开 **https://led.baud-dance.com** → 选择 16×16 中文取模
2. 输入诗句中所有不重复的汉字，例如 **静夜思** 的字符集：

```
静夜思床前明月光疑是地上霜举头望低故乡
```

3. 点生成 → 把输出的 `{0x..., 0x..., ...}` 数据替换到 `font.c` 的 `zh16x16` 数组中
4. 修改 `font.c` 中 `font16x16` 的 `len` 字段为实际字符数量（上面是 18 个）
