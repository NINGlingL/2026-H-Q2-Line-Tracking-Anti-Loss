## 第 2 步：新建 MSPM0 工程

菜单栏点 **File** → **New** → **MSPM0 Project**

在弹出的窗口里这样填：

| 字段 | 填什么 |
|------|--------|
| Project name | `MSPM0G3507_Demo` |
| Device | 下拉选 **MSPM0G3507** |
| Package | 看你的芯片封装，常见的是 **LQFP-64(PM)** |
| SDK | 选 `mspm0_sdk_2_11_00_07` |
| Toolchain | **TICLANG** |
| Project template | **Empty with SysConfig** |

Location 就用默认（workspace 下），点 **Finish**。
