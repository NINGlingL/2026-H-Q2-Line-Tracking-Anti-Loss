## 第 1 步：复制驱动文件到工程


### 1.2 复制源文件（.c）

从 `D:\A嵌入式\资料库\通用驱动库\` 中，选中这 2 个文件：
```

```

### 1.3 在 CubeIDE 中添加到工程

1. 打开 CubeIDE，打开你的工程 `01_ide`

4. 现在你应该能看到刚才复制的 5 个新文件出现在工程树中

## 第 2 步：CubeMX 生成 I2C1 初始化代码

虽然你说已经开启了 I2C1，但你的 main.c 里还没有 `MX_I2C1_Init()` 调用。按照下面做：

### 2.1 检查 I2C1 配置

1. 在 CubeIDE 中双击 `01_ide.ioc` 文件（打开 CubeMX 界面）
2. 左侧选择 **Pinout & Configuration** 标签
3. 在 **Connectivity** 下拉中找到 **I2C1**
4. 确认 I2C1 模式是 **I2C**（不是 Disabled）
5. 确认引脚：**PB6 = SCL**, **PB7 = SDA**

如果没有启用，点击 I2C1 下拉选择 **I2C**，CubeMX 会自动分配引脚。

### 2.2 重新生成代码

1. 点击顶部工具栏的 **齿轮图标**（Generate Code / 生成代码）
2. 或者菜单栏：**Project → Generate Code**
3. 弹出提示选择 **Yes** 覆盖

生成完成后，你的 main.c 中会自动出现 `MX_I2C1_Init();`。
