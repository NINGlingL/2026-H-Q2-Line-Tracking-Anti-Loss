# 2023年全国大学生电子设计竞赛 E题：运动目标控制与自动追踪系统

## 题目性质

E题为**本科组**控制类赛题，题名为"运动目标控制与自动追踪系统"，是TI杯2023年全国大学生电子设计竞赛的正式赛题。

## 任务要求

设计制作一个运动目标控制与自动追踪系统，包含两个独立子系统：

- **红色光斑位置控制系统**：模拟运动目标，红色激光笔固定在二维电控云台上，光斑落在正前方1m处的白色屏幕上（光斑直径≤1cm），能在屏幕范围内任意移动。屏幕有效面积大于0.6×0.6m²，中心画有边长0.5m的正方形标识。
- **绿色光斑位置控制系统**：用于自动追踪红色光斑，绿色激光笔放置在屏幕平行线段上，距红色激光笔0.4m~1m。**两个系统必须完全独立，之间不得有任何方式通信。**

## 基本要求（满分50分）

1. **复位功能**：红色光斑能从屏幕任意位置回到原点，误差≤2cm。
2. **边线移动**：红色光斑在30秒内沿屏幕四周边线顺时针移动一周，距边线距离≤2cm。
3. **A4靶纸追踪（正放）**：在屏幕任意位置贴A4靶纸（黑胶带贴边），红色光斑在30秒内沿胶带顺时针移动一周。
4. **A4靶纸追踪（旋转）**：A4靶纸以任意旋转角度贴在任意位置，要求同（3）。

## 发挥部分（满分50分）

1. **一键自动追踪**：复位后一键启动，绿色光斑2秒内追踪红色光斑，两光斑中心距离≤3cm，追踪成功发出连续声光提示。
2. **动态追踪**：红色光斑重复基本要求(3)~(4)动作，绿色光斑同步自动追踪。启动2秒后应追踪成功，追踪过程中两光斑中心距离>3cm记为追踪失败。两系统均需设置暂停键，按下后立即制动。
3. 其他自主发挥。

## 关键限制

- 两系统完全独立，不得通信
- 屏幕无任何电子元件
- 控制系统不能采用台式计算机或笔记本电脑
- 光斑直径≤1cm

## H题：自动行驶小车

**题目类别**：控制类

**设计任务**：
设计一个采用 **TI MSPM0 系列 MCU** 控制的自动行驶小车，能在指定路径上自动行驶。

**设计要求（共4项任务）**：

| 任务 | 要求 | 时间限制 |
|------|------|----------|
| 任务1 | 小车从A点自动行驶到B点停车，停车时有声光提示 | ≤15秒 |
| 任务2 | 从A点到B点→沿半弧线到C点→到D点→沿半弧线回到A点停车，每经过一个点声光提示一次 | ≤30秒 |
| 任务3 | 从A点到C点→沿半弧线到B点→到D点→沿半弧线回到A点停车，每经过一个点声光提示一次 | ≤40秒 |
| 任务4 | 按任务3的路径自动行驶4圈后停车 | 用时越少越好 |

**核心技术要点**：
- 主控芯片：TI MSPM0G3507 微控制器
- 循迹方案：红外寻迹模块 / 灰度传感器识别路径
