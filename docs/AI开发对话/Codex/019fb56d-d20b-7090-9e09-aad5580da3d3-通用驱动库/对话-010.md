### 第二步：CubeMX 生成 I2C1 初始化代码

1. 打开 `.ioc` 文件
2. 确认 **I2C1** 已启用（PB6=SCL, PB7=SDA）

4. 取消 main.c 中 `/* MX_I2C1_Init(); */` 和 `/* #include "i2c.h" */` 的注释

### 第三步：生成中文字模（关键步骤）

1. 打开 **https://led.baud-dance.com**
2. 选择 **16×16** 中文取模
3. 输入诗句所有不重复汉字（静夜思共 19 个）：

```
静夜思床前明月光疑是地上霜举头望低故乡
```

4. 生成 → 复制 `{0x..., 0x..., ...}` 数据
5. 替换 `font.c` 中 `zh16x16` 数组内容
6. 修改 `font.c` 第 421 行的 `len` 字段：`const Font font16x16 = {16, 16, ..., 19, &afont16x8};`
7. 把 `main.c` 的 `#define TEST_WITH_ASCII 1` 改为 `0`
