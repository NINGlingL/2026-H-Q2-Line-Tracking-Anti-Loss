## 一、需要哪些文件

每次在新工程中使用 OLED，只需要 **5 个文件**：

| 文件 | 放到 | 作用 |
|------|------|------|
| `ssd1306.h` | `Core/Inc/` | OLED 驱动头文件 |
| `ssd1306.c` | `Core/Src/` | OLED 驱动实现 |
| `font.h` | `Core/Inc/` | 字体库头文件 |
| `font.c` | `Core/Src/` | 字模数据 |
| `hal_detect.h` | `Core/Inc/` | 自动识别 STM32 型号 |

> ⚠️ **不需要** `i2cdev.h/c`——SSD1306 驱动直接调用 `HAL_I2C_Master_Transmit()`，不依赖 i2cdev。

---

## 二、main.c 中必须写什么（最小模板）

```c
/* ===== 1. 包含头文件 ===== */
#include "ssd1306.h"
#include "font.h"

/* ===== 2. 在 main() 中初始化 ===== */
int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_I2C1_Init();               // CubeMX 生成

    OLED_Init(&hi2c1, 0x78);       // 初始化 OLED (I2C1, 地址 0x78)
    HAL_Delay(50);                 // 等待 OLED 稳定

    /* ===== 3. 绘图循环 ===== */
    while (1) {
        OLED_NewFrame();           // ① 清空显存，开始画新一帧

        // ... 在这里画你想画的内容 ...

        OLED_ShowFrame();          // ② 把显存推送到屏幕
        HAL_Delay(16);             // ③ ~60fps (16ms)
    }
}
```

**核心模型只有 3 步**：

```
OLED_NewFrame()  →  画内容  →  OLED_ShowFrame()
   (清空白板)       (在内存里画)    (一次性刷到屏幕)
```

## 三、完整 API 速查表

### 3.1 初始化与控制

| 函数 | 说明 |
|------|------|
| `OLED_Init(&hi2c1, 0x78)` | 初始化，绑定 I2C1，地址 0x78 |
| `OLED_DisPlay_On()` | 唤醒屏幕 |
| `OLED_DisPlay_Off()` | 关闭屏幕（低功耗） |
| `OLED_SetColorMode(mode)` | `OLED_COLOR_NORMAL`（黑底白字）或 `OLED_COLOR_REVERSED`（反色） |

### 3.2 帧操作

| 函数 | 说明 |
|------|------|
| `OLED_NewFrame()` | 清空显存（1024 字节归零） |
| `OLED_ShowFrame()` | 整帧推送到屏幕（8 页 × 128 列） |

### 3.3 像素

| 函数 | 说明 |
|------|------|
| `OLED_SetPixel(x, y, color)` | 画一个点，x: 0~127，y: 0~63 |
