## 🔹 第 3 步：确认 I2C1 初始化（你来做，2 分钟）

1. 在 CubeIDE 中双击 **`01_ide.ioc`**，打开 CubeMX
2. 点击左侧 **Pinout & Configuration** → **Connectivity** → **I2C1**
3. 确认模式是 **I2C**（不是 Disabled）
4. 确认引脚：**PB6 = SCL**，**PB7 = SDA**
5. 点击 **Project → Generate Code**（或按 `Alt+K`）
6. 这会自动在 main.c 中生成 `MX_I2C1_Init()` 和 `#include "i2c.h"`
