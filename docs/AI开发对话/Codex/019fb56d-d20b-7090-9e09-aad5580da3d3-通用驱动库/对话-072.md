```
【已占用·不可用】

  LED:   PB22      → 板载LED
  KEY:   PB21      → 板载按键
  BSL:   PA18      → BSL按钮

【UART·3路可用】
  UART1: PA8/PA9      → 相机 (921600)
  UART2: PB15/PB16    → HC-05蓝牙 (115200)
  UART3: PB12/PB13    → 8路循迹 (115200)

【I2C·2路】
  I2C0: PA0(SDA) + PA1(SCL)  → SSD1306 OLED
  I2C1: PB2(SCL) + PB3(SDA)  → ICM-20948

【TB6612 直流电机】
  左轮: PB0(PWM) + PA12(IN1) + PA13(IN2)
  右轮: PB1(PWM) + PA14(IN1) + PA15(IN2)

【TMC2208 步进电机(摆杆)】
  STEP: PB10  DIR: PB11  EN: PB14

【编码器】
  硬件(左轮): PB8(A相) + PB9(B相) → TIMG6
  软件(右轮): PA16 → EXTI中断计数
```
