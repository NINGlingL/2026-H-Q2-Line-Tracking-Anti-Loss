## 代码做的事（4 行核心调用）

```c
OLED_NewFrame();                                          // ① 清屏
OLED_DrawRectangle(0, 0, 127, 63, OLED_COLOR_NORMAL);    // ② 画外框
OLED_DrawImage(50, 18, &bilibiliImg, OLED_COLOR_NORMAL); // ③ 画图 (居中)
OLED_ShowFrame();                                         // ④ 刷新到屏幕
```
