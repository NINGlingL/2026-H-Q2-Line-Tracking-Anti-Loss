## 怎么看偏差 & 怎么调

烧录后看屏幕，判断方向和大小：

| 你看到的现象 | 改这个值 |
|-------------|---------|
| 图标偏右，左边空白多 | `DISP_OFFSET_X` → `-2` |
| 图标偏左，右边空白多 | `DISP_OFFSET_X` → `+2` |
| 图标偏下，上方空白多 | `DISP_OFFSET_Y` → `-2` |
| 图标偏上，下方空白多 | `DISP_OFFSET_Y` → `+2` |
