### 三、H题 — 自动行驶小车

#### 题目要求
- **要求指定使用TI板子**（比赛期间TI板子已出现有价无市的紧缺局面）
- 制作并不复杂，但要求参赛者设计**高效控制算法**
- 在**算力较低、无摄像头**要求下，实现**快速非循迹自动行驶**
- 小车在指定路径上循迹行驶（非传统循迹线跟踪）

#### 典型硬件配置方案
| 模块 | 配置 |
|------|------|
| **主控** | TI指定板子（必备） |
| **传感器** | 红外传感器 + 三维角度陀螺仪（武汉轻工大学一等奖方案） |
| **控制算法** | PID算法（红外传感器+陀螺仪联合调制） |
| **优化方案** | 用红外传感器替代灰度传感器，提升稳定性 |
| **高级方案** | 自适应算法（武汉大学实现18秒无差错跑完4圈） |
