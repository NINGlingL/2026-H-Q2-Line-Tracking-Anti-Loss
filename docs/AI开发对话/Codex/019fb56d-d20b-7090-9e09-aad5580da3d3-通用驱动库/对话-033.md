## 🔄 程序工作流程

```
启动
 ├─ OLED_Init(&hi2c1)       → 初始化屏幕
 ├─ MPU6050_Init(&hi2c2)    → 复位IMU → 校准零偏 → 配置200Hz
 ├─ 显示启动画面 (1.5s)
 │
 └─ 主循环:
      │
      ├─ PA10 中断触发? ──→ mpu_data_ready = 1
      │                         ↓
      ├─ mpu_data_ready == 1? ──→ MPU6050_GetAttitude()
      │    (含 Mahony 互补滤波姿态解算)
      │
      └─ OLED 刷新 (30fps)
          显示 accel/gyro/roll/pitch/yaw/temp
```

两种读取模式自动切换：
- **INT 正常工作** → 每秒读 200 次（中断驱动）
- **INT 未触发超过 50ms** → 自动降级为定时轮询
