## 🔧 v3 修正的两处

### 1. 软件编码器 → 两个引脚

你说得对，即使是软件方式，正交编码器必须 **A+B 两相**才能判断方向：

```
右轮软件编码器:
  PA16 → A相 (EXTI 双沿中断)
  PA17 → B相 (EXTI 双沿中断)
```

A 相比 B 相超前 90° = 正转，滞后 90° = 反转，在两个中断里判断相位差即可。

### 2. 使能引脚

| 信号 | 引脚 | 电平 | 说明 |
|------|------|------|------|
| **TB6612 STBY** | **PB14** | H=工作, L=待机 | 左排针 Pin36, 正常跑车时拉高 |
| **TMC2208 EN** | **PB17** | **L=使能**, H=禁用 | 右排针 Pin34, 步进电机低电平使能 |

> 注意：TB6612 和 TMC2208 的使能电平逻辑**相反**。TB6612 是 STBY=H 才工作，TMC2208 是 EN=L 才使能。
