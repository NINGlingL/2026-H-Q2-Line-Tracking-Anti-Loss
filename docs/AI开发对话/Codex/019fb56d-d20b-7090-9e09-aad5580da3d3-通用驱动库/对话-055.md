# 2023年全国大学生电子设计竞赛G题：空地协同智能消防系统 题目要求

## 一、题目概述

G题"空地协同智能消防系统"属于本科组**控制类**赛题，要求构建一个由**四旋翼无人机**与**地面消防车**组成的闭环协同作业平台，模拟真实应急场景下的智能巡检与初级火情响应。

## 三、关键技术要求

### 1. 场地与飞行
- 场地尺寸：**40dm×48dm**（4m×4.8m）结构化室内/半室外场地
- 无人机飞行高度：约**18dm**（1.8m）
- 需实现数学意义上严格的全覆盖路径规划巡航（常用Boustrophedon分解、双向扫描优化、A*改进型CPP等算法）
- 需兼顾无人机最小转弯半径、最大加速度、悬停稳定性等物理约束

### 2. 模拟火源
- 采用**电池供电的红色光源**作为模拟火源
- 火源亮灭由**激光笔持续照射**控制——持续照射约**2秒**开启，再次持续照射熄灭
- 需要光敏电阻检测，且需现场标定阈值（环境光干扰是主要难点）

### 3. 空地协同逻辑
- 无人机发现火源后执行：**定位→标记→上报→悬停确认**四步动作
- 消防车接收坐标后自主导航至火源点（差速轮式底盘PID路径跟踪+红外循迹辅助）
- **重要规则**：火源只允许在消防车照射时才熄灭；无人机照射火源仅用于识别标记和投放灭火包
- 激光指示带宽：**8dm覆盖宽度**

### 4. 通信要求
- 无人机端需将位置坐标（x, y, z, θ）以**每秒1帧**速率上传至消防车
- 需完成坐标系转换（无人机机体坐标→全局场地坐标）、时间戳同步、丢包补偿
- 常用方案：LoRa+FSK双模冗余、2.4G私有协议或ESP-NOW等低延迟高可靠无线链路

### 5. 无人机端硬件
- 飞控主控（如STM32H7/ESP32-S3）
- 激光发射模块（650nm Class II）
- 火焰传感器/热释电传感器（补充检测冗余）
- 高能量密度锂聚合物电池

### 6. 消防车端硬件
- 嵌入式Linux或RTOS系统
- TFT液晶触控屏（实时显示无人机轨迹及航程积分）
- 无线接收模块、电机驱动电路
- 显示刷新率需≥30Hz

### 二、E题 — 三子棋游戏装置

#### 题目要求
- 设计并制作三子棋游戏装置，能够控制机械臂或其他机构**放置棋子**，实现**人机对弈**
- 棋盘由黑色实线围成9个方格（3×3），棋盘格子边距约10~30mm，线宽约2mm，棋子直径约30mm

- 需要结合**机械结构、控制科学、嵌入式系统、机器视觉、机器学习与人工智能**等多学科知识
- 装置需能**实时获取棋盘信息**、**稳定抓取棋子**，实现人机对战
