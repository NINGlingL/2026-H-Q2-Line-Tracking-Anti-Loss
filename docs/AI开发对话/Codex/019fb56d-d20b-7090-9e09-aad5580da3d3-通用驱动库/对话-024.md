## 助手

| 函数 | 说明 |
|------|------|
| `OLED_DrawLine(x1,y1, x2,y2, color)` | 直线 |
| `OLED_DrawRectangle(x, y, w, h, color)` | 空心矩形 |
| `OLED_DrawFilledRectangle(x, y, w, h, color)` | 实心矩形 |
| `OLED_DrawCircle(x, y, r, color)` | 空心圆 |
| `OLED_DrawFilledCircle(x, y, r, color)` | 实心圆 |
| `OLED_DrawEllipse(x, y, a, b, color)` | 椭圆 |
| `OLED_DrawTriangle(x1,y1, x2,y2, x3,y3, color)` | 空心三角形 |
| `OLED_DrawFilledTriangle(x1,y1, x2,y2, x3,y3, color)` | 实心三角形 |
| `OLED_DrawImage(x, y, &img, color)` | 绘制位图 |

> 坐标范围：**x = 0~127**，**y = 0~63**，**color** 填 `OLED_COLOR_NORMAL` 或 `OLED_COLOR_REVERSED`

|------|---------|---------|

### 3.6 文字（中文）

| 函数 | 说明 |
|------|------|
| `OLED_PrintString(x, y, "床前明月光", &font16x16, color)` | 打印 UTF-8 中文 |

> ⚠️ **中文不能直接拿来用**——字库 `font16x16` 默认只有 4 个字（波特律动），需要自己生成。

## 五、添加自定义中文的流程

### 5.1 取模工具

打开 **https://led.baud-dance.com** → 文字取模 → 16×16 中文：
- 取模方式：**列行式**
- 字节序：**高位在前（MSB）**
- 输出格式：**C 语言数组**

### 5.2 输入你要的所有不重复汉字

比如 "你好世界" → 输入框输入这 4 个字。

### 5.3 把生成的数据填入 font.c

打开 `Core/Src/font.c`，找到末尾：

```c
// 替换前：
const uint8_t zh16x16[][36] = {
    /* 0 波 */ {...},   // ← 删掉这些旧的
    /* 1 特 */ {...},
    /* 2 律 */ {...},
    /* 3 动 */ {...},
};
const Font font16x16 = {16, 16, (const uint8_t *)zh16x16, 4, &afont16x8};
//                                                            ↑ 这里 4 = 旧字符数

// 替换后：
const uint8_t zh16x16[][36] = {
    /* 0 你 */ {...},   // ← 粘贴取模工具生成的数据
    /* 1 好 */ {...},
    /* 2 世 */ {...},
    /* 3 界 */ {...},
};
const Font font16x16 = {16, 16, (const uint8_t *)zh16x16, 4, &afont16x8};
//                                                            ↑ 改成新字符数
```

> 关键：**`len` 必须改成实际字符数量**，顺序要和取模工具输入的顺序一模一样。

### 5.4 在 main.c 中使用

```c
OLED_PrintString(0, 0, "你好世界", &font16x16, OLED_COLOR_NORMAL);
```

## 六、常用代码片段

### 画一个进度条

```c
OLED_DrawRectangle(10, 30, 108, 10, OLED_COLOR_NORMAL);          // 边框
OLED_DrawFilledRectangle(12, 32, percent, 6, OLED_COLOR_NORMAL); // 填充
```

### 居中显示文字

```c
// 8x6 ASCII: x = (128 - strlen*6) / 2
uint8_t len = strlen("Center Me");
OLED_PrintASCIIString((128 - len*6)/2, 28, "Center Me", &afont8x6, OLED_COLOR_NORMAL);

// 16x16 中文: x = (128 - 字数*16) / 2
OLED_PrintString((128 - 3*16)/2, 24, "静夜思", &font16x16, OLED_COLOR_NORMAL);  // 3个字, x=40
```

### 滚动显示长文字

```c
static int16_t scroll_x = 128;
OLED_NewFrame();
OLED_PrintASCIIString((uint8_t)scroll_x, 28, "Scrolling text...", &afont12x6, OLED_COLOR_NORMAL);
OLED_ShowFrame();
scroll_x -= 2;
if (scroll_x < -120) scroll_x = 128;
HAL_Delay(30);
```
