## 助手

产品配置在 CCS 内部数据库里，命令行改不了。你打开 CCS 做这一步最简单：

---

## 🔧 在 CCS Theia 中更新产品路径

1. 启动 CCS Theia：双击 **`D:\TI\ccs\theia\ccstudio.exe`**

> 注意路径变了！之前的桌面快捷方式指向旧路径可能会失效，直接用新路径打开。

2. 菜单：**Window → Preferences**

3. 左侧：**Code Composer Studio → Products**

4. 你会看到旧的条目（带 `D:\A嵌入式\TI` 的路径）→ 全选 → **Remove** 删掉

5. 点 **Add...**：
   - 选 `D:\TI\mspm0_sdk_2_11_00_07` → 确定
   - 再点 **Add...** → 选 `D:\TI\sysconfig_1.26.2` → 确定

6. 点 **Apply and Close**

---

## 🔨 然后编译工程

7. 菜单：**Project → Clean...** → 选 `01` → Clean
8. 点击 **🔨 Build**

> 这次 SDK 路径是 `D:\TI\...`（纯英文），gmake 不会再报 `Illegal byte sequence`。
