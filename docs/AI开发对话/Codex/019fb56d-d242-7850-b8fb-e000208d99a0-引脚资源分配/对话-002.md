## 助手

我先用 Python 直接解析这些 PDF/DOCX，因为当前环境缺少 `pdftoppm`，普通 PDF 读取工具无法渲染页面；Python 里有 `PyMuPDF(fitz)` 和 `python-docx`，可以提取文字、截图并生成最终 PDF。

## 助手

description: 解析题目和开发板 PDF/DOCX 并导出文字与页面图片
command: python - <<'PY'
from pathlib import Path
import fitz
from docx import Document
files = [
Path(r'D:\A嵌入式\资料库\电赛资料\H题_车载平衡滚球运动控制系统.pdf'),
Path(r'D:\A嵌入式\资料库\3507\立创·天猛星MSPM0G3507开发板资料-241115\立创·天猛星MSPM0G3507开发板资料\02-【MSPM0G3507】开源硬件\立创·天猛星MSPM0G3507开发板原理图.pdf'),
Path(r'D:\A嵌入式\资料库\3507\立创·天猛星MSPM0G3507开发板资料-241115\立创·天猛星MSPM0G3507开发板资料\02-【MSPM0G3507】开源硬件\天猛星MSPM0G3507开发板引脚图.pdf')]
outdir=Path(r'C:\Users\16484\pin_plan_work')
outdir.mkdir(exist_ok=True)
for f in files:
    print('\n====', f.name, '====')
    doc=fitz.open(str(f))
    print('pages', doc.page_count)
    text=[]
    for i,p in enumerate(doc):
        t=p.get_text('text')
        print('--page',i+1,'text chars',len(t))
        print(t[:1500].replace('\n',' | '))
        text.append(f'===== page {i+1} =====\n{t}')
        pix=p.get_pixmap(matrix=fitz.Matrix(2,2), alpha=False)
        png=outdir/(f.stem+f'_p{i+1}.png')
        pix.save(str(png))
    (outdir/(f.stem+'.txt')).write_text('\n'.join(text),encoding='utf-8')

docx=Path(r'D:\A嵌入式\资料库\电赛资料\H题_车载平衡滚球运动控制系统.docx')
if docx.exists():
    d=Document(str(docx))
    txt='\n'.join(p.text for p in d.paragraphs)
    (outdir/'H题_docx.txt').write_text(txt,encoding='utf-8')
    print('\n==== docx ====')
    print(txt[:3000])
print('输出目录', outdir)
PY
