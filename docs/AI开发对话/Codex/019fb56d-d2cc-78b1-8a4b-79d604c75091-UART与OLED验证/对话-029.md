## 蓝牙控制指令

| 按键 | 功能 |
|:-:|:-:|
| **F** | 前进 |
| **B** | 后退 |
| **L** | 左转 |
| **R** | 右转 |
| **S** / 空格 | 停止 |
| **+** | 加速 +10% |
| **-** | 减速 -10% |
| **0-9** | 速度档位 (10%~90%) |

## OLED 显示内容

| 行 | 内容 |
|:-:|------|
| 0 | `BT Car Control` 标题 |
| 1 | 当前方向 + 速度百分比 |
| 2 | RX 接收字节数 + 运行时间 |
