## 硬件接线

| MSPM0G3507 | HC-05 |
|:-:|:-:|
| PA22 (UART2 RX) | TX |
| PA21 (UART2 TX) | RX |
| 3.3V | VCC |
| GND | GND |

**注意**: HC-05 的 TX 接 MSPM0 的 RX (PA22)，HC-05 的 RX 接 MSPM0 的 TX (PA21) — 交叉连接。

重新编译下载后，手机通过蓝牙连接 HC-05，发送文字就会在 OLED 上显示，RX 计数也会增加。如果还是 RX:0，请检查：
1. HC-05 的 TX/RX 有没有接反
2. HC-05 波特率是否确实是 9600（用 AT 命令确认：`AT+UART?`）
3. 手机是否已成功配对并连接 HC-05
