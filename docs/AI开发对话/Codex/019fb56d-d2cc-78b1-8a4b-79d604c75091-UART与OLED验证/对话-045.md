## 当前模块架构

```
empty.c (主程序)
  ├── moto.c/h        → TB6612 电机驱动
  ├── uart_bt.c/h     → HC-05 蓝牙 (UART2, 中断+环形缓冲)
  ├── control.c/h     → 指令解析 (F/B/L/R/数字 → 电机动作)
  ├── mpu6050.c/h     → MPU6050 通用驱动 (Mahony + 互补滤波)
  └── mpu6050_hal_mspm0.c  → I2C_1 硬件读写实现
```

## 硬件接线

| 模块 | MSPM0 引脚 | 外设 |
|:-:|:-:|:-:|
| OLED | PA0=SDA, PA1=SCL | SSD1306 (I2C_0) |
| **MPU6050** | **PA16=SDA, PA15=SCL** | 陀螺仪 (I2C_1) |
| HC-05 | PA21=TX, PA22=RX | 蓝牙 (UART2) |
| 电机 | PA12/PA13 PWM, PB2/3/15/16 GPIO | TB6612 |

## OLED 显示

| 行 | 内容 |
|:-:|------|
| 0 | **YAW: +XXX deg** (航向角, 大字) |
| 1 | 方向 + 速度% + RX 计数 |
| 2 | 分隔线 |
| 3-8 | 蓝牙接收数据回显 |

## 需要在 Keil 中添加的源文件

在 Keil IDE 中把以下文件添加到 Source Group：
- `../mpu6050.c`
- `../mpu6050_hal_mspm0.c`
- `../mpu6050_hal.h`
- `../mpu6050.h`

> MPU6050 上电后会自动校准 (200 次采样, ~0.4s)，校准时 OLED 显示 "Keep STILL !"，传感器需**保持水平静止**。然后 YAW 角会实时显示在 OLED 第 0 行。
