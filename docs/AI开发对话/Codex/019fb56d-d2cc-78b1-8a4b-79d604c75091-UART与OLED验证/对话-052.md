### 为什么 WHO_AM_I 能读但大量读就慢？

MPU6050 的 `PWR_MGMT_1` 写入 0x00 唤醒后，`Init` 只等了 **10ms**。MPU6050 内部振荡器稳定需要更长时间（典型 30-50ms）。WHO_AM_I 寄存器是静态的（不需要传感器稳定），而 0x3B-0x48 的加速度/陀螺仪寄存器依赖内部时钟。时钟未稳时读取可能返回错误数据或拉长时钟 stretching。

---

### 修复方向

1. 超时从 **100,000 → 5,000**（~5ms 超时，总校准最长 ~12 秒）
2. 唤醒后加 **50ms 延迟** 等 MPU6050 时钟稳定
3. 每次 I2C 读之间加微小间隔

44	             DL_I2C_CONTROLLER_STATUS_IDLE)) {
45	        if (--timeout == 0) return 0xFF;  /* 超时返回 */
46	    }
47	
48	    DL_I2C_startControllerTransfer(I2C_1_INST, addr,
49	        DL_I2C_CONTROLLER_DIRECTION_TX, 1);
50	
51	    timeout = 100000;
52	    while (DL_I2C_getControllerStatus(I2C_1_INST) &
53	           DL_I2C_CONTROLLER_STATUS_BUSY_BUS) {

55	    }

61	    }
62
