# 📐 MSPM0 G3507 引脚分配方案

## 总览：20 个引脚，覆盖 6 个外设模块

```
TB6612 ─┐
编码器1 ─┤  (硬件 QEI)
编码器2 ─┤  (软件 GPIO 中断)
5路循迹 ─┤── MSPM0 G3507
OLED    ─┤   SSD1306 + ICM20948 共用 I2C
蓝牙    ─┤   HC-05 UART
ICM20948─┘   (备用,共享 I2C)
```

---

## 完整引脚表

| 引脚 | 功能 | 外设复用 | 说明 |
|------|------|---------|------|
| **PA0** | I2C_SDA | I2C0_SDA | SSD1306(0x3C) + ICM20948(0x68) 共用 |
| **PA1** | I2C_SCL | I2C0_SCL | 同一条 I2C 总线,地址不冲突 |
| **PA5** | ENC1_A | TIMG6_CCP0 | 🔧 硬件编码器 左轮 A 相 |
| **PA6** | ENC1_B | TIMG6_CCP1 | 🔧 硬件编码器 左轮 B 相 |
| **PA12** | PWMA | TIMG0_CCP0 | TB6612 电机 A PWM |
| **PA13** | PWMB | TIMG0_CCP1 | TB6612 电机 B PWM |
| **PA21** | BT_TX | UART2_TX | HC-05 蓝牙发送 |
| **PA22** | BT_RX | UART2_RX | HC-05 蓝牙接收 |
| **PB0** | ENC2_A | GPIOB (中断) | 📝 软件编码器 右轮 A 相 |
| **PB1** | ENC2_B | GPIOB (中断) | 📝 软件编码器 右轮 B 相 |
| **PB2** | BIN1 | GPIOB | TB6612 电机 B 正转 |
| **PB3** | BIN2 | GPIOB | TB6612 电机 B 反转 |
| **PB4** | STBY | GPIOB | 🆕 TB6612 使能 (软件可控!) |
| **PB5** | LS1 | GPIOB | 循迹传感器 1 |
| **PB6** | LS2 | GPIOB | 循迹传感器 2 |
| **PB7** | LS3 | GPIOB | 循迹传感器 3 |
| **PB8** | LS4 | GPIOB | 循迹传感器 4 |
| **PB9** | LS5 | GPIOB | 循迹传感器 5 |
| **PB15** | AIN2 | GPIOB | TB6612 电机 A 反转 |
| **PB16** | AIN1 | GPIOB | TB6612 电机 A 正转 |

**预留：PA19(SWDIO)、PA20(SWCLK) — SWD 调试口，禁止占用 ✅**
