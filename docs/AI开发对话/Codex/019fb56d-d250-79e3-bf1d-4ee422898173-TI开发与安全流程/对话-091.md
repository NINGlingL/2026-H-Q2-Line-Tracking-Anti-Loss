      "command": "C:\\Users\\16484\\.cargo\\bin\\embedded-debugger-mcp.exe",

    }

配置没问题。但 MCP 服务器是**启动 Claude Code 时加载的**，你配置之后没重启过，所以还没生效。

**退出 Claude Code 再重新打开**，就能看到 `embedded-debugger` 的 MCP 工具了（`flash_program`、`diagnose_fault`、`read_memory` 等）。

description: Read MSPM0 chip state via pyocd
command: python -c "
from pyocd.core.helpers import ConnectHelper
import pyocd.core.target as T
with ConnectHelper.session_with_chosen_probe(blocking=False) as s:
    t = s.target
    print(f'Probe: {s.probe.product_name} ({s.probe.unique_id})')
    print(f'Core:  Cortex-M0+  (CPUID 0x{t.read32(0xE000ED00):08X})')
    state = {T.Target.State.RUNNING:'RUNNING', T.Target.State.HALTED:'HALTED'}.get(t.get_state(),'?')
    print(f'State: {state}')
    if t.get_state() == T.Target.State.HALTED:
        print(f'PC: 0x{t.read_core_register(\"pc\"):08X}')
        print(f'SP: 0x{t.read_core_register(\"sp\"):08X}')
    print(f'Clock: 32MHz (SYSOSC)')
    print(f'Flash: 128KB / SRAM: 32KB')
    print()
