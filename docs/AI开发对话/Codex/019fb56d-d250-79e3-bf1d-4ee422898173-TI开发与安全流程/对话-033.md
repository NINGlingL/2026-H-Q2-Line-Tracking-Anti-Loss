```
OLED 显示效果:
┌────────────────┐
│ Xun Ji Status  │  第 0 行
│ 1 2 3 4 5      │  第 1 行 (传感器编号)
│ X O O X O      │  第 2 行 (X=触发 O=未触发)
│                │
│ Raw: 0x13      │  第 4 行 (十六进制原始值)
└────────────────┘
```

关键设计点：
- **一次性读取** 5 路传感器（`DL_GPIO_readPins` + 掩码），单指令完成
- **只在状态变化时刷新**屏幕，减少无意义的 I2C 通信
- `LS_ACTIVE_LOW` 宏控制触发极性，根据你的实际模块改 `0` 或 `1`
- 10ms 轮询间隔
