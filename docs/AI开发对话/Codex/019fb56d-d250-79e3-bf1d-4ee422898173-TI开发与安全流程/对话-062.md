## 主控选型：MSPM0 系列

- **推荐芯片**：MSPM0G3507（主频 80MHz，128KB Flash，32KB SRAM，60 个 GPIO，4×UART / 2×I2C / 2×SPI / 1×CAN）
- **推荐开发板**：天猛星开发板
- **选型要点**：
  - 优先使用官方开发板，供电稳定（3.3V±0.05V），烧录成功率 >99%
  - 第三方板需关注供电波动和散热设计，劣质板长时间工作可能因电源管理芯片过热导致重启或烧毁
  - 供电建议采用**双重保护策略**

## 循迹方案

| 场景 | 方案 |
|------|------|
| 有黑线引导区域 | **8路灰度传感器**巡线，结合惯性导航辅助 |
| 无黑线引导区域 | **纯惯性导航**（JY901S 陀螺仪 + 霍尔编码器里程积分），只做航向角控制 |

- 惯导思路：陀螺仪直接解算航向角（-180°~180°），注意处理角度跳变，将目标航向角送入方向 PID 控制器的目标值即可，无需复杂的位置推算（EKF 融合）

## 控制算法

| 控制器类型 | 用途 | 算法 |
|-----------|------|------|
| 增量式 PI 控制器 | 速度环 | 基于 20ms 定时器中断测量 MG310 电机霍尔编码器速度，快速响应 |
| 位置式 PD 控制器（串级 PID） | 方向环/循迹环 | 角度环（外环）+ 角速度环（内环），减少超调和振荡 |

## 硬件配置参考

- 结构：两驱动轮 + 牛眼轮
- 电机：MG310 直流电机（带霍尔编码器）
- 陀螺仪：维特九轴 JY901S
- 传感器：8路灰度传感器
- 通信：无线串口

### 2017年全国大学生电子设计竞赛B题优秀作品——滚球控制系统（中国矿业大学）

该方案的核心架构如下：

| 组成部分 | 具体方案 |
|----------|----------|
| **主控制器** | STM32 单片机 |
| **控制算法** | PID 控制 |
| **执行机构** | 舵机（通过 PWM 脉冲控制） |
| **视觉/位置反馈** | OV7725 摄像头 + 图像显示界面 |

### 工作原理
系统通过摄像头采集小球在平板上的位置信息，经 STM32 处理并运行 PID 算法，输出 PWM 信号驱动舵机调整平板倾斜角度，从而控制小球滚动到目标位置。测试结果表明该系统能完成题目要求的全部基本功能和发挥功能。
