# MSPM0 DriverLib QEI Encoder PID Motor Control Example Code

Based on the search results, here is a summary of the available resources, approaches, and example code for implementing QEI encoder-based PID motor control on MSPM0 using DriverLib.

---

## Key Finding: MSPM0 Does Not Have a Dedicated QEI Peripheral

Unlike older TI MCUs (e.g., TM4C/dsPIC), the **MSPM0 does not have a dedicated hardware QEI module**. Instead, QEI functionality is implemented using the **TIMG (Timer) in capture mode** with 2-signal (PHA/PHB) or 3-signal (PHA/PHB/IDX) configuration. This is documented in the MSPM0 Technical Reference Manual (SLAU923).

### QEI 2-Signal Mode Configuration on MSPM0 (from TI Manual)

```
1. Configure PINCMx for TIMGx_C0 (PHA) and TIMGx_C1 (PHB)
2. Set TIMG.CCCTL_01[0].COC = 1 and TIMG.CCCTL_01[1].COC = 1 (capture mode)
3. Configure CCP as input: CCPD.C0CCP0 = 0
4. Set TIMx.LOAD to encoder resolution (e.g., 4000)
5. Set CTRCTL register: CAC, CZC, CLC bits to 4h (2-signal QEI) or 5h (3-signal QEI)
6. Enable counter: EN = 1
```

## Where to Find Actual Example Code

### 1. TI MSPM0-SDK (Official Source)
The **MSPM0-SDK** (currently v2.09.00.01) includes **motor control examples** for stepper, brushed, sensorless FOC, sensored FOC, and Hall-sensored trap control. The DriverLib examples are organized under:
```
mspm0_sdk_x_x_x/examples/nortos/LP_MSPM0xxxx/DriverLib/
```

**Download from:** TI's official MSPM0-SDK page.

### 2. Open-Source Hardware Projects (Best Practical Match)

Two **oshwhub.com** projects directly match your request — both are PID learning kits built on the **MSPM0G3507** development board with encoder-equipped motors:

**Software Architecture:**
- **`hardware/hw_encoder.c`** — Encoder pulse acquisition (using external interrupts on GPIO for A/B phase signals)
- **`hardware/hw_motor.c`** — Motor PWM drive (Timer PWM output, 10kHz frequency)
- **`middleware/mid_pid.c`** — Universal PID algorithm implementation
- **`app/app_speed_pid.c`** — Speed loop PID control
- **`app/app_distance_pid.c`** — Position loop PID control

**PID Formula Used:**
```
PID_OUT = Kp × error + Ki × accumulated_error + Kd × error_rate_of_change
```

**Speed Control:** Real-time encoder speed measurement → PID calculates output → adjusts PWM duty cycle  
**Position Control:** Accumulated encoder pulses as feedback → PID closed-loop controls motor start/stop and direction

**Encoder Implementation Detail:** Since MSPM0G3507 lacks a dedicated QEI peripheral, these projects use **external interrupts on GPIO** to capture A/B phase pulses, with phase difference (90°) used to determine rotation direction.
