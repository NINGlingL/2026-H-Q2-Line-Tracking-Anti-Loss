## IMU/陀螺仪的两个用途

### 用途 1：辅助循迹（航向角控制）

灰度传感器只能告诉你"线在车的左边还是右边"，但看不到**车的朝向**。陀螺仪能补这个盲区：

```
灰度传感器: "线偏左 3cm"  →  横向误差
陀螺仪:     "车头偏右 15°" →  角度误差

两者融合 → 更稳的循迹
```

**具体场景：**
- **急弯**：灰度传感器来不及反应 → 陀螺仪提前感知车在转弯 → 提前纠正
- **丢线**：过十字路口/断线时灰度全灭 → 陀螺仪维持最后航向 → 惯性导航直行
- **直角弯**：灰度看到一个方向，陀螺仪看到车已转够 90° → 精确停止转弯

24 年电赛很多队伍就用 `灰度 + 陀螺仪` 串级 PID：
```
外环(位置PID):  灰度误差 → 目标角速度
内环(角速度PID): 陀螺仪Z轴 → 电机差速
```

### 用途 2：H 题核心——摆杆角度反馈（滚球平衡）

这才是 H 题里 IMU **不可替代**的作用：

```
          ┌─── 摆杆 ───┐
         /              \
        /    ○ 钢球      \
       /                  \
舵机 ──┘                  └── 转轴
       ↑                  
  IMU 贴在这里, 测摆杆倾角 θ
```

- 舵机转动 → 摆杆倾斜角度 θ
- 重力沿摆杆分量 = g·sin(θ) → 球滚动
- IMU 实时测量 θ → PID 内环反馈
- 摄像头/传感器测球位置 x → PID 外环反馈

**串级 PID 结构：**
```
目标球位置 → [位置PID] → 目标倾角 → [倾角PID] → 舵机PWM → 摆杆
                 ↑                         ↑
           球位置反馈(OpenMV)          倾角反馈(IMU/陀螺仪)
```

## 结论

| 用途 | 传感器 | 是否必需 |
|------|--------|:--:|
| 循迹方向 | IMU Z轴 (偏航角) | ⭐ 加分项，非必需 |
| 摆杆倾角 | IMU X/Y轴 (倾角) | 🔴 **H 题必需** |

ICM20948 你已经在引脚规划里留了 I2C 接口，刚好两个用途都能覆盖。**循迹可以先用纯灰度跑通，但滚球平衡必须要 IMU 来测摆杆角度。**

## 用户

舵机吗，不能用丝杆滑杆和TMC2208？

## 助手

你说得对，**丝杆+步进+TMC2208 比舵机更适合这道题**。我之前推荐舵机是"惯性思维"，仔细想一下，H 题的滚球平衡对精度和响应要求很高，步进方案确实更优。

---

## 舵机 vs 丝杆+步进 对比

| 维度 | 舵机 (MG996R) | 丝杆 + 步进 + TMC2208 |
|------|:--:|:--:|
| **角度精度** | 0.5°~1° (模拟电位器反馈) | **0.02°** (256微步进 × 丝杆传动比) |
| **响应速度** | 0.17s/60° (慢) | 由丝杆导程决定，通常**更快** |
| **保持力矩** | 堵转发热，抖舵 | 静止力矩大，**不抖** |
| **噪音** | 齿轮噪音 | TMC2208 静音驱动 (StealthChop2) |
| **闭环** | 内置(电位器) | 开环，但可用 `StallGuard` 失速检测 |
| **控制接口** | 1 个 PWM | 2 个 GPIO (STEP + DIR) |
| **寿命** | 塑料齿轮易磨损 | 丝杆 + 步进 = **长寿命** |
| **机械复杂度** | 直接装 | 需要连轴器/丝杆/滑台 |

## 为什么 TMC2208 适合这道题

```
磁编码器测摆杆角 ──→ MSPM0 PID ──→ STEP/DIR ──→ TMC2208 ──→ 步进电机
       ↑                                                    │
       └──────── 丝杆推拉 ── 摆杆倾斜 ── 球滚动 ──────────────┘
```

### 1. 精度碾压
- 步进电机一圈 200 步 × TMC2208 256 微步 = **51200 步/圈**
- 丝杆导程 2mm → 每步 = 0.00004mm 线性位移
- 换算到摆杆角度（假设丝杆距转轴 10cm）：每步约 **0.002°** 
- 对比舵机：0.5°~1° → **精度差 250 倍**

### 2. 控制简单
TIMG 输出 PWM 脉冲给 STEP 脚 + 一个 GPIO 控制 DIR 方向：
```c
// TIMA0 输出 STEP 脉冲 (10kHz), PB4=DIR
DL_TimerA_setPeriod(TIMA0, 800);  // 每步 80us
DL_GPIO_setPins(GPIOB, DIR_PIN);  // 方向
```

### 3. TMC2208 额外功能
- **StallGuard**：检测失速（球卡住、丝杆堵转）
- **StealthChop2**：超静音（比赛现场不吵）
- **UART 配置**：可在线调电流/微步数
