## 🔴 P0 级别 — 必须修复

### P0-2 ❌ 储能电源监测缺失

**文件**: `moto.c`, 全局架构
**问题**: 整个驱动库完全没有电池电压 ADC 监测。MSPM0 G3507 内部有 ADC0/ADC1，可用于读取电池分压。当前电机控制没有任何低压保护——电池电压过低时，电机仍会尝试全功率运行，可能导致：
- 锂电池过放永久损坏
- TB6612 在欠压状态下行为不可预测
- 系统在主控低压复位前可能失控

**修复建议**:
```c
// moto.c 增加:
#define BATT_ADC_CHANNEL  DL_ADC12_CHANNEL_0  // 根据实际引脚调整
#define BATT_LOW_THRESHOLD_MV  3300  // 2S 锂电池低压阈值
#define BATT_CRIT_THRESHOLD_MV 3000

static void Moto_CheckBattery(void)
{
    uint16_t batt_mv = ADC_ReadBattery();
    if (batt_mv < BATT_CRIT_THRESHOLD_MV) {
        Moto_Stop();  // 紧急断电
        // 进入不可自恢复报警状态
    }
}
```

### P0-4 ❌ 独立看门狗缺失

**文件**: 全局
**问题**: 没有任何看门狗配置代码。G3507 有 WWDT0/WWDT1 两个窗口看门狗。如果主循环因 I2C 挂死等原因卡住，电机将持续以最后设置的 PWM 运行，小车失控。

**修复建议**: 在 `main()` 中初始化 WWDT0，使用 LFOSC (32kHz 独立时钟)，主循环末尾喂狗，ISR 内严禁喂狗。

---

### P0-3 ⚠️ TB6612 STBY 硬连线到 3.3V

**文件**: `moto.h` 第 8 行注释
```c
// STBY 接 3.3V (使能)
```
**问题**: STBY 引脚硬连线，软件无法控制电机使能/禁用。如果使用一个 GPIO 接 STBY，急停时可以直接拉低 STBY 禁用所有电机。

**修复建议**: 将 STBY 接到一个 GPIO（如 PB4），在 `Moto_Init()` 中拉高，`Moto_Stop()` 中也拉低。

## 🟡 P1 级别 — 强烈建议修复

### P1-3 ❌ I2C 无超时 — 会导致主循环永久卡死

**文件**: `ssd1306.c` 第 112-121 行
```c
static void I2C_WriteBytes(uint8_t *data, uint8_t len)
{
    DL_I2C_fillControllerTXFIFO(I2C_1_INST, data, len);
    while (!(DL_I2C_getControllerStatus(I2C_1_INST) & DL_I2C_CONTROLLER_STATUS_IDLE));
    //  ↑ 如果 I2C 总线被拉低（OLED 松脱/短路），这里永远不返回！
    DL_I2C_startControllerTransfer(I2C_1_INST, SSD1306_I2C_ADDR, ...);
    while (DL_I2C_getControllerStatus(I2C_1_INST) & DL_I2C_CONTROLLER_STATUS_BUSY_BUS);
    //  ↑ 同理，总线卡死时永久阻塞
    while (!(DL_I2C_getControllerStatus(I2C_1_INST) & DL_I2C_CONTROLLER_STATUS_IDLE));
}
```

**危险度**: ⚡**最高** — 这是最可能在实际使用中触发的问题。OLED 排线松动 = 整车卡死。

**修复建议**:
```c
static bool I2C_WriteBytesTimeout(uint8_t *data, uint8_t len, uint32_t timeout_ms)
{
    uint32_t start = g_systick;  // 需要实现 systick
    DL_I2C_fillControllerTXFIFO(I2C_1_INST, data, len);
    while (!(DL_I2C_getControllerStatus(I2C_1_INST) & DL_I2C_CONTROLLER_STATUS_IDLE)) {
        if ((g_systick - start) > timeout_ms) {
            // 总线恢复：发送 9 个 SCL 脉冲
            DL_I2C_emergencyBusRecovery(I2C_1_INST);
            return false;
        }
    }
    // ... 后续也加超时
    return true;
}
```
