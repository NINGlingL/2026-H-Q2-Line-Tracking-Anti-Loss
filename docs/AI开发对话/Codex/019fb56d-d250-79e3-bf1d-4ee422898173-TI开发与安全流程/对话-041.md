## MSPM0 G3507 引脚分配方案

### 总览：20 引脚 / 6 个模块

```
TB6612 ─── 2 PWM + 4 GPIO + 1 STBY = 7 pins
编码器1 ─── TIMG6 硬件 QEI = 2 pins (左轮)
编码器2 ─── GPIOB 中断 软件解码 = 2 pins (右轮)
5路循迹 ─── 5 × GPIOB = 5 pins
OLED+IMU ── I2C0 共用总线 = 2 pins
蓝牙 ──── UART2 = 2 pins
调试 ──── SWD = 2 pins (保留)
```

### 完整引脚表

| 引脚 | 功能 | 外设 | 说明 |
|------|------|------|------|
| **PA0** | I2C_SDA | I2C0_SDA | OLED + ICM20948 共用 |
| **PA1** | I2C_SCL | I2C0_SCL | OLED + ICM20948 共用 |
| **PA5** | ENC1_A | TIMG6_CCP0 | 硬件编码器 左轮 A相 |
| **PA6** | ENC1_B | TIMG6_CCP1 | 硬件编码器 左轮 B相 |
| **PA12** | PWMA | TIMG0_CCP0 | TB6612 电机A PWM |
| **PA13** | PWMB | TIMG0_CCP1 | TB6612 电机B PWM |
| **PA21** | BT_TX | UART2_TX | HC-05 蓝牙 |
| **PA22** | BT_RX | UART2_RX | HC-05 蓝牙 |
| **PB0** | ENC2_A | GPIOB | 软件编码器 右轮 A相 (中断) |
| **PB1** | ENC2_B | GPIOB | 软件编码器 右轮 B相 (中断) |
| **PB2** | BIN1 | GPIOB | TB6612 电机B 正转 |
| **PB3** | BIN2 | GPIOB | TB6612 电机B 反转 |
| **PB4** | STBY | GPIOB | TB6612 使能 (新增!) |
| **PB5** | LS1 | GPIOB | 循迹传感器 1 |
| **PB6** | LS2 | GPIOB | 循迹传感器 2 |
| **PB7** | LS3 | GPIOB | 循迹传感器 3 (中间) |
| **PB8** | LS4 | GPIOB | 循迹传感器 4 |
| **PB9** | LS5 | GPIOB | 循迹传感器 5 |
| **PB15** | AIN2 | GPIOB | TB6612 电机A 反转 |
| **PB16** | AIN1 | GPIOB | TB6612 电机A 正转 |

**保留禁止占用：PA19(SWDIO)  PA20(SWCLK)**

### 外设占用

| 外设 | 用途 |
|------|------|
| TIMG0 | 电机 PWM |
| TIMG6 | 硬件编码器 QEI |
| I2C0 | OLED + ICM20948 |
| UART2 | HC-05 蓝牙 |
| GPIOB | 方向/循迹/软件编码器/STBY |
