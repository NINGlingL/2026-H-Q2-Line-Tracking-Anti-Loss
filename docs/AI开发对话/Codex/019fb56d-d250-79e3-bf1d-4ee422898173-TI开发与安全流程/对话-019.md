### P2 ⚠️ PWM 频率仅 4kHz

**文件**: `moto.c` 计算: `4MHz / 1000 = 4kHz`

TB6612 典型 PWM 频率 10-20kHz。4kHz 在电机啸叫范围内，会产生可闻的高频噪音。

**修复建议**: 将 `PWM_PERIOD` 从 1000 改为 `400` → 10kHz，或在 SysConfig 中将 TIMG0 时钟提升。

## 🎯 结论

**可以在 G3507 上运行**，外设(PWM/GPIO/I2C/UART)都存在于 G3507，引脚与现有项目配置兼容。但有以下**致命隐患**：

| 优先级 | 数量 | 最严重问题 |
|--------|:---:|-----------|
| 🔴 P0 | 2 | **无电池监测** + **无看门狗** |
| 🟡 P1 | 1 | **I2C 无超时 → OLED 松脱 = 整车卡死** |
| 🟢 P2 | 5 | 加减速反了、PWM 4kHz 啸叫、阻塞自检等 |

**I2C 无超时是最可能在比赛现场触发的问题** — OLED 排线震动松脱 → `I2C_WriteBytes` 永久阻塞 → 电机保持最后状态 → 小车失控。强烈建议优先修复。
