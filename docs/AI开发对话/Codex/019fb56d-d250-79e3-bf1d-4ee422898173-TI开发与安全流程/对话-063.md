## 三、核心挑战分析

这道题本质上是**两个控制系统的叠加**：

### 控制层 1：小车循迹 (你已经在做)

```
灰度传感器 → 位置误差 → PID → 差速电机
```

- 8 路灰度传感器循迹（题目限制只能用灰度模块）
- 编码器速度反馈（可选，用于精确速度控制）
- 纯循迹已经能拿 16+5+20 = 41 分

### 控制层 2：滚球平衡 (新问题)

```
球位置传感器 → 位置误差 → PID → 舵机角度 → 摆杆倾斜 → 球滚动
                                    ↑
                           IMU/编码器(角度反馈)
```

这是**球-杆系统 (Ball-on-Beam)**，经典控制理论问题：
- 摆杆倾斜 → 重力分量 → 球滚动加速度
- 本质是**不稳定系统**（球会自己滚走），必须闭环
- 需要**串级 PID**：外环(球位置 → 目标倾角) + 内环(倾角 → 舵机PWM)

## 四、需要什么硬件

### 已有/已规划的

| 硬件 | 状态 | 用途 |
|------|:--:|------|
| MSPM0 G3507 | ✅ | 主控 |
| TB6612 + 直流电机 | ✅ | 小车驱动 |
| 五路循迹模块 | ✅ | 循迹 (建议升级到 8 路) |
| 编码器 ×2 | ✅ | 速度/里程反馈 |
| SSD1306 OLED | ✅ | 调试显示 |
| HC-05 蓝牙 | ✅ | 调试输出 |

### 需要新增的

| 硬件 | 数量 | 用途 | 建议型号 |
|------|:--:|------|------|
| **舵机** | 1 | 控制摆杆倾斜角度 | MG996R (金属齿, 大扭力) 或 S3010 |
| **PPR 水管** | 1 | 弧形摆杆轨道 | 题目指定: 外径 2cm, 壁厚 0.34cm, 长 25cm |
| **钢球** | 1 | 滚动小球 | 直径 ~1cm |
| **球位置传感器** | 1 | 检测球在摆杆上的位置 | 3 选 1 (见下方) |
| **OpenMV/摄像头** | 1 | 图传 + 球位置识别 | OpenMV Cam H7 / K210 |
| **IMU 陀螺仪** | 1 | 摆杆角度反馈 | MPU6050 / ICM20948 (已有接口!) |
| **8 路灰度模块** | 1 | 循迹 (替代 5 路) | 8 路 TCRT5000 阵列 |
| **大容量电池** | 1 | 整车供电 | 3S 锂电池 (11.1V) + 稳压模块 |
| **显示/存储设备** | 1 | 接收图传画面 | 手机/平板/笔记本电脑 |

### 球位置传感器的 3 种方案

| 方案 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **OpenMV 视觉** | 摄像头俯拍摆杆, 识别球的位置 | 精度高, 同时满足任务1(图传) | 处理速度受限, 需要补光 |
| **电阻式触摸屏** | 贴在线性轨道上, 球压位置产生电压 | 简单, 精度高, 实时 | 需要定制, 接触可能不可靠 |
| **红外对管阵列** | 沿轨道排列红外发射/接收对, 球遮挡光束 | 便宜, 实时 | 分辨率受限于阵列密度 |

**推荐方案：OpenMV 视觉** — 一举两得，既能识别球位置又能满足任务 1 的图传要求。

```
                       │  │  │  │  │

          ▼               ▼  ▼  ▼              ▼
    ┌──────────┐  ┌──────────┐  ┌──────────────────┐
    │8路灰度    │  │编码器×2  │  │  OpenMV/USART    │
    │(循迹)     │  │(速度里程)│  │  球位置(x,y)      │
    └──────────┘  └──────────┘  └──────────────────┘
          │               │              │
          ▼               ▼              ▼
    ┌─────────────────────────────────────────┐
    │           PID 控制系统                    │
    │  循迹PID → 差速电机                       │
    │  平衡PID → 舵机 → 摆杆倾角 → 球位置       │

    └─────────────────────────────────────────┘

    │TB6612   │  │ 舵机     │  │OLED+蓝牙 │

    └─────────┘  └─────────┘  └─────────┘
```
