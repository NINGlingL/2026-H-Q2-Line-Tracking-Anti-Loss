### CH1116 vs SSD1306 的关键差异

1. **I2C 地址**: `0x3C` (7-bit) / `0x78` (8-bit 模块丝印)— 与 SSD1306 相同
2. **列偏移**: CH1116 内部 RAM 为 132×64，`CH1116_COL_OFFSET = 2` 使 128 列显示居中
3. **DC-DC 控制**: 加入了 CH1116 特有的 `0xAD, 0x30` 命令启用内部升压
4. **时钟分频**: `0xD5, 0x80`（分频=1，比 SSD1306 的 0xF0 更保守的频率）
5. **VCOMH**: `0xDB, 0x30`（~0.83×VCC，SSD1306 用 0x20）
6. **新增 API**: `CH1116_ShowUNum`、`CH1116_ShowFloat`、`CH1116_ShowChinese`、`CH1116_ShowHZString` — 支持无符号数、浮点数、汉字显示

### 使用方式

```c
#include "ch1116.h"

CH1116_Init();
CH1116_ShowString(0, 0, "Hello G3507!");
CH1116_Update();
```

用法与 SSD1306 完全一致，API 前缀从 `SSD1306_` 改为 `CH1116_`。
