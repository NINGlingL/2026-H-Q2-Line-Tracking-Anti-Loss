## 助手

你当前工程配置的调试器是 **XDS110**（TI 官方调试器）。你的国产核心板上有没有板载调试器？还是需要外接一个？

分三种情况：

---

### 情况一：你有 XDS110（或核心板自带调试芯片）

1. USB 线一头接核心板，一头接电脑
2. CCS 里右键工程 → **Debug As → Code Composer Debug Session**
3. 等下载完成 → 点绿色三角 ▶ 运行

---

### 情况二：你有 DAP-Link / J-Link OB（最可能的国产板方案）

核心板上一般有 4 个排针（SWD 接口）：

```
核心板丝印      接调试器
3.3V    ────→  VCC
GND     ────→  GND
SWCLK   ────→  SWCLK
SWDIO   ────→  SWDIO
