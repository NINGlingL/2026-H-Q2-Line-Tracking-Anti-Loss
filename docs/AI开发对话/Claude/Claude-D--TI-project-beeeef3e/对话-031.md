## 助手

MSPM0G3507 有三类定时器，它们在 SysConfig 里分别出现：

## 定时器全家福

| 类型 | 数量 | 位数 | 能干吗 |
|------|------|------|--------|
| **TIMA**（高级） | 1 个 | 16 位 | PWM + 死区 + 故障保护 → 电机桥专用 |
| **TIMG**（通用） | 最多 8 个 | 16/32 位 | PWM + 捕获 + 比较 + **编码器 QEI** |
| **TIMX**（基础） | 最多 4 个 | 16 位 | PWM + 捕获 + 比较 → 通用场景 |

## 编码器（QEI）怎么用

**只有 TIMG 支持 QEI**。能用的 TIMG 及对应引脚：

| TIMG 实例 | Phase A (CCP0) | Phase B (CCP1) |
|-----------|---------------|---------------|
| TIMG0 | PA14 | PA15 |
| TIMG1 | PA16 | PA17 |
| TIMG2 | PB18 | PB19 |
| TIMG6 | PB6 | PB7 |
| TIMG7 | PB8 | PB9 |
| TIMG8 | **PA29** | **PA30** |

SDK 自带 QEI 示例（直接打开就能用）：
```
D:\TI\mspm0_sdk_2_02_00_05\examples\nortos\LP_MSPM0G3507\driverlib\timg_qei_mode\keil\
```

示例里配的就是 **TIMG8 + PA29/PA30**。编码器接 PA29（A 相）和 PA30（B 相），旋转时读 `DL_TimerG_getQEIDirection()` 就知道正反转，LED 会跟着变化。

## 编码器接线

```
编码器                     G3507
 A相  ───→  PA29 (CCP0)
 B相  ───→  PA30 (CCP1)
 VCC  ───→  3.3V
 GND  ───→  GND
```

和 STM32 的编码器模式完全一样——两路正交信号进来，硬件自动计数，软件只管读方向和数值。

## 用户

在天猛星G3507上的分布呢

## 助手

SDK 示例用的是 PA29/PA30，但那是 **LQFP-64 封装** 的脚——天猛星的 **LQFP-48 根本没有 PA29 和 PA30**。

LQFP-48 上能用的 TIMG QEI 引脚：

| TIMG | Phase A | Phase B | 天猛星上是否可用 |
|------|---------|---------|----------------|
| **TIMG0** | PA14 | PA15 | ✅ 空闲 |
| **TIMG1** | PA16 | PA17 | ✅ 空闲 |
| TIMG6 | PB6 | PB7 | ✅ 空闲 |
| TIMG7 | PB8 | PB9 | ✅ 空闲 |
| ~~TIMG8~~ | ~~PA29~~ | ~~PA30~~ | ❌ 48脚没有 |

其他定时器引脚：

| 引脚 | 可用于 |
|------|--------|
| PA2-PA5 | TIMA0 4 路 PWM |
| PA6-PA9 | TIMX0、TIMG2 的 PWM/捕获 |
| PA12-PA13 | TIMG4 的 PWM |
| PB0-PB1 | TIMX1 的 PWM |
| PB2-PB3 | TIMG5、I2C1 |
| PB4-PB5 | TIMX2 的 PWM |

> 推荐用 **TIMG0 (PA14/PA15)** 接编码器，PA16/PA17 也没占用。天猛星板的 LED、按键、串口都没碰这些脚。

## 用户

如果我要接两个电机只需要做一个软件编码器是吗

## 助手

不是。"软件编码器"是指用 GPIO 中断计数，精度差、CPU 负载高，不推荐。

G3507 的 TIMG 有硬件 QEI——它自己计数，不占 CPU。**接两个带编码器的电机完全够用**：

| | 电机 1 | 电机 2 |
|---|---|---|
| **编码器 A 相** | PA14 (TIMG0) | PA16 (TIMG1) |
| **编码器 B 相** | PA15 (TIMG0) | PA17 (TIMG1) |
| **PWM 正转** | PA2 (TIMA0 CH0) | PA4 (TIMA0 CH2) |
| **PWM 反转** | PA3 (TIMA0 CH1) | PA5 (TIMA0 CH3) |

```
电机1编码器 ──→ PA14(CCP0) + PA15(CCP1)  ← TIMG0 硬件计数
电机2编码器 ──→ PA16(CCP0) + PA17(CCP1)  ← TIMG1 硬件计数
电机1 H桥   ──→ PA2(PWM) + PA3(PWM)     ← TIMA0 带死区
电机2 H桥   ──→ PA4(PWM) + PA5(PWM)     ← TIMA0 带死区
```

8 根线搞定两个电机。编码器数据硬件自动更新，CPU 只管读 `DL_TimerG_getQEICount()` 就行。

| **BIN2** | PA5 | 电机 B 方向 2 |
| **PWMB** | PA7 | 电机 B 速度 PWM |
| **AO1/AO2** | 电机 A 两端 | — |
| **BO1/BO2** | 电机 B 两端 | — |
