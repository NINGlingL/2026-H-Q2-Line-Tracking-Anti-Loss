## 助手

PA10 和 PA11 是 **串口 UART 引脚**（接 CH340 的 TX/RX），只能用来串口烧录，不能 SWD 调试。

SWD 调试需要 **PA19 (SWDIO)** 和 **PA20 (SWCLK)**——这两个是芯片的专用调试引脚，和 UART 完全独立。

**你再看一下板子，有没有另一组排针或焊盘，丝印标着以下任意一个：**

- `SWDIO` / `SWD` / `SWCLK`
- `PA19` / `PA20`
- `DIO` / `CLK`
- 或者板子边缘有 4 个未焊接的过孔/焊盘

拍个核心板正反面的照片？我帮你看。

**直接用手机数据线一头插电脑 USB，一头插核心板的 USB-C 口就行。**

你核心板上的 CH340 是**内置的**——USB-C 口插上电脑后，自动完成：

```
电脑 USB → USB-C → 板载 CH340 → PA10/PA11 (UART)
                         ↓
                     3.3V 供电
```

不需要额外接 CH340 模块。GND/PA10/PA11/3.3V 那排针是引出来给其他用途的（比如接外部串口设备），烧录用不上它们。
