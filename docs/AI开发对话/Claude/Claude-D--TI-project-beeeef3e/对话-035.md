## 助手

Keil 每轮编译前跑 SysConfig 会覆盖 uvprojx。不跟 XML 较劲了，你在 Keil **GUI** 里手动加：

1. **Project → Options for Target '...'**（或 Alt+F7）
2. 左侧 **C/C++ (AC6)** 标签
3. 中间 **Include Paths** 右侧点 `...`
4. 点新增 → 填入 `..\`
5. OK → OK
6. **F7**
