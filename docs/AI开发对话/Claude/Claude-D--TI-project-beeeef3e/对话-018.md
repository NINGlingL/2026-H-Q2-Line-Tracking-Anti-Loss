## 助手

COM9 只是 DAP-Link 的**串口**功能，不是调试功能。DAP-Link 有两个功能：

- **串口（COM9）** → 用来 printf 打印的
- **CMSIS-DAP 调试器** → 用来烧录的，应该以 HID 或 WinUSB 设备出现

跑一下看看设备管理器里到底有哪些东西：

## 助手

找到问题了！COM9 的硬件 ID 是 `VID:PID=C251:F001`——这是 DAP-Link 的 CMSIS-DAP 芯片，但 Windows 给它装了**串口驱动**而不是调试器驱动。CCS 需要 WinUSB 驱动才能识别它。

## 修复（3 分钟）

### 1. 下载 Zadig

打开浏览器 → https://zadig.akeo.ie/ → 下载 **Zadig 2.8**（或最新版）

### 2. 装 WinUSB 驱动

1. 运行 `zadig.exe`
2. 菜单 **Options → List All Devices**（必须勾！）
3. 下拉列表里找到 `USB 串行设备 (COM9)` 或 VID `C251` / PID `F001` 的设备
4. 右侧驱动选择框选 **WinUSB**
5. 点 **Replace Driver**

### 3. 验证

- 设备管理器里这个设备应该从"端口"消失，出现在 **通用串行总线设备** 下
- 重启 CCS → Debug As → 这次 CMSIS-DAP 应该出现了
