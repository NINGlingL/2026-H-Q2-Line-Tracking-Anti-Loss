## 助手

CCS **可以用** DAP-Link 烧录 MSPM0G3507，不需要 Keil。

你刚才卡住的原因只有一个：**Windows 把 DAP-Link 当成了串口设备（COM9），而不是调试器**。CCS 的 DebugServer 只认 WinUSB/HID 驱动的调试器，不认识串口驱动的设备。

你之前用 Zadig 如果已经把 COM9 那个 `C251:F001` 设备的驱动换成了 **WinUSB**，那么：

1. 设备管理器里它应该不再出现在"端口"下面
2. CCS 的 Debug As 会自动检测到 CMSIS-DAP

---
