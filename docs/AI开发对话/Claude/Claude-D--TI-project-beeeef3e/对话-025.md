## 编译烧录

1. F7 编译
2. F8 烧录（CMSIS-DAP）
3. USB-C 插电脑，串口助手开 COM 口、115200 波特率
4. 按一下复位键，串口会输出 8 个传感器的值：

```
x1:1,x2:0,x3:0,x4:1,x5:1,x6:0,x7:0,x8:0
```

`1` = 检测到黑线，`0` = 没检测到（白底/无反射）。

## 传感器 I2C 协议

| 项目 | 值 |
|------|---|
| I2C 地址 | **0x12** |
| 速度 | 400kHz (Fast) |
| 写寄存器 | 地址 0x01：发 `0x01` 进校准 / 发 `0x00` 退出 |
| 读传感器 | 地址 0x30：返回 8 位，每位对应一路传感器 |

## 助手

八路巡线模块用的是 **I2C 通信**，不需要 8 根线。总共就四根：

```
天猛星板          传感器模块
  PA0  ────→  SDA   (只此一根数据线，8路数据全走它)
  PA1  ────→  SCL
  3.3V ────→  VCC
  GND  ────→  GND
```

数据是打包成一个字节传过来的——寄存器 `0x30` 返回 1 个字节，**每一位代表一路传感器**：

```
返回字节:  b7  b6  b5  b4  b3  b2  b1  b0
           ↓   ↓   ↓   ↓   ↓   ↓   ↓   ↓
传感器:    1   2   3   4   5   6   7   8
```

所以传感器 1~8 的数据是**通过同一根 PA0 线传进来的**，不需要分别接线。
