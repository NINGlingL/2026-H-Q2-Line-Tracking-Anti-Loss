## 用户

GPIO的接口的上拉电阻和下拉电阻到底有什么区别

## 助手

一个很简单的理解方式：

---

## 一句话

| | 上拉 | 下拉 |
|---|---|---|
| 电阻接在哪 | 引脚 → **VCC (3.3V)** | 引脚 → **GND** |
| 不按/不接时 | 读到 **高电平 (1)** | 读到 **低电平 (0)** |
| 按下/接通时 | 读到 **低电平 (0)** | 读到 **高电平 (1)** |

---

## 为什么需要

引脚悬空（什么都不接）时电压不确定，可能被电磁干扰搞得乱跳。接上拉/下拉电阻给它一个**默认电平**，就不乱跳了。

## 实例：按键接线

### 上拉接法（最常用）

```
3.3V
 │
 ├──[10kΩ 上拉电阻]──┐
 │                   │
 │              ┌────┤ 引脚 PA18
 │              │
 │           [按键]
 │              │
GND ────────────┘
```

- **没按按键**：引脚通过电阻被拉到 3.3V → 读到 **1**
- **按下按键**：引脚直接连 GND → 读到 **0**

```
3.3V
 │
 │              [按键]
 │                │
 │              ┌────┤ 引脚 PA18
