## 接线

板上的 SWD 排针，用杜邦线连 DAP-Link：

| DAP-Link | 天猛星板 SWD 口 |
|----------|-----------------|
| SWDIO | PA19 (SWDIO) |
| SWCLK | PA20 (SWCLK) |
| GND | GND |
| 3.3V | 3.3V（可不接，板子 USB-C 自供电） |

> ⚠️ **千万别用 ST-LINK！** 立创官方文档明确警告：ST-LINK 会锁死 MSPM0 芯片。

## CCS 里选烧录方式

板子 USB-C 供电 + DAP-Link 插电脑后：

1. 右键工程 → **Debug As → Debug Configurations…**
2. 左侧选你的工程 → 右侧 **Target** 标签页
3. 在 **Connection** 下拉里找 **CMSIS-DAP** 或 **DAP-Link**
4. 如果没有，点旁边的 **Auto-detect** 让它自动搜索
5. 选好后点 **Debug**

如果 Connection 列表里根本没有 CMSIS-DAP 选项，告诉我截图，我帮你手动写 `.ccxml`。

## 用户

我的DAP烧录器一边是C口一边是3.3 clk dio gnd我是使用手机数据线连接dap然后对应四根针脚插3507吗

## 助手

对。接线如下：

```
DAP-Link (烧录器)        天猛星 G3507 (开发板)
┌──────────────┐         ┌──────────────┐
│   USB-C ←──手机数据线──→ 电脑 USB       │
│              │         │              │
│   3.3V ──────────────→ 3.3V (可跳过)  │
│   GND  ──────────────→ GND           │
│   CLK  ──────────────→ SWCLK         │
│   DIO  ──────────────→ SWDIO         │
└──────────────┘         └──────────────┘
                              ↑
                         USB-C → 手机数据线 → 电脑 (供电)
```

> DAP-Link 用一根手机数据线连电脑，开发板用另一根 USB-C 供电。两根线都插电脑上。

天猛星板上的 SWD 排针丝印应该标着 `SWCLK` / `SWDIO` / `GND` / `3.3V`，一一对应接上就行。接好后 CCS 里 Debug As，选 CMSIS-DAP。
