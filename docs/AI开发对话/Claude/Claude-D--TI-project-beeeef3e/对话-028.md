### 3. main.c 调用

```c
#include "ti_msp_dl_config.h"
#include "ssd1306.h"

int main(void)
{
    SYSCFG_DL_init();
    SSD1306_Init();                            // 初始化
    SSD1306_ShowString(0, 0, "Hello G3507!");  // 第0行显示
    SSD1306_Update();                           // 刷新屏幕
    while (1);
}
```

| API | 功能 |
|-----|------|
| `SSD1306_Init()` | 初始化 OLED |
| `SSD1306_Clear()` | 清缓冲区 |
| `SSD1306_ShowString(page, col, "文字")` | 显示英文 |
| `SSD1306_ShowNum(page, col, num, 宽度)` | 显示数字 |
| `SSD1306_DrawPixel(x, y, 颜色)` | 画点 |
| `SSD1306_Update()` | 把缓冲区刷到屏幕 |

## 助手

看到了。这是 SysConfig 界面。按以下步骤：

**1. 左侧 "TI DRIVERLIB" 下面，点 I2C 旁边的 `＋`** → 添加一个 I2C 实例

**2. 右边 I2C 配置面板**，按这个填：

| 配置项 | 选什么 |
|--------|--------|
| **Name** | `I2C_0` |
| **Peripheral** | `I2C0` |
| **Controller / Target** | 勾选 **Controller**（主机） |
| **Bus Speed** | **Fast (400kHz)** |

**3. 引脚配置**，点 PinMux 区域：

| 引脚 | 分配 |
|------|------|
| **SDA** | `PA0` |
| **SCL** | `PA1` |

**4. Ctrl+S 保存**

SysConfig 会自动生成 `ti_msp_dl_config.c/h`，里面就有 `I2C_0_INST` 给你用。
