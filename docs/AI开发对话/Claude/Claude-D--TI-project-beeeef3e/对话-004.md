## 助手

`.ccxml`（调试配置）是对的，问题不在调试这边。报错出在**编译系统**——CCS 的 managed build 不认识 `MSPM0G3507`，因为它不知道去哪个 SDK 里找这个芯片的编译参数。

## 第一步：切换工作区

在 CCS 里：

1. 菜单 **File → Switch Workspace → Other…**

2. 弹窗里填（或点 Browse 选）：
   ```
   D:\TI_project\workspace
   ```
3. 点 **Launch** → CCS 自动重启，工作区就切过去了

> 以后启动 CCS 都会默认用这个工作区，不用再改。你在 `C:\Users\16484\workspace_ccstheia` 里的老工程不会丢，只是不在当前工作区显示了。想切回去的话同样操作填老路径就行。

---

## 第二步：从零新建工程

重启后，确认一下 MSPM0 SDK 是否已注册──

**Window → Preferences → Code Composer Studio → Products**，看列表里 MSPM0 SDK 有没有打勾。没有的话 Add 指向 `D:\TI\mspm0_sdk_2_11_00_07`，Apply and Close。

然后开始新建：

### 1. File → New → CCS Project

| 字段 | 填什么 |
|------|--------|
| **Project name** | 起个名字，比如 `blinky_pa0` |

### 2. Project templates and examples

这个页面会列出可用模板。在顶部的筛选框里操作：

- **Device / Board filter**：直接敲 `MSPM0G3507`，下拉列表里选 **MSPM0G3507**（不是 LP_MSPM0G3507）
