## MSPM0G3507 串口通信

### 硬件

G3507 有 4 个 UART。天猛星板上 CH340 已经接好了：

| 功能 | 引脚 | 连到 |
|------|------|------|
| TX（发） | **PA11** | CH340 RX → USB-C → 电脑 |
| RX（收） | **PA10** | CH340 TX → USB-C → 电脑 |

一根 USB-C 线插电脑，既是供电又是串口。和 STM32F103 用 PA9/PA10 接 CH340 一模一样。

### SysConfig 配置

加 UART 实例：

| 配置项 | 值 |
|--------|---|
| **Name** | `MYUART` |
| **Peripheral** | UART0 |
| **TX Pin** | PA11 |
| **RX Pin** | PA10 |
| **Baud Rate** | 115200 |
| 中断 | 勾选 RX（接收中断） |

### 代码

```c
#include "ti_msp_dl_config.h"
#include <stdio.h>

/* printf 重定向到串口 */
int fputc(int ch, FILE *f) {
    DL_UART_transmitDataBlocking(MYUART_INST, (uint8_t *)&ch, 1);
    return ch;
}

int main(void)
{
    SYSCFG_DL_init();

    printf("Hello MSPM0!\r\n");   // 串口输出

    while (1) {
        uint8_t rx_byte;
        /* 阻塞接收一个字节 */
        DL_UART_receiveDataBlocking(MYUART_INST, &rx_byte, 1);
        printf("收到: %c\r\n", rx_byte);
    }
}
```

### vs STM32 对比

| 操作 | STM32 HAL | MSPM0 DriverLib |
|------|-----------|-----------------|
| 发送 | `HAL_UART_Transmit(&huart1, buf, len, timeout)` | `DL_UART_transmitDataBlocking(UART, buf, len)` |
| 接收 | `HAL_UART_Receive(&huart1, buf, len, timeout)` | `DL_UART_receiveDataBlocking(UART, buf, len)` |
| printf 重定向 | 重写 `__io_putchar` 或 `fputc` | 重写 `fputc`（一样） |
| 波特率 | CubeMX 里设 | SysConfig 里设 |

用法几乎一样，只是函数名换了。

## 助手

这个 MPU6050 驱动库功能非常完整，不仅仅是"读传感器"，而是一整套姿态+控制方案：

## 功能总览

### 一、底层

| 功能 | 实现 |
|------|------|
| **I2C 通信** | 读写寄存器，连续多字节读取 |
| **地址** | 0x68 |

### 二、传感器基础

| 功能 | 函数 |
|------|------|
| **初始化** | `MPU6050_Init()` — 唤醒 + 验证 WHO_AM_I + 配置量程/滤波器 |
| **读取原始值** | `MPU6050_ReadAccelRaw()` / `ReadGyroRaw()` / `ReadTempRaw()` |
| **读取工程值** | `MPU6050_ReadData()` — 直接输出 g、deg/s、°C |

### 三、校准

| 功能 | 函数 |
|------|------|
| **零偏校准** | `MPU6050_Calibrate(samples)` — 传感器**静止水平放置**，自动计算陀螺和加速度计零偏 |
| **校准后读取** | `MPU6050_ReadDataCalibrated()` — 自动减零偏，**Z 轴陀螺带温漂补偿** |

### 四、姿态解算（核心）

| 方案 | 函数 | 用途 |
|------|------|------|
| **加速度计直接算** | `MPU6050_GetAttitude()` | Roll/Pitch，静止时准 |
| **Mahony 四元数** | `MPU6050_QuaternionUpdate()` | 加速度+陀螺融合，Roll/Pitch/Yaw |
| **Mahony 轻量版** | `MPU6050_QuaternionUpdateFast()` | 只读陀螺仪，不读加速度计，巡线时用 |
| **互补滤波 Yaw** | `MPU6050_ComplementaryFilterUpdate()` | Z 轴陀螺积分，用于纯航向角跟踪 |
| **获取欧拉角** | `MPU6050_GetEuler()` | 输出 Roll/Pitch/Yaw |

### 五、角度 PID 转弯控制

| 功能 | 函数 |
|------|------|
| **初始化 PID** | `MPU6050_AnglePID_Init()` |
| **设置目标角度** | `MPU6050_AnglePID_SetTarget(90.0f)` |
| **PID 计算** | `MPU6050_AnglePID_Calculate()` → 输出差速值 |
| **阻塞式转弯** | `MPU6050_TurnAngle(90.0f, 200)` — 自动转 90° 后停车 |

```c
/* 1. 初始化 */
MPU6050_Init();
MPU6050_Calibrate(200);  // 传感器保持静止

/* 2. 定时调用（1ms 周期） */
