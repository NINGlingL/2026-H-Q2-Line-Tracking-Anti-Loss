## 助手

改回来了，但还是不亮。I2C 通信需要一个常见的东西——**外部上拉电阻**。

很多 OLED 模块不自带上拉电阻，MSPM0 的内部上拉又太弱。拿两个 **4.7kΩ**（或 2.2k~10k 之间的都行）：

```
3.3V ──[4.7kΩ]──┬── SDA (PA0)
                  │
3.3V ──[4.7kΩ]──┬── SCL (PA1)
```

没有电阻的话也可以用 2 个 **10kΩ** 凑合。加了之后重新上电，应该就亮了。

## 用户

不是我电灯的时候PA0就很暗，所以是板子本身问题？

## 助手

不是板子问题。I2C 和点灯是两个完全不同的模式：

| | LED 点灯 | I2C 通信 |
|---|---|---|
| 引脚模式 | 推挽输出 | **开漏输出** |
| 需要外部上拉？ | 不需要 | **必须！** |

I2C 是开漏输出——引脚只能拉低不能拉高，高电平全靠外部上拉电阻拉到 3.3V。**没有外部上拉电阻，SDA 和 SCL 永远在高阻态，不会有正常通信。**

你必须有这两个电阻：

```
3.3V ──[4.7kΩ]──┬── SDA (PA0)
3.3V ──[4.7kΩ]──┬── SCL (PA1)
```

天猛星板上 PA0 旁边不一定有预留的电阻位，你得自己用两个电阻飞线接上。没有电阻 I2C 不可能工作——STM32 也是一样的。
