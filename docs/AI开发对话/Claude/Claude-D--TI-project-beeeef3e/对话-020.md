## 助手

CS_DAP_0 是芯片内部的调试端口，不是 DAP-Link 本身。报错的意思是 CCS 正试图通过 **XDS110 驱动**跟它通信，自然找不到 XDS110 硬件。

问题出在 `.ccxml` 里硬编码了 XDS110 驱动。DAP-Link 需要不同的协议。让我搜一下 CCS 有没有 CMSIS-DAP 相关的驱动文件。

## 助手

CCS 20.5 **不支持 CMSIS-DAP**。它只认 TI 自家的 XDS110/XDS200 和 Segger J-Link。你的 DAP-Link 在 CCS 里用不了。

## 三条路

| 方案 | 怎么搞 | 花钱 |
|------|--------|------|
| **继续串口烧录**（最快） | UniFlash → BSL → hex 文件，已经成功过一次 | 0 |

## 三种可行方案

### 方案一：纯 CCS + BSL 串口烧录（0 元，已经跑通）

```
CCS 写代码 → CCS 编译 → tiarmobjcopy 转 hex → UniFlash BSL 烧录
```
就是你现在已经成功过的流程。缺点是每次都要转一次 hex、开 UniFlash、不能单步调试。

### 方案二：纯 Keil（DAP-Link 直接能用，立创官方推荐）

```
Keil 写代码 → Keil 编译 → 一键下载到芯片（DAP-Link）
```
Keil 原生支持 DAP-Link，能用硬件断点、单步调试。立创天猛星的官方教程就是用 Keil。免费版限制 32KB 代码——G3507 有 128KB Flash，但入门阶段 32KB 够用了。

### 方案三：CCS 编译 + Keil 烧录（别扭，不推荐）

CCS 的项目文件 Keil 不认，没法直接拿 CCS 工程去 Keil 烧。手动导来导去很麻烦。
