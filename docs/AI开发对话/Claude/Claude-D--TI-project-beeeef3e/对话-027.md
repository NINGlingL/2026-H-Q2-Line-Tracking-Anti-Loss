## 助手

MSPM0G3507 有 **2 个 I2C**：

| I2C 模块 | 默认 SDA | 默认 SCL | 可复用引脚 |
|----------|---------|---------|-----------|
| **I2C0** | PA0 | PA1 | PB2/PB3, PA10/PA11 |
| **I2C1** | PB2 | PB3 | PA5/PA6, PA13/PA14 |

你的巡线传感器项目用了 **I2C0**：

```
SDA → PA0
SCL → PA1
```

两个 I2C 可以同时用，互不冲突——比如 I2C0 接巡线传感器，I2C1 接 OLED 屏幕。

## 你需要准备的东西

### 硬件

| 东西 | 说明 |
|------|------|
| 0.96寸 OLED 模块 | 4 脚 I2C 版（VCC/GND/SCL/SDA），芯片是 **SSD1306** |
| 4 根杜邦线 | 母对母 |

### 接线

```
天猛星板          OLED 模块
  PA0 (SDA)  →  SDA
  PA1 (SCL)  →  SCL
  3.3V       →  VCC
  GND        →  GND
```

> I2C 地址默认 **0x3C**（模块背面如果焊了电阻改地址才是 0x3D）

### 软件

SDK 里有 I2C 基础示例，从这里开始：

| 示例 | 位置 |
|------|------|
| **I2C 主机轮询收发**（推荐） | `i2c_controller_rw_multibyte_fifo_poll/keil/` |

这个示例教你怎么用 I2C 发数据——SSD1306 本质上就是通过 I2C 往它寄存器里写命令和数据。有了 I2C 基础通信，加上 SSD1306 的初始化序列和字库，屏幕就亮了。

## 怎么用

### 1. SysConfig 配 I2C

双击 `.syscfg` → 添加 I2C → 取名 **I2C_0**：

| 配置项 | 值 |
|--------|-----|
| SDA 引脚 | **PA0** |
| SCL 引脚 | **PA1** |
| 模式 | **Controller**（主机） |
| 速度 | **Fast (400kHz)** |

### 2. 添加源文件

把 `ssd1306.c` 加入 Keil 工程 Source Group，include 路径加上 `D:\A嵌入式\资料库\3507外设驱动库`
