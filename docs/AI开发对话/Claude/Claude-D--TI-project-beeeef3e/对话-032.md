## SysConfig 设置

### 1. 添加 PWM 定时器（TIMX 或 TIMG）

添加一个 **TIMX**（或 TIMG）→ 取名 `TIMER_0`：

| 配置项 | 值 |
|--------|---|
| **Mode** | PWM Edge-Aligned |
| **Prescaler** | 640 |
| **Period** | 100 |
| **CCP0 引脚** | **PA6**（电机 A PWM） |
| **CCP1 引脚** | **PA7**（电机 B PWM） |

### 2. 添加 GPIO 输出

添加 GPIO → 5 个引脚全配成 **Output**：

| 名称 | 引脚 | 用途 |
|------|------|------|
| AIN1 | PA2 | 电机 A 方向 1 |
| AIN2 | PA3 | 电机 A 方向 2 |
| BIN1 | PA4 | 电机 B 方向 1 |
| BIN2 | PA5 | 电机 B 方向 2 |
| STBY | PA12 | 待机控制 |

## main.c 里调用

```c
#include "ti_msp_dl_config.h"
#include "motor.h"

int main(void)
{
    SYSCFG_DL_init();
    Motor_Init();

    MotorA_SetSpeed(50);   /* 电机 A 50% 正转 */
    MotorB_SetSpeed(-30);  /* 电机 B 30% 反转 */
    delay_cycles(64000000); /* 2 秒 */

    Motor_Stop();
    while(1);
}
```
