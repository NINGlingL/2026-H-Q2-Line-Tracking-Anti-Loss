## 助手

ST-LINK 可以用，但它默认是 STM32 的调试器，CCS 不认。你有两个选择：

## 方案一：花 15 元买 DAP-Link（推荐）

淘宝搜 **CMSIS-DAP** 或 **DAP-Link**，十几块钱包邮。到货后：

```
DAP-Link 端         核心板 SWD 端
3.3V          →     3.3V
GND           →     GND
SWCLK         →     SWCLK
SWDIO         →     SWDIO
```

USB 插电脑，CCS 自动识别，右键工程 → Debug As → 选 CMSIS-DAP → 下载完成。

这是最省心的方案。ST-LINK 留着以后玩 STM32 再用。

---

## 方案二：把 ST-LINK 变身为 J-Link（免费，现在就能试）

ST-LINK v2 的硬件和 J-Link OB 几乎一样，Segger 官方有转换工具：

1. 去 [segger.com](https://www.segger.com/downloads/jlink/) 下载 **J-Link Software and Documentation Pack**，装到电脑上

2. 安装目录里找到 `JLinkSTM32.exe` 或搜索 **STLinkReflash**，运行

3. 它会把你的 ST-LINK 固件刷成 **J-Link OB**（可逆，有工具能刷回去）

4. 刷完后，CCS 就把它当成 J-Link 来用——CCS 原生支持 J-Link

5. 接线同上，CCS 里 Debug As → 选 **J-Link** → 下载

> 刷固件有极小的变砖风险，但网上教程很多，基本很安全。

好，那就搞。按这个步骤来：

## 第一步：下载官方 STLinkReflash

打开浏览器，去 Segger 官网：
```
https://www.segger.com/downloads/jlink/
```

往下翻找到 **J-Link Software and Documentation Pack**，下载最新的 Windows 版本（约 50MB）。

装好之后，安装目录里会有 `STLinkReflash.exe`。

## 第二步：识别你的 ST-LINK

1. ST-LINK 插上 USB，连电脑
2. 打开 Windows 设备管理器（Win+X → 设备管理器）
3. 展开 **通用串行总线设备**，看有没有 **ST-LINK** 字样

## 第三步：刷固件

1. 运行 `STLinkReflash.exe`
2. 它会自动检测你的 ST-LINK 型号和版本
3. 如果能识别，点 **Convert to J-Link** 或类似按钮
4. 等待进度条走完，提示成功

> 如果工具提示 **"Unknown ST-LINK"** 或 **"Not supported"** → 说明你的 ST-LINK 是克隆版，不兼容，**不要强行刷**，此时放弃，别冒险。
