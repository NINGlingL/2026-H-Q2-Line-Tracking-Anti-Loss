## 助手

QEI 在 SysConfig 里是**独立模块**，不是 PWM 的子功能。

## SysConfig 操作

点左侧 **`+`** → 选 **QEI**（不是 PWM）→ 取名：

| | 电机 A 编码器 | 电机 B 编码器 |
|---|---|---|
| **QEI 实例名** | `QEI_0` | `QEI_1` |
| **绑定的 TIMG** | TIMG0 | TIMG1 |
| **Phase A (CCP0)** | **PA14** | **PA16** |
| **Phase B (CCP1)** | **PA15** | **PA17** |
| **中断** | 勾选 | 勾选 |

## 接线

```
电机A 编码器           G3507
  A相 ────→ PA14 (TIMG0 CCP0)
  B相 ────→ PA15 (TIMG0 CCP1)

电机B 编码器           G3507
  A相 ────→ PA16 (TIMG1 CCP0)
  B相 ────→ PA17 (TIMG1 CCP1)
```

## 代码里读取速度

```c
/* 初始化 */
DL_TimerG_startCounter(QEI_0_INST);
DL_TimerG_startCounter(QEI_1_INST);

/* 读编码器值（硬件自动计数，不占 CPU） */
int32_t encA = DL_TimerG_getQEICount(QEI_0_INST);
int32_t encB = DL_TimerG_getQEICount(QEI_1_INST);

/* 读方向 */
uint8_t dirA = DL_TimerG_getQEIDirection(QEI_0_INST); // DL_TIMER_QEI_DIR_UP / _DOWN
```

编码器是纯硬件计数——TIMG 收到 AB 相脉冲自动加减，CPU 只管定时读数值。
