## 在 Keil 里新建 MSPM0 工程

1. 打开 Keil（`D:\Keil\keil\UV4\UV4.exe`）

2. **Project → New uVision Project**

3. 存到 `D:\TI_project` 下，文件夹起名比如 `keil_test`

4. 弹窗 **Select Device** → 搜 `MSPM0G3507` → 选它 → OK

5. 弹出 **Manage Run-Time Environment** → 勾选：
   - **CMSIS → CORE**
   - **Device → Startup**
   - **Device → DriverLib**

6. OK，工程建完。右键 Source Group → Add New Item → 新建 `main.c`

去试试，先从第 1 步做到第 4 步，看能不能找到芯片。
