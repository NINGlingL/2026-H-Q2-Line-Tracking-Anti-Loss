## 第三步：配置 PA0 引脚

1. 双击 `.syscfg` → 打开 SysConfig
2. 左侧 **GPIO** → 点 `+` 添加一个 GPIO 实例
3. 右侧 **Pins** 区域 → 点 `Add` → 搜 `PA0` → 选它
4. 方向选 **Output**
5. 保存（Ctrl+S）→ SysConfig 自动生成 `ti_msp_dl_config.c` / `.h`

## 第四步：写点灯代码

打开 `main.c`（或新建的 `empty.c`），替换为：

```c
#include "ti_msp_dl_config.h"

#define DELAY (16000000)  /* 约 0.5 秒 */

int main(void)
{
    SYSCFG_DL_init();

    while (1) {
        delay_cycles(DELAY);
        DL_GPIO_togglePins(GPIO_GPIO_0_PORT, GPIO_GPIO_0_PIN);
        /* ↑ SysConfig 默认把第一个 GPIO 实例命名为 GPIO_0 ↑      */
        /*   如果不确定名字，打开 ti_msp_dl_config.h 搜 "PORT" 确认 */
    }
}
```

## 助手

你说得对，CCS 的"新建"其实就是选芯片 → 选模板，没有真正从零开始。**但 `Empty` 模板就等于从零开始**——它只有一个空 `main.c` 和一张白板 `.syscfg`，你可以完全自己决定怎么写。

现在的问题是你可能没看到 `Empty` 模板——如果 MSPM0 SDK 没注册，模板列表就不会出现 MSPM0 的项（或者只剩 LaunchPad 板级的）。

## 先修 SDK 注册

在 CCS 里：

1. **Window → Preferences**
2. 左侧 **Code Composer Studio → Products**
3. 点 **Refresh**，看列表里有没有 `MSPM0 SDK`
   - **没有** → 点 **Add**，选 `D:\TI\mspm0_sdk_2_11_00_07`
4. 确保 **MSPM0 SDK** 前打勾 ✅
5. **Apply and Close**
6. 重启 CCS

## 再新建

1. **File → New → CCS Project**
2. Project name 填 `blinky_pa0`
3. 芯片筛选框输入 `MSPM0G3507`，选 **MSPM0G3507**（纯芯片，不是 LP_ 的）
4. 底下模板列表应该会出现：

   | 模板名 | 用途 |
   |--------|------|
   | **Empty (with SysConfig)** | 空工程 + SysConfig ⭐ 选这个 |
   | `Empty` | 纯空工程 |

5. 选 **Empty (with SysConfig)** → Finish
