## 第一步：接线

看你的核心板，找到 **4 针或 5 针的排针**，丝印一般标着：

| 核心板丝印 | 接 DAP-Link 哪根 |
|-----------|-----------------|
| **3.3V** 或 **VCC** | 3.3V |
| **GND** | GND |
| **SWCLK** 或 **SCK** 或 **TCK** | SWCLK |
| **SWDIO** 或 **SDA** 或 **TMS** | SWDIO |

如果丝印标的不是功能名而是引脚名，那就认准 **PA20 = SWCLK**、**PA19 = SWDIO**。

> 接线顺序：先接 GND → 再接信号线 → 最后接 3.3V。通电后不要带电拔插 SWD 线。

**同时也把 USB-C 线插上核心板供电。**
