## 用户

源码和库有什么区别

## 助手

DriverLib 是 TI 写好的硬件驱动库（`DL_GPIO_xxx`、`DL_UART_xxx` 这些函数就来自它）。

| | **源码版** `driverlib_src` | **库版** `driverlib_library` |
|---|---|---|
| 驱动代码 | `.c` 源文件，和你的代码一起编译 | 预编译好的 `.a` 静态库 |
| 编译速度 | 首次慢（要编译整个库），之后只编译改过的 | 快（不用编译库本身） |
| 调试时 | **能跳进 `DL_GPIO_togglePins` 里面单步看** | 不能，库函数是黑盒 |
| 能改驱动吗 | 能 | 不能 |

## 选哪个

**选源码版（`empty_driverlib_src`）**。你是新手，调试时能跳进 `DL_GPIO_togglePins()` 里面单步执行、看寄存器变化，这个比快几秒编译重要得多。代码体积和速度在单片机上都一样，只是编译快慢的区别。

## 助手

不是 Compiler Discovery Path——那个是给编译器用的。你需要的是 **Product Discovery Path**，两个是不同的东西。

在 **Window → Preferences → Code Composer Studio → Products** 页面：

- **Compiler Discovery Path**：指向编译器（你的已经配好了，`D:\TI\ti_cgt_arm_llvm_4.0.2.LTS`）
- **Product Discovery Path**：指向 SDK（**这个才需要加**）

你需要在 **Product Discovery Path** 那部分：

1. 点 **Add…**
2. 选 `D:\TI`（或者直接选 `D:\TI\mspm0_sdk_2_11_00_07`）
3. 点 **Refresh** 按钮
4. 下面列表应该会出现 `MSPM0 SDK 2.11.00.07`
5. 打勾 ✅ → Apply and Close

别动 Compiler Discovery Path——那个是好的。只加 Product Discovery Path。
