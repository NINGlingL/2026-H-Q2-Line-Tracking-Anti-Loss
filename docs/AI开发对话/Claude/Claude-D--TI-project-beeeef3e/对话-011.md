## 用户

我已经有了program你说的老固件是什么，而且我已经买了还没到而已

## 助手

"老固件"指的是 ST-LINK 出厂时的旧版固件——具体就是 2019 年之前、能被 `STLinkReflash` 识别的版本。

坦白说：ST 官网上找不到老固件下载，只能去第三方论坛碰运气。而且刷固件的过程是：

1. 拆开 ST-LINK 外壳
2. 短接某个引脚让芯片进 DFU 模式
3. 用 STM32CubeProgrammer 烧录老固件
4. 拼运气——老固件可能根本不兼容你这一批次的硬件

**你已经买了 DAP-Link，这件事就别再纠结了。** ST-LINK 安安静静留着以后玩 STM32，MSPM0 用 DAP-Link，各干各的。

到货前你可以做的事：把工程编译通过，SysConfig 配好，代码调通——等 DAP-Link 一到，插上就能烧录。比现在花一晚上跟 ST-LINK 较劲有意义得多。

## 用户

那我下的JLINK V960是干什么的

## 助手

那个是 J-Link **硬件**的 PC 端驱动和工具集，不是刷固件用的。

| 文件 | 干什么的 |
|------|----------|
| `JLink.exe` | J-Link 命令行调试器 |
| `JFlash.exe` | 用 J-Link 烧录芯片 |
| `JLinkGDBServer.exe` | GDB 调试服务器 |
| `JLinkRTTViewer.exe` | 实时终端调试 |

**没有 J-Link 硬件，这套软件什么也干不了。** 就像你有打印机驱动但没有打印机。

DAP-Link 不需要这套东西——CCS 直接通过 CMSIS-DAP 协议和它通信，到货后插上就能用。J-Link V960 这个文件夹你可以删了，或者留着以后真的买了 J-Link 硬件再用。
