## SysTick = 同一个东西

SysTick 是 **ARM 内核自带**的 24 位递减定时器，不是 TI 也不是 ST 设计的。F103（Cortex-M3）和 G3507（Cortex-M0+）都有，用法完全一样。

```c
// F103 和 G3507 都能用
SysTick_Config(32000);  // 1ms 中断 @ 32MHz
```

## 但滴答 ≠ 通用定时器

| | F103 | G3507 |
|---|---|---|
| **系统节拍** | SysTick (24位) | SysTick (24位) — 同一个 |
| **通用定时器** | TIM1, TIM2, TIM3, TIM4 | TIMx, TIMG, TIMA — 不同的外设 |

SysTick 一般只拿来做 `HAL_Delay()` 或 RTOS 心跳。做 PWM、输入捕获、编码器这些活的是通用定时器，那是 TI 自己的设计，和 STM32 的 TIM 不是同一个东西，API 不一样。

**简单记**：SysTick = 同一个人（ARM 给的），通用定时器 = 两家人（TI vs ST 各自设计）。

## 用户

所以滴答计时器和通用计时器不是一个东西？

## 助手

对。两个东西，各干各的：

| | SysTick（滴答） | 通用定时器 |
|---|---|---|
| **谁给的** | ARM 内核自带 | 芯片厂家设计的 |
| **位数** | 24 位 | 16 或 32 位 |
| **数量** | 每颗芯片 1 个 | 多个 |
| **能干嘛** | 只能定时中断 | 定时 + PWM + 输入捕获 + 编码器… |
| **用在哪** | `delay_ms()`、RTOS 心跳 | 电机控制、测频率、输出波形 |

SysTick 就是个只能计时的简单闹钟，通用定时器是瑞士军刀——什么都能干。
