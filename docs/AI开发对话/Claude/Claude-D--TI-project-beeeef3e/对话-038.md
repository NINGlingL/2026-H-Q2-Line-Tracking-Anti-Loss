## 助手

不能直接用，有两个依赖要解决：

**1. SysConfig 里 I2C 实例名必须是 `MPU6050_INST`**

驱动里写死了这个名字。SysConfig 里 I2C 实例改名即可。

**2. 需要两个时间函数**

驱动用到 `delay_ms()` 和 `Board_Millis()`，这两个不在驱动里。给你的工程加一个简单的实现：

```c
// 放到你的 main.c 或新建 board.c
volatile uint32_t g_ms = 0;

void delay_ms(uint32_t ms) {
    uint32_t start = g_ms;
    while ((g_ms - start) < ms);
}

uint32_t Board_Millis(void) {
    return g_ms;
}

// 在 SysTick 中断里每 1ms 调用
void SysTick_Handler(void) {
    g_ms++;
}
```

SysTick 在 SysConfig 里勾选 `SysTick → period = 32000, interrupt enable`。

---

除此之外，底层 I2C 通信、MPU6050 初始化、校准、姿态解算全部开箱即用。接线跟 OLED 共用 PA0/PA1。
