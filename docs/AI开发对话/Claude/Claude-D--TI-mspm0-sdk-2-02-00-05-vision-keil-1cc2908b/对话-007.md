## 🚀 立即测试

### 1. 编译下载
- 按 **F7** 编译
- 按 **F8** 下载到板子

### 2. 连接硬件
- **OLED**: PA0(SDA), PA1(SCL), VCC(3.3V), GND
- **串口**: PA11(RX) ← USB转TTL TX, GND ← GND

### 3. 打开串口工具测试
- 配置：**115200 bps, 8N1**
- 发送任意文本，例如：
  ```
  Hello World!
  This is a test.
  123456789
  ```
- OLED 会实时显示你发送的内容
