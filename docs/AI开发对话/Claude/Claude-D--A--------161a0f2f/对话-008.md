## 舵机行不行？— 算个数

摆杆 25cm，铰链在左端，球要动 ±5cm：

```
摆杆倾角 θ = arcsin(5/12.5) ≈ 23.6°
右端需要升降 = 25 × sin(23.6°) ≈ 10cm（上下各10cm，合计20cm）
```

舵机摆臂半径只有 **2~3cm**（标准圆盘臂），直接推右端：

```
右端升降 ±2cm → 倾角 ≈ 4.6° → 球动 ±1cm
```

**结论：舵机直接推右端，球只能动 ±1cm。**

- 第 4/5/6 项（球稳在目标点 ±1cm）→ ✅ 勉强够
- 第 3 项（球从 O 走到 +5cm 再走到 -5cm）→ ❌ 完全不够

## 怎么办？

**要么换丝杆步进，要么给舵机加杠杆放大。**

| | 丝杆+步进 | 舵机+杠杆放大 |
|---|---|---|

| 价格 | ~65元 | ~35元 |

**推荐丝杆步进。** 理由：拓展板上 STEP1/DIR1（A07/B00）和 STEP2/DIR2（B14/B10）四线步进口已经预留好了，买个 TMC2208 驱动 + T8 丝杆滑台模块直接插上就能用，一步到位搞定全部控球需求。

### 真正要关注的不是 T6/T8，是**导程**

同样 T6，导程不同速度差很多：

```
要求第3项: O → +5cm → -5cm，≤5秒
球总行程 15cm，折算右端约需升降 9cm

T6 导程 1mm: 90000μm÷1000μm×1转÷200步 = 450转 → 90000步
              @2000步/s = 45秒 ❌ 太慢

T6 导程 2mm: 450转 → @2000步/s = 22.5秒 ❌ 还是慢

T6 ×4mm导程: 225转 → @2000步/s ≈ 11秒 ❌

T8 ×8mm导程: 112转 → @2000步/s ≈ 5.6秒 ⚠️ 勉强
```

等一下——刚才那个 20cm 是**静态极端情况**。实际跑 PID 闭环时，摆杆只需要小幅快速修正，不用走满全程。

**重新算：**

第 3 项要球从 O 滚到 +5cm，需要的实际倾角约 10~15°，不是 23.6°（小于 23.6° 球就开始滚了）。右端升降约 4~6cm。

```
T6 导程 2mm，右端升 5cm:
50000μm÷2000μm = 25转 = 5000步
@2000步/s = 2.5秒 ✅
@3000步/s = 1.7秒 ✅ 有余量
```
