### 在 MSPM0G3507 上用（3 步）

```c
// 1. 获取 MSP 版 HAL (mpu6050_hal_msp.c 已经用 DL_I2C 写好了)
const mpu6050_hal_t *hal = mpu6050_hal_msp_get();

// 2. 初始化 (NULL = 默认配置)
MPU6050_Init(hal, NULL);

// 3. 校准 + 读数
MPU6050_Calibrate(200);

MPU6050_Data_t data;
MPU6050_ReadData(&data);

// 如果要转弯:
mpu6050_motor_t motor = { .set_motors = Car_SetMotors, .stop = Car_Stop };
MPU6050_TurnAngle(&motor, 90.0f, 200);  // 右转 90 度
```

### 移植到其他 MCU（STM32/ESP32/...）

只需实现 5 个回调函数，填进 `mpu6050_hal_t`：

```c
mpu6050_hal_t hal = {
    .i2c_write      = my_i2c_write,       // 你的 I2C 写寄存器
    .i2c_read       = my_i2c_read,        // 你的 I2C 读寄存器
    .i2c_read_burst = my_i2c_read_burst,  // 你的 I2C 连续读
    .delay_ms       = my_delay_ms,        // 你的毫秒延时
    .millis         = my_millis,          // 你的系统毫秒计数
};
```

`mpu6050.h` / `mpu6050.c` / `mpu6050_app.h` / `mpu6050_app.c` 四个文件**一行都不需要改**。
