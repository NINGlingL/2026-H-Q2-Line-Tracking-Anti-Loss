陀螺仪在 H 题里**不只是辅助，是好几个得分项的关键**。

---

### 用在哪

| 场景 | 怎么用 | 对应哪项 |
|------|--------|----------|
| **判断转弯** | 角速度突变 → 识别进入圆弧段 → 提前减速 | 第 2/4/5/6 项 |
| **计数圈数** | 航向角（yaw）积分满 360° = 一圈，精确停在 A 点 | 第 2/5/6 项 |
| **直线段稳航向** | 红外循迹管偏移，陀螺补充航向角 → 直线不蛇形 | 第 2 项 |
| **补偿离心力（关键）** | 测出实际转弯角速度 → 算离心力 → 预调摆杆倾角抵消 → **球不乱滚** | 第 4/5/6 项 |

---

### 尤其是离心力补偿，这是拉开分数的点

```
没有陀螺:
  车转弯 → 离心力把球甩出去 → 摄像头发现球偏了 → PID 调摆杆拉回来
  → 已经慢了，球已经偏过 1cm 了 ❌

有陀螺:
  车转弯 → 陀螺立刻测到角速度 → 提前计算离心力 → 提前调摆杆
  → 球还没偏就补偿好了 ✅
```

这是第 4/5/6 项（合计 60 分）的核心——**前馈补偿**，全靠陀螺仪。

---

### 还有一个

ICM20948 是 9 轴（3 加速度 + 3 角速度 + 3 磁力计），加速度计可以检测小车加减速的惯性力，同样可以前馈到摆杆控制——加速时摆杆前倾，减速时摆杆后倾，提前抵消惯性。

---

### 所以

你的 ICM20948 不是可选的传感器，是**控球精度的核心**。把它挂到 I2C 线上（跟 OLED 共用 A14/A15），别浪费。

之前说 SPI 的事——现在确定用 I2C 就行，OLED 地址 0x3C，ICM20948 地址 0x68，不冲突，一根总线两个设备。
