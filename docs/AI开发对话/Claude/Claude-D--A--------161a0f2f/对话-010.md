### 不过有一个小提醒

GX28 一体丝杆电机常见导程有 **2mm、4mm、8mm、12mm**。别买 8mm 或 12mm 导程的，虽然快但推力掉太多，而且对控球精度不利。**买 2mm 或 4mm 导程的。**

---

GX28 小、轻、便宜，很适合你的小车。确认导程是 2 或 4mm 就直接下单。

## 助手

### 力够不够？✅ 够

```
GX28 保持转矩 ≈ 0.1 N·m
T6 丝杆 螺距 1mm:

轴向推力 = 2π × 0.1 / 0.001 ≈ 628 N ≈ 64 kg

你的负载: 半管 + 钢球 + 摩擦力 ≈ 不到 1N
余量 600 倍，完全不担心。
```

### 速度够不够？⚠️ 勉强

```
球从 O → +5cm，需要摆杆倾斜约 3°~5°
右端升降 ≈ 1.5~2.5cm（不需要走满 10cm）

螺距 1mm = 转一圈走 1mm
两方向合计右端行程 ≈ 4~5cm = 40~50 转

GX28 @ 300 RPM → 5mm/s → 10秒  ❌ 超了
GX28 @ 500 RPM → 8.3mm/s → 6秒 ⚠️ 勉强
GX28 @ 600 RPM → 10mm/s → 5秒 ✅ 刚好
GX28 @ 800 RPM → 13mm/s → 3.8秒 ✅ 有余量
```

GX28 在 12V + TMC2208 驱动下跑 600~800 RPM 是没问题的，负载这么轻。

### 结论

| 参数 | 评价 |
|------|------|
| 直径 T6 | ✅ 够用 |
| 行程 100mm | ✅ 够了（实际用不到 10cm） |
| 螺距 1mm | ⚠️ 能用，但速度偏紧 |
| 螺距 2mm | ✅ 更保险（时间缩短一半） |

**还没买的话换 2mm 导程，已经买了就别换了**——1mm 也能用，就是步进电机转速要拉高一点。TMC2208 在 12V 供电下带 GX28 跑 600~800 RPM 没问题。

另外确认一下：这个 GX28 带不带螺母？螺母是黄铜的还是 POM 塑料的？黄铜耐磨但要加点润滑，POM 安静但精度差一点。

## 助手

对，螺距 2mm 比 1mm 好。区别很直观：

| | 螺距 1mm | 螺距 2mm |
|---|---|---|
| 转一圈走多少 | 1mm | **2mm** |
| 右端升降 2cm 需多少转 | 20 转 | **10 转** |
| 完成 ±5cm 控球 ≈ 需时 | ~5s（吃力） | **~2.5s**（从容） |
| 精度 | 0.005mm/步 | **0.01mm/步**（也远超需求） |
| 推力 | 64kg | 32kg（还是远超 1N 负载） |

> 2mm 螺距：速度快一倍，精度仍然远远超过 ±1cm 控球需求（差了 1000 倍），推力还是够的。

**结论：能选 2mm 就选 2mm，1mm 也能用但速度紧张。** 其他参数不变——T6 直径、100mm 行程、GX28 电机，只把螺距从 1mm 换成 2mm。
