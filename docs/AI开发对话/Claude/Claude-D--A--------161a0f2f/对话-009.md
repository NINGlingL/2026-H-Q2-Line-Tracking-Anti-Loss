```
                                              │
                                        接摆杆右端
```

**关键词 2：`微型直线丝杆滑台模组`**

带底座和导轨的成品，到手直接用，50~80 块。贵的不要看，找那种铝型材底座、小尺寸的。

**关键词 3：`42步进电机 T8丝杆 直线`**

42 步进（NEMA17）比 28 步进扭力大，配 T8 丝杆，最常见的 3D 打印机 Z 轴配置，50 块左右。

### 你看图认准这个结构就行

```
  ┌──────────┐     ┌─────┐     ┌═══════════┐
  │ 步进电机  │═════│联轴器│═════║ T8丝杆 ║─── 黄铜螺母 ─── 摆杆右端

      ↑                            ↑
   DIR+STEP                     螺母沿丝杆

   STEP1/DIR1
```

**要确认的规格：**
- 步距角 1.8°（200 步/转，标配）
- 导程 2mm 或 4mm（导程越大越快）
- 电压 12V（你电池直供）
- 带联轴器 + 黄铜螺母

### 驱动板另外买

丝杆套装一般不带驱动，需要单独买：**TMC2208** 或 **A4988** 步进驱动模块，淘宝搜 `TMC2208 步进电机驱动模块`，8~12 块一个。

```
G3507         TMC2208         步进电机
───────      ─────────       ────────
STEP1(A07) → STEP
DIR1(B00)  → DIR

             2B  → 电机A+
             2A  → 电机A-
             1A  → 电机B+
             1B  → 电机B-
```

拓展板上 STEP1（A07）/ DIR1（B00）已经预留好了，直接接 TMC2208 就行。

### 算一下力够不够

```
GX28 保持转矩 ≈ 0.06~0.12 N·m (看具体型号)
T8 丝杆导程 2mm:

轴向推力 = 2π × 转矩 / 导程
        = 2π × 0.06 / 0.002
        ≈ 188 N ≈ 19 kg 推力

你的负载: 半管 ~50g + 钢球 ~4g + 摩擦力 ≈ 不到 1N
```

> **结论：GX28 推力是你需求的 100 倍以上，绰绰有余。**
