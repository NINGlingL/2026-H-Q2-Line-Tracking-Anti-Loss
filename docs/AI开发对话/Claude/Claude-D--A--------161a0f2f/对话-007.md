题目要求：刻度间距 0.1cm，贴在凹槽剖面**边沿**（不是槽内）。

直接用 **0.1cm 间距的不锈钢直尺/标尺贴纸**，或者打印透明贴纸。淘宝搜"刻度尺贴纸"。

## 避坑提醒

1. **水管开槽**：用热风枪局部加热 230~250°C，用一个 φ10mm 钢棒压出弧形凹槽，不要用锉刀刮内壁（会被判违规）
2. **连杆长度**：舵机臂到摆杆右端的距离决定了角度行程，建议先做可调长度的（铜柱旋进旋出），调试完再锁死
3. **铰链虚位**：便宜的合页有间隙，建议挑紧一点的，或者在轴上套 O 型圈消除旷量
4. **舵机供电**：MG996R 堵转电流很大（~2A），建议单独从 5V 供电，不要跟 MCU 共用。拓展板的 5V 降压 TPS5450 是 5A 的，应该够，但舵机电源和 MCU 电源之间串个 LC 滤波防干扰

### 一句话原理

**舵机旋转 → 拉杆推/拉摆杆 → 摆杆倾斜 → 钢球在重力作用下滚动。**

---

### 关键结构

```
          铰链(固定，不动)
               │
               ├────────────────────────────┐
               │    25cm PPR水管凹槽        │  ← 钢球在里面滚
               └────────┬───────────────────┘
                        │
                   拉杆连接点         舵机
                  (距铰链~5cm)     ←→  (装在车板上)
                        │              ┌─┐
                        └──────────────┤○│ 圆盘臂
                                       └─┘
```

**为什么连接点不放在摆杆最右端？**

```
连在最右端(25cm):  舵机推±2cm → 倾角≈4.6° → 球位移仅±1cm   ❌ 不够
连在距铰链5cm处:   舵机推±2cm → 倾角≈23.6° → 球位移≈±5cm  ✅ 刚好
```

> 这是一个杠杆原理——连接点越靠近铰链，同样的舵机行程能产生更大的倾角变化。
