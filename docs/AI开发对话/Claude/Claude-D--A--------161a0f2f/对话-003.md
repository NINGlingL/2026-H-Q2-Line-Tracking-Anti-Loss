## 五、⚠️ 天猛星避坑要点

| 坑 | 说明 |
|----|------|
| **PA18 禁用** | 上电/复位时必须是低电平，绝对不能使用！ |
| **软件 I2C 引脚** | 只有 PB10/PB11 能稳定做开漏输出，最多两个 |
| **I2C 模块整合** | OLED 和 MPU6050 共用 I2C 总线，只保留一份底层驱动 |
| **I2C 地址** | OLED=0x3C, MPU6050=0x68，同总线靠地址区分 |
| **烧录器** | 推荐 J-Link 或 DAP-Link，ST-Link 容易锁芯片 |
| **浮点运算** | Keil O2 优化可能导致浮点异常，关键计算关闭优化 |

```
4. 参考 ZLC 国一小车方案

5. 你本地的 3507外设驱动库
   → 用我们已经通用化的 MPU6050 驱动 + SSD1306
```
