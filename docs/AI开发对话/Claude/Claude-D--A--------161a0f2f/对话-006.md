### ⚠️ ICM20948：强烈建议用 I2C

拓展板上 IMU 预留的是 UART（A25/A26），但 ICM20948 是 I2C/SPI 接口的，不是 UART。

**用 I2C（推荐）：**
- 直接挂到 OLED 同一路 I2C 总线上（A14 SDA / A15 SCL）
- 地址不冲突：OLED=0x3C，ICM20948=0x68
- **零额外引脚，不用改板子**
- 400kHz I2C 对 9 轴数据读取完全够用

**用 SPI（不推荐）：**
- 需要 4 根线（CS/MOSI/MISO/SCK）
- 板上空闲引脚只有 A27/B21/B22，不够四根
- 得飞线 + 软件 SPI，麻烦且不稳定

---

### 8路循迹模块的接口要确认

板子上 TRACK1~12 是 12 路独立的数字 IO，适合接你的 5 路**无 MCU** 模块。

但 8 路**带 MCU 数据处理**那个，它输出是什么接口？是 UART 还是直接把位置值发出来？如果是 UART，板子上蓝牙/摄像头/无刷/IMU 占满了 4 路，你需要腾一路出来——比如摄像头那路 UART1（B06/B07）可以先给循迹用。

你确认一下 8 路模块的通信方式，然后就可以开干了。

- 凹槽：内壁必须光滑，不准有凹坑/增摩擦改造

## 舵机 vs 丝杆 vs 步进 — 选哪个？

| | 舵机 + 连杆 | 丝杆滑台 + 步进 | 步进 + 直接驱动 |
|---|---|---|---|
| **精度** | 一般（死区~0.5°） | 高 | 高 |
| **响应速度** | 快（0.1~0.2s/60°） | 慢 | 中 |
| **重量** | 轻（~60g） | 重（~200g） | 中（~100g） |
| **自锁** | 无（断电松） | 有 | 有（保持转矩） |
| **复杂程度** | 简单 | 复杂 | 中等 |
| **对控球±1cm够不够** | ✅ 够用 | ✅ 过设计 | ✅ 够用 |
| **价格** | ~25元 | ~80元 | ~50元 |

### 建议：舵机 + 连杆（最简单且够用）

±1cm 钢球的位移误差对应的摆杆角度变化量并不大，数字舵机完全能胜任。电赛场上越简单越不容易翻车。
