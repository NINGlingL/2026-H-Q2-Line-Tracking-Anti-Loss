**moto 驱动库文件：**

| 文件 | 说明 |
|------|------|
| `moto.h` | TB6612 电机驱动库 API |

| `empty.c` | 主程序 (调用 moto 库) |

**API 速查：**

```c
Moto_Init();              // 初始化
Moto_Forward(80);         // 前进 80%
Moto_Backward(50);        // 后退 50%
Moto_Left(60);            // 左转 60%
Moto_Right(60);           // 右转 60%
Moto_Stop();              // 停止
Moto_SetSpeed(70);        // 保持方向, 改速度
Moto_SpeedUp(10);         // 加速 10%
Moto_SpeedDown(10);       // 减速 10%
Moto_SelfTest(callback);  // 开机自检
```

> 注意：TB6612 的 **STBY 引脚必须接高电平** (3.3V) 才能工作。如果 STBY 接到了某个 GPIO，告诉我引脚号，我在 `Moto_Init()` 里加上拉。
