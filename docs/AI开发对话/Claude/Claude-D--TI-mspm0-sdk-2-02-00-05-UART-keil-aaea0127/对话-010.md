# Claude-D--TI-mspm0-sdk-2-02-00-05-UART-keil-aaea0127（续）

## 用户

VM和相邻的GND是12V电源直接接对吗

## 助手

**对的。** 但有一个关键细节：

## 12V 电源连接

```
12V 电源正极 ────→ TMC2208 VM
12V 电源负极 ────→ TMC2208 GND (VM 旁边的那个)
```

### ⚠️ 但是必须注意两个 GND 要相连：

```
12V 电源负极 ──┬── TMC2208 GND
               └── MSPM0 GND ← 必须连！
```

TMC2208 的 **VIO GND** 和 **VM GND** 在模块内部是相通的，但如果你只接了 VM 电源而 **没有把 12V 的 GND 和 MSPM0 的 GND 连起来**，那么 MSPM0 发送的 STEP/DIR 信号就没有参考地，完全无法工作，甚至会损坏模块。

---

## 完整电源接线汇总

| 连接 | 引脚 → 引脚 |
|------|------------|
| 12V 正 | → TMC2208 **VM** |
| 12V 负 | → TMC2208 **GND** (VM 旁) |
| 12V 负 | → **MSPM0 GND** (共地, 关键!) |
| 3.3V | → TMC2208 **VIO** |
| 3.3V GND | → TMC2208 **GND** (VIO 旁) |

> 如果你的板子上 12V GND 和 3.3V GND 已经通过供电回路连在一起（比如用同一个电源适配器分压），那 VIO GND 和 VM GND 自动共地，不用额外跳线。但保险起见，**直接连一根 GND 线**最稳妥。

---

**一句话**：VM 接 12V 正，VM 旁边的 GND 接 12V 负，并且把 12V 负和主控板 GND 连起来。

## 用户

A+ A- B+ B-怎么连

## 助手

28BYJ-48 是 5 线步进电机，TMC2208 是 4 线双极驱动。接线如下：

## 28BYJ-48 → TMC2208 (A+ A- B+ B-)

| 28BYJ-48 线色 | TMC2208 端子 |
|:-:|:-:|
| **橙** | **A+** |
| **粉** | **A-**(橙粉是一组线圈 A) |
| **黄** | **B+** |
| **蓝** | **B-**(黄蓝是一组线圈 B) |
| **红** | **不接**(中心抽头，用胶带包好绝缘) |

> 线序可以交换（橙↔粉、黄↔蓝互换不影响，只是电机反转方向），关键是**必须成对**：橙+粉一组，黄+蓝一组。

---

## ⚠️ 一个重要警告

**28BYJ-48 和 TMC2208 的匹配问题：**

1. **28BYJ-48 是 5V 电机**，标称电流约 250mA（启动峰值 ~600mA）
2. **TMC2208 默认电流设置**（靠板上电位器）通常调到 1A+，直接驱动 28BYJ-48 会**烧电机线圈**

### 必须先调电流

TMC2208 板上的电位器（通常需要小螺丝刀调）：
- 把电流调到 **0.3~0.4A 左右**
- 标准公式：`I = Vref / (2.5 × R_sense)`
- 或简单方法：调到最小，然后慢慢加大，摸电机外壳**微温不烫**为准

---

## 另一种更稳妥的选择

28BYJ-48 本质是**单极 (unipolar) 电机**，更适合配 **ULN2003 驱动板**（那种配套卖的带板子的）。如果你用 TMC2208，虽然也能转，但电流匹配要小心。

**你确定要用 TMC2208 驱动 28BYJ-48 吗？** 还是你有别的步进电机？确认一下我再给你配置对应的 SysConfig 引脚。

## 用户

我是说和M1A M1B M2A M2B来说怎么接

## 助手

明白，TMC2208 板子上标的是 **M1A M1B M2A M2B**。接线如下：

## 28BYJ-48 → TMC2208 (M1A M1B M2A M2B)

| 28BYJ-48 线色 | TMC2208 端子 |
|:-:|:-:|
| **橙** | **M1A** |
| **粉** | **M1B** (橙+粉 = 线圈 1) |
| **黄** | **M2A** |
| **蓝** | **M2B** (黄+蓝 = 线圈 2) |
| **红** | **不接**(绝缘包好) |

---

**对应关系：**

```
M1A 橙 ────┐
M1B 粉 ────┘ 线圈1 (28BYJ-48 的 A 相)
M2A 黄 ────┐
M2B 蓝 ────┘ 线圈2 (28BYJ-48 的 B 相)
```

**判断哪两根是一组线圈的方法**：用万用表蜂鸣档，28BYJ-48 五根线中，橙-粉通、黄-蓝通、红-其他都通（红是中心抽头）。所以橙粉一组、黄蓝一组，别接混。

---

线序互换不影响工作，只会反转方向：
- 橙↔粉互换 → 电机反转
- 黄↔蓝互换 → 电机反转

如果需要方向反了，程序里调 DIR 引脚或者互换任意一组线即可。
