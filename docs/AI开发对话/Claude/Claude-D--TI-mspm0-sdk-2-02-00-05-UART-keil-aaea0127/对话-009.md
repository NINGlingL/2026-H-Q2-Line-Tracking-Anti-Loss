## 硬件接线

### TMC2208 → MSPM0G3507

| TMC2208 引脚 | MSPM0G3507 | 说明 |
|:-:|:-:|------|
| **VIO** | 3.3V | 逻辑电平 |
| **GND** | GND | 共地 |
| **VM** | 外部 12V | 电机电源 (独立供电) |
| **GND** | 电源 GND | 与 MSPM0 GND 相连 |
| **STEP** | PA12 (GPIO OUT) | 步进脉冲 |
| **DIR** | PA13 (GPIO OUT) | 方向 |
| **EN** | PA15 (GPIO OUT) | 使能(低有效) |
| **TX** | PA11 (UART0 RX) | UART 配置用 |
| **RX** | PA10 (UART0 TX) | UART 配置用 |

### 28BYJ-48 步进电机 → TMC2208

| 28BYJ-48 线 | TMC2208 |
|:-:|:-:|
| 红 | VM (12V) |
| 橙 | B2 |
| 黄 | B1 |
| 粉 | A1 |
| 蓝 | A2 |

## SysConfig 图形化配置

### 1. GPIO 配置 (步进控制)

**添加 GPIO Instance:**

```
GPIO1:
  - Name: STEP_PIN
  - Pin: PA12
  - Direction: OUTPUT
  - Initial Value: LOW

GPIO2:
  - Name: DIR_PIN
  - Pin: PA13
  - Direction: OUTPUT
  - Initial Value: LOW

GPIO3:
  - Name: EN_PIN
  - Pin: PA15
  - Direction: OUTPUT
  - Initial Value: HIGH (默认禁用)
```

### 2. UART 配置 (TMC2208 串口)

**已有 UART_3 改为 UART_0:**

```
UART Instance:
  - Name: UART_TMC
  - Peripheral: UART0
  - Baud Rate: 115200 (TMC2208 默认)
  - Data Bits: 8
  - Parity: None
  - Stop Bits: 1
  - TX Pin: PA10
  - RX Pin: PA11
```

### 3. TIMER 配置 (可选: PWM 生成步进脉冲)

如果用定时器自动生成 STEP 脉冲：

```
TIMER Instance:
  - Name: TIMER_STEP
  - Peripheral: TIMG0
  - Mode: PWM
  - Frequency: 1kHz (步进频率)
  - Duty: 50%
  - Output Pin: PA12 (与 STEP_PIN 复用)
```

## 电源注意事项

| 模块 | 电源 | 电流 |
|:-:|:-:|:-:|
| MSPM0 | 3.3V (ST-Link 或稳压) | ~50mA |
| TMC2208 VIO | 3.3V | ~10mA |
| TMC2208 VM | **独立 12V 1A** | 电机峰值 0.5A |
| 28BYJ-48 | 通过 TMC2208 | ~0.5A |

**关键**：VM (电机电源) 必须用独立 12V 适配器，不能用 MSPM0 的 3.3V！但 GND 必须全部相连。
