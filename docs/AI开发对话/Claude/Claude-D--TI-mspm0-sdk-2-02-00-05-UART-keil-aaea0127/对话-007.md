改好了，三个改动：

### 1. 字符过滤器 `Cmd_Read()`

只放行 15 个合法字符：`FfBbLlRrSs+-0123456789`，`\r` `\n` 和其他垃圾全部丢弃。

```c
static bool Cmd_Filter(uint8_t c)
{
    if (c == 'F' || c == 'f') return true;
    // ... 方向 5个
    if (c == '+' || c == '-' || c == '=' || c == '_') return true;
    if (c >= '0' && c <= '9') return true;
    return false;   // ← \r \n 空格 其他全部丢弃
}
```

### 2. 数字键不切方向

后退时按 `5` → 只设置速度 50%，保持后退方向。只有当前已停止时才切到前进。

```c
case '5': Moto_SetSpeed(50);           // 只调速
          if (Moto_GetDirection()=='S') // 停了才切方向
              Moto_Forward(50);
          break;
```

### 3. OLED 刷新节流

有指令立即刷，无指令约 50ms 一次，减少屏幕刷新对主循环的阻塞。

| 函数 | 用途 |

| `Control_Init()` | 初始化 |
