## 助手

**必须连接。**

任何串口通信（包括 HC-05 蓝牙模块）的 GND 必须和主控板共地，否则：

1. **电平参考不一致** → RX/TX 的高低电平阈值混乱 → 乱码/丢包/误触发
2. **浮空干扰** → 没有共地时 RX 引脚相当于悬空天线，会拾取环境噪声 → 你看到的 RX:665 就是这种噪声计数

---

**正确接线（HC-05 → MSPM0）：**

| HC-05 | MSPM0G3507 |
|:-:|:-:|
| VCC | 3.3V 或 5V (看模块) |
| **GND** | **GND (必须)** |
| TXD | PA22 (UART2 RX) |
| RXD | PA21 (UART2 TX) |

---

**问题定位**：
- 如果你现在没接 GND，先接上，RX 计数会归零或大幅减少
- 如果接了 GND 还是有大量噪声计数，检查 PA22/PA21 是否接反了（TX↔RX 要交叉）

## 助手

蓝牙模块供电不足有几个解决方案：

---

## 方案 1: 外部 5V 供电 + 共地（推荐）

```
USB 5V 电源 ──┬── HC-05 VCC
              └── HC-05 GND ───┐
                               ├── MSPM0 GND (共地)
主控板 3.3V ────────────────── MSPM0 VCC
              
HC-05 TX  ────────────────── PA22 (MSPM0 RX)
HC-05 RX  ────────────────── PA21 (MSPM0 TX)
```

**关键**：HC-05 和 MSPM0 用各自电源，但 **GND 必须相连**。

---

## 方案 2: 降低 HC-05 功耗

如果必须用主控板 3.3V 供电：

1. **AT 指令降低发射功率**（需进入 AT 模式）：
   ```
   AT+ROLE=0      // 从机模式（更省电）
   AT+CLASS=0     // 设备类型 0
   ```
