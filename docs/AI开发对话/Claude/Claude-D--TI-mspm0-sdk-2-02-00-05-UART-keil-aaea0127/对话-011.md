## 用户

你给我说A+ A- B+ B-和M1A M2A M1B M2B怎么接

## 助手

两种标注是同一个东西，只是不同板子的叫法。对应关系：

## A+/A-/B+/B- ↔ M1A/M1B/M2A/M2B

```
A+  ===  M1A     ← 线圈A 正端
A-  ===  M1B     ← 线圈A 负端

B+  ===  M2A     ← 线圈B 正端
B-  ===  M2B     ← 线圈B 负端
```

## 对应 28BYJ-48

| 28BYJ-48 | 叫法 A | 叫法 B |
|:-:|:-:|:-:|
| 橙 | **A+** | **M1A** |
| 粉 | **A-** | **M1B** |
| 黄 | **B+** | **M2A** |
| 蓝 | **B-** | **M2B** |
| 红 | 不接 | 不接 |

---

**核心规则就一句**：
- 橙粉一组 → A 相 → A+/A- 或 M1A/M1B
- 黄蓝一组 → B 相 → B+/B- 或 M2A/M2B

你板子上标的哪种，就按哪列接，两种写法完全等价。

## 用户

和板子端怎么连接

## 助手

直接在板子的接线端子（螺丝旋钮那排）上接，一一对应：

## TMC2208 板子端子排

板子上通常有一排 4 个端子（有些板子上方还有 EN/DIR/STEP 那排小的），电机端子这排：

```
┌─────────────────────────────┐
│  M1A   M1B   M2A   M2B     │  ← 或标 A+ A- B+ B-
│  (橙)  (粉)  (黄)  (蓝)     │
└─────────────────────────────┘
```

## 物理接线操作

| 端子位置 | 板子标注 | 插线 |
|:-:|:-:|:-:|
| 第1个 | A+ 或 M1A | **橙线** |
| 第2个 | A- 或 M1B | **粉线** |
| 第3个 | B+ 或 M2A | **黄线** |
| 第4个 | B- 或 M2B | **蓝线** |

用螺丝刀松开端子螺丝 → 插入线芯 → 拧紧螺丝。

---

## 完整 TMC2208 板子接线总览

TMC2208 板子一般有两排：

```
电机端子排:   M1A  M1B  M2A  M2B
              (橙) (粉) (黄) (蓝)

电源/控制排:  VM   GND  VIO  EN   STEP  DIR  (TX RX 有的板子有)
              │    │    │    │    │     │
             12V   GND  3.3V PA15 PA12  PA13
```

**注意红线（中心抽头）不要插到任何端子**，用绝缘胶带包好。

## 用户

我是说驱动板和主控

## 助手

明白了，是 TMC2208 驱动板和 MSPM0G3507 主控板之间的接线：

## TMC2208 → MSPM0G3507 接线

| TMC2208 板子端子 | MSPM0G3507 | 说明 |
|:-:|:-:|------|
| **STEP** | **PA12** | 步进脉冲 (GPIO 输出) |
| **DIR** | **PA13** | 方向 (GPIO 输出) |
| **EN** | **PA15** | 使能 (GPIO 输出，低有效) |
| **VIO** | **3.3V** | 逻辑供电 |
| **VM** | **12V 电源正** | 电机电源（外部独立） |
| **GND** | **GND** | 共地（12V负 + 主控GND） |

```
TMC2208                         MSPM0G3507
─────────                       ──────────
STEP  ────────────────────────→ PA12
DIR   ────────────────────────→ PA13
EN    ────────────────────────→ PA15
VIO   ────────────────────────→ 3.3V
VM    ───── 12V电源正 ────────── (独立适配器)
GND   ───── 12V电源负 ──────────→ GND  ←关键共地
```

---

## 如果要用 UART 配置 TMC2208

有的 TMC2208 板子带 TX/RX 串口接口：

| TMC2208 | MSPM0G3507 |
|:-:|:-:|
| **RX** | **PA10** (UART0 TX) |
| **TX** | **PA11** (UART0 RX) |

不用 UART 的话，TMC2208 靠板上的电位器调电流、跳线选细分，直接 STEP/DIR 就能驱动。

---

## 电源汇总

| 电源 | 给谁 |
|:-:|------|
| 12V 独立适配器 | TMC2208 VM + 电机 |
| 3.3V (主控板) | TMC2208 VIO + MSPM0 |
| GND | 全部相连（12V负 ↔ 主控GND ↔ TMC2208 GND）|
