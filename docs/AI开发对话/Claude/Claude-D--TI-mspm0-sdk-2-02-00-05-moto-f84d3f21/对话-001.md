### 2. `empty.c` — 完整重写 (533行)

**硬件映射：**

| 功能 | 引脚 | PINCM |
|------|------|-------|
| 电机A IN1 | PB16 | 33 |
| 电机A IN2 | PB15 | 32 |
| 电机B IN1 | PB2 | 15 |
| 电机B IN2 | PB3 | 16 |
| PWM A (CCP0) | PA12 | 34 (PF=4) |
| PWM B (CCP1) | PA13 | 35 (PF=5) |
| OLED I2C0 SDA | **PA0** | 1 (PF=3) |
| OLED I2C0 SCL | **PA1** | 2 (PF=3) |
| 蓝牙 UART2 TX | PA21 | 46 (PF=2) |
| 蓝牙 UART2 RX | PA22 | 47 (PF=2) |

**蓝牙指令协议：**
- `F`/`f` → 前进，`B`/`b` → 后退，`L`/`l` → 左转，`R`/`r` → 右转
- `S`/`s`/空格 → 停止
- `+`/`=` → 加速 (+10%)，`-`/`_` → 减速 (-10%)
- `0`-`9` → 速度预设 (0=停止, 1=10% … 9=90%)

**OLED 显示内容：**
- 方向 (Forward/Backward/Left/Right/STOP)
- 速度百分比 + 进度条
- 最后收到的蓝牙指令
- 运行状态

## ⚠️ 注意事项

1. **I2C OLED 引脚**：代码默认 OLED 接 **PA0(SDA) 和 PA1(SCL)**。如果你的 OLED 接在其他引脚上，请修改 `empty.c` 中第 33-34 行的 `PINCM_PA0`/`PINCM_PA1` 定义，以及第 45-46 行的 `PF_I2C0_SDA`/`PF_I2C0_SCL`。

2. **编译配置**：确保 Keil 工程里已添加 `ssd1306.c` 和 `empty.c` 一起编译。如果用了 microlib 导致 `snprintf` 报错，切换到标准 C 库即可。

3. **SysConfig 不要重新生成** — 重新生成会覆盖 `ti_msp_dl_config.c`，虽然不影响 `empty.c` 中手动初始化的外设。
