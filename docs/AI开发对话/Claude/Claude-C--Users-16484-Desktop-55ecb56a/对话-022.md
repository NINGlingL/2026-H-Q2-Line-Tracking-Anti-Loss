## 结论

**真正在工作的是**：1 个物理网卡（WiFi）+ 2 个 VMware 虚拟机网卡 + 3 个系统协议接口。

你是想问 RetroArch 联网用哪个 IP 吗？用 WLAN 的 IPv4 地址就行（`ipconfig` 里找 `192.168.x.x`）。VMware 那两个是给虚拟机用的，不是给你用的。
