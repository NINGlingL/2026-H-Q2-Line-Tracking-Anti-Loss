## 你还需要

找两个 ROM 文件放到 `D:/Game/FC/RetroArch/downloads/`：

| 文件 | 搜索关键词 |
|------|-----------|
| `kof97pls.zip` | "拳皇97风云再起 ROM 下载" |
| `neogeo.zip` | "neogeo bios 下载" |

> ⚠️ 两个文件**都不要解压**，直接 .zip 放进去。然后打开 RetroArch，Import Content → Scan Directory 扫描 downloads 文件夹。

对手拿到"联机对手需要的内容"文件夹后照里头的指南操作就行，不需要再下载任何东西。
