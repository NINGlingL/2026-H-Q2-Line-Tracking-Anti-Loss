## 第一层：MCP 协议是什么

MCP（Model Context Protocol）是一个**标准化的工具调用协议**。可以把它理解为"AI 和外部程序之间的通用语言"。

类比：USB 协议让你插任何品牌的 U 盘电脑都能识别。MCP 协议让你接任何工具 Claude Code 都能调用。

MCP Server 启动后，会向 Claude Code 注册自己有哪些"工具"可用，比如：

```
工具列表：
- build_firmware()       → 编译固件
- flash_firmware()       → 烧录到芯片
- read_memory(addr)      → 读取指定地址的内存
- write_memory(addr, val)→ 写入内存
- serial_send(data)      → 通过串口发送数据
- serial_read()          → 读取串口返回
- get_variable(name)     → 读取变量值
```

你输入"帮我把 LED 闪烁频率改成 500ms"，Claude Code 就知道该调哪个工具、传什么参数。
