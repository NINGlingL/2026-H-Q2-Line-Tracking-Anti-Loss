## RetroArch 纯局域网快速步骤

```
1. 所有人装 RetroArch（版本必须一致）
2. 主菜单 → 在线更新 → 核心下载 → FinalBurn Neo
3. 所有人准备相同的游戏 ROM（放入 RetroArch 的 downloads 目录扫描）
4. 同连一个路由器
5. 房主：联机 → 作为游戏主机 → 加载 FBNeo 核心 → 加载游戏
6. 其他人：联机 → 刷新局域网主机列表 → 加入
7. 开打
```

## 方案：RetroArch + FBNeo 核心

### 为什么选这个

| 你的要求 | 满足情况 |
|---------|---------|
| 不需要注册 | ✅ 离线用，无账号系统 |
| 局域网联机 | ✅ Netplay LAN，原生支持 |
| 异地也能联 | ✅ 配合 Tailscale 组虚拟局域网即可 |
| 拳皇、街霸、合金弹头、魂斗罗 | ✅ FBNeo 核心全支持 |
| Fightcade 替代 | ✅ 不依赖 GGPO 服务器，直接 P2P |

### 为什么 Fightcade 不好用

Fightcade 走的是互联网服务器中转，你和对面的 ROM 版本、模拟器核心版本如果不完全一致，就会出现"连上了但不同步"的问题——你看到的和他看到的是两场不同的对局。RetroArch 局域网直连则没有这个问题，因为双方在同一网络下直接同步状态。

### 快速操作

```
1. 两人都装 RetroArch（github.com/libretro/RetroArch/releases）
2. 两人都下载 FBNeo 核心（主菜单 → 在线更新 → 核心下载 → FinalBurn Neo）
3. 两人准备相同的 ROM 文件
4. 同连一个路由器
5. 房主：联机 → 作为游戏主机 → 加载 FBNeo → 加载游戏
6. 对手：联机 → 刷新局域网主机列表 → 加入
7. 开打
```
