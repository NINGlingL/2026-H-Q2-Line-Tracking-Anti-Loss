## 助手

## 加载拳皇97

### 第 1 步：打开 RetroArch

双击 `D:\Game\FC\RetroArch\retroarch.exe`

### 第 2 步：扫描游戏

主菜单 → **Import Content** → **Scan Directory** → 选择 `D:\Game\FC\RetroArch\downloads\` → 等扫描完成

### 第 3 步：启动游戏

返回主界面，左侧会出现一个手柄图标（FBNeo 的播放列表），点进去 → 点拳皇97 → 选 **FinalBurn Neo** → 游戏开始

### 第 4 步：测试

进游戏后按键盘方向键和 `ASDZXC` 试试有没有反应。没问题就退出（按 ESC 两次回到主菜单）。

---

## 局域网联机（你和朋友）

### 第 5 步：你当房主

1. 先查你的局域网 IP：按 Win+R → 输入 `cmd` → 输入 `ipconfig` → 找 `IPv4 地址`（如 `192.168.1.105`）
2. RetroArch 主菜单 → **Netplay** → **Start Netplay Host**
3. 弹出核心选择 → 选 **FinalBurn Neo**
4. 弹出游戏选择 → 选拳皇97
5. 屏幕左下角显示"正在等待客户端连接" → 说明就绪

### 第 6 步：朋友加入

朋友那边：

1. 先确认能 ping 通你：`ping 你的IP`
2. RetroArch → **Netplay** → **Connect to Netplay Host**
3. 输入你的 IP（如 `192.168.1.105`）
4. 回车 → 自动加载游戏 → 进入对战

### 第 7 步：开始对战

连接成功后双方画面同步。选人界面出现 → 选角色 → 开打。

---

## 如果连不上

```
① 先把 Windows 防火墙关了试试
② 确认两人在同一个路由器下面（同 WiFi）
③ 朋友先 ping 你：ping 192.168.1.105（换成你的 IP）
   通 → RetroArch 再试
   不通 → 网络问题，检查路由器
④ 确认双方的 ROM 文件一样（从你电脑拷过去）
```

1. 主菜单 → **Online Updater** → **Core Downloader**

另外，"netplay not supported"通常不是核心的问题，是**操作顺序**的问题。正确的局域网联机顺序：

```
① 主菜单 → Netplay → Start Netplay Host
      ↓ （此时游戏还没加载）
② 弹出窗口让你选核心 → 选 FinalBurn Neo
      ↓
③ 弹出窗口让你选游戏 → 选拳皇97
      ↓
④ 左下角显示"Waiting for client..."
```

> ⚠️ 不要先加载游戏再点 Netplay，那个顺序才会报"不支持"。

先用在线更新换核心，然后按这个顺序重试。
