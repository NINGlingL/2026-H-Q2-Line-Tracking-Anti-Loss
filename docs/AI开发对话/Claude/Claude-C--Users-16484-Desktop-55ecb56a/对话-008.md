## 使用方法

> ⚠️ **重启 Claude Code 后生效**

### 日常使用

在 Claude Code 对话里直接用自然语言：

- "帮我编译这个项目" → 调 `stm32_build`
- "烧录到板子上" → 调 `stm32_flash`
- "编译并烧录" → 调 `stm32_build_and_flash`
- "看看板子状态" → 调 `stm32_board_info`
- "读一下这个变量的值" → 调 `stm32_read_memory`

### 命令行手动用（不消耗 token）

把 `bin/` 加入 PATH 后可以自己敲：

```bash
stm32-build D:/你的项目路径 Debug
stm32-flash D:/你的项目路径/Debug/xxx.elf
stm32-bf D:/你的项目路径 Debug    # 一键编译+烧录
```
