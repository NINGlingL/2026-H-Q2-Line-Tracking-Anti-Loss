## 助手

Skill（技能）是 Claude Code 里的**专用功能模块**，你可以把它理解为"快捷键"或"预设工具包"。

### 怎么用

输入 `/<技能名>` 就能触发。比如：

- `/code-review` → 自动审查你改的代码有没有 bug
- `/deep-research 某个话题` → 自动搜索、查资料、写研究报告
- `/review PR链接` → 审查 GitHub 上的 Pull Request

### 它解决什么问题

有些任务需要多步操作、特定流程或专门的判断逻辑。如果每次都口头交代一遍，效率低且容易遗漏。skill 把这些流程**封装好**，一键执行。

### 和普通对话的区别

| 普通对话 | Skill |
|---------|-------|
| 你说一步，我做一步 | 内置完整流程，自动按步骤走 |
| 依赖你交代清楚 | 自带领域知识和方法论 |
| 灵活但不稳定 | 标准化但不够灵活 |

### 当前可用的 skill

你环境里现在有这些：`deep-research`、`dataviz`（图表）、`code-review`、`simplify`（代码简化）、`security-review`、`verify`（验证改动）、`loop`（定时循环）、`review`（审查 PR）、`init`（初始化项目文档）等等。

## 四、安装方式

Skill 放在两个位置：

- `~/.claude/skills/` — 个人用，所有项目生效
- `.claude/skills/` — 项目用，可 git 共享给团队

安装就是下载文件夹放到上述目录，很多仓库提供了一键脚本。

---

## 五、建议
