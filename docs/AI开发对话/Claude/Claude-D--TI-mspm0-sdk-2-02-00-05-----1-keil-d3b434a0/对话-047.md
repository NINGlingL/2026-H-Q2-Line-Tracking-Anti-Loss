## 💡 三种方案对比

### 方案1：纯循迹（无编码器）
```
策略：跟着黑线走，碰到起点标记停止
优点：最简单
缺点：速度不可控，可能冲出赛道
适用：低速，赛道宽容度高
```

### 方案2：单编码器 + 循迹
```
策略：
- 右轮编码器控制速度（防止太快冲出）
- 循迹传感器控制方向
- 里程计数判断"跑了一圈"

优点：速度可控，能判断一圈
缺点：转弯时内外轮速度差，里程会有误差
适用：中速，您的任务很可能够用
```

### 方案3：双编码器 + 循迹
```
策略：
- 左右轮独立速度控制
- 精确里程计算（左+右）/2
- 转弯时差速控制

优点：最精确，直线/弯道都能精确控制
缺点：左轮软件编码器不稳定（现在的问题）
适用：高速，精度要求高
```
