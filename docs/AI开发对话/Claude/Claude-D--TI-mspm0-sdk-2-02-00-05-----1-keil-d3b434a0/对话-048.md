### 关键点：**平衡小球才是核心**

这题的难点不是循迹精度，而是：
1. **速度平滑控制** - 避免加速度过大导致球滚动
2. **转弯速度控制** - 弯道必须减速
3. **实时速度反馈** - PID控制速度平滑

## 💡 我的判断

### ✅ **单编码器足够！**

**原因：**

1. **循迹靠传感器** - 8通道循迹传感器控制方向
2. **速度靠右轮编码器** - 硬件QEI精确可靠
3. **球的平衡更重要** - 不需要毫米级里程精度
4. **双编码器收益小** - 您的左轮软件编码器不稳定，调试成本高

### 控制策略：

```
速度环（右轮编码器）：
- 直线段：目标速度 = 中速（避免球滚动）
- 弯道段：目标速度 = 低速（防止离心力）
- 速度PID：平滑加减速

方向环（循迹传感器）：
- 位置偏差 → 差速转向
- 左右轮PWM = base_speed ± turn_adjustment

球平衡（倾角传感器，如果有）：
- 检测托盘倾斜 → 调整速度/加速度
```
