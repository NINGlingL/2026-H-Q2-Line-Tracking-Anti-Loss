## 🔍 误差原因分析

### 1. **陀螺仪积分漂移**
- 陀螺仪测量的是角速度，需要积分得到角度
- 积分会累积误差
- 即使校准后，仍有小的零偏导致漂移

### 2. **采样频率和死区**
- 当前采样：50Hz（每20ms）
- 死区：±2度/秒
- 慢速转弯时，真实角速度可能被死区过滤掉

### 3. **转换系数可能不准**
- 使用的是±250dps量程，转换系数131 LSB/dps
- 实际芯片可能有偏差

## 🔧 改进方案

### 方案1: 调整转换系数（简单）

## 🔧 改进内容

### 1. **补偿系数 × 1.5**
```c
float gz = gz_raw / 131.0f * 1.5f;
```
- 您转90度显示60度 → 实际/显示 = 90/60 = 1.5
- 所以乘以1.5倍补偿

### 2. **降低死区：2°/s → 1°/s**
```c
if (fabsf(gz) < 1.0f) gz = 0.0f;
```
- 减少慢速转弯时的数据丢失
