## 🎯 测试Yaw角度

### 初始化时
- **Mag值**应该在20-100之间（如果太小说明磁力计没工作）

### 测试方法
1. **水平放置**：记住初始Yaw值（例如180度）
2. **顺时针旋转90度**：Yaw应该增加到270度
3. **继续旋转**：270→0→90→180（循环）
4. **静止时**：Yaw应该稳定，不漂移

## ⚠️ 注意事项

### 磁力计干扰
磁力计对环境敏感：
- **远离**：电机、电池、金属物体
- **校准**：可能需要8字校准（暂未实现）
- **室内**：建筑钢筋可能影响精度

### 如果Mag值为0或很小
说明磁力计没工作，可能原因：
1. I2C Master配置问题
2. AK09916没响应
3. 硬件连接问题

### 如果Yaw不稳定
可以调整滤波系数（`empty.c`第119行）：
```c
yaw_smooth += 0.05f * diff;  // 改为5%，更平滑
```

   - 范围：-180到+180度

2. **GZ角速度校准**
   - 启动时自动校准零偏

   - 低通滤波（70%旧值+30%新值）

3. **循迹为主，陀螺仪为辅**
