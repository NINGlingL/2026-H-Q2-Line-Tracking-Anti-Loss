- 范围：0-65535（会回绕）
- 读取的是定时器寄存器值

**软件编码器（L）**：
- 使用32位有符号整数
- 范围：-2147483648 到 +2147483647
- 累加计数，不会回绕

## ✅ 硬件编码器改为累加计数模式

### 修改内容：

**之前的问题**：
- R直接读取16位定时器（0-65535）
- L是32位累加计数
- 单位和范围完全不同

**现在的方案**：
- R也改为32位累加计数
- 检测16位定时器的增量（处理回绕）
- L和R现在都是**32位有符号整数，持续累加**

### 统一后的特性：
```
左轮（L）：32位累加，4倍频，5ms轮询
右轮（R）：32位累加，4倍频，硬件QEI
单位：完全一致！
范围：-21亿 到 +21亿
```
