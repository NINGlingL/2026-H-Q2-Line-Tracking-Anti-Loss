## 🔧 SysConfig配置步骤

### 1. 打开SysConfig
在Keil项目目录中双击 `empty.syscfg`

### 2. 添加GPIO配置

#### 配置PA16（编码器A相）
1. 左侧点击 `GPIO`
2. 点击 `Add GPIO`
3. 配置：
   - **Name**: `E2A` 或 `ENCODER_LEFT_A`
   - **Pin**: PA16
   - **Direction**: Input
   - **Internal Resistor**: Pull Up
   - **Interrupt**: Enable
   - **Interrupt Trigger**: Rising and Falling Edge

#### 配置PA17（编码器B相）
1. 再次点击 `Add GPIO`
2. 配置：
   - **Name**: `E2B` 或 `ENCODER_LEFT_B`
   - **Pin**: PA17
   - **Direction**: Input
   - **Internal Resistor**: Pull Up
   - **Interrupt**: None（只需要A相中断）

### 3. 保存并生成代码
1. 保存 `.syscfg` 文件（Ctrl+S）
2. 编译时会自动运行SysConfig生成新的 `ti_msp_dl_config.c/h`
