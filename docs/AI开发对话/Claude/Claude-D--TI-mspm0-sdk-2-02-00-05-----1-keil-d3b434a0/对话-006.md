## 📊 改进说明

### 问题原因分析
陀螺仪数据跳动通常由以下原因造成：

1. **零偏漂移** - 陀螺仪静止时输出不为0
2. **传感器噪声** - 高频噪声导致数据抖动
3. **滤波器增益过大** - Kp=2.0过于激进
4. **积分累积误差** - Ki过大导致误差积累

### 优化方案

#### 1. **启动时零偏校准**（新增）
```c
void Calibrate_Gyro(void)
```
- 采集200个样本（1秒）
- 计算平均值作为零偏
- 后续读数自动减去零偏
- **启动时需保持开发板静止！**

#### 2. **死区处理**（新增）
```c
if (fabsf(imu_data.gx) < 0.5f) imu_data.gx = 0.0f;
```
- 小于0.5°/s的角速度视为0
- 消除静态噪声

#### 3. **低通滤波器**（新增）
```c
roll_filtered = 0.8 * roll_filtered + 0.2 * euler.roll;
```
- 平滑显示输出
- 减少视觉跳动
- 不影响实际控制精度

#### 4. **降低滤波器增益**
```c
IMU_Filter_Init(0.01f, 0.5f, 0.001f);  // Kp: 2.0→0.5, Ki: 0.01→0.001
```
- 减少过度修正
- 更稳定的姿态估计
