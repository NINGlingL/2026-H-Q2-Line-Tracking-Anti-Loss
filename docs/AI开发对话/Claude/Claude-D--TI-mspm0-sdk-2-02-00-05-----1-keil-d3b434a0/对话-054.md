## 🎮 蓝牙控制指令

```
F/f - 前进（手动模式）
B/b - 后退
L/l - 左转
R/r - 右转
P/p - 进入PID循迹模式
S/s - 停止
Z/z - 重置YAW角为0
1-9 - 设置速度档位（1=10%, 9=90%）
```
