## 📋 SysConfig配置步骤

### 1. 打开SysConfig
在Keil项目目录中双击 `empty.syscfg`

### 2. 添加GPIO
1. 点击左侧 `GPIO`
2. 点击 `Add GPIO`
3. 配置：
   - **Name**: `MOTO_EN` 或 `STBY`
   - **Pin**: PB14
   - **Direction**: Output
   - **Initial Value**: High (或Low，看您需要)
   - **Internal Resistor**: None

### 3. 保存并生成
1. 保存 `.syscfg` 文件
2. Keil编译前会自动运行SysConfig重新生成 `ti_msp_dl_config.c/h`

### 添加内容：
```c
/* 配置PB14为输出（STBY使能引脚） */
DL_GPIO_initDigitalOutput(IOMUX_PINCM31);  // PB14对应PINCM31
DL_GPIO_setPins(GPIOB, DL_GPIO_PIN_14);     // 拉高使能TB6612
DL_GPIO_enableOutput(GPIOB, DL_GPIO_PIN_14);
```

这样在 `Moto_Init()` 时会自动：
1. 配置PB14为输出
2. 拉高PB14（使能TB6612）
3. 启动PWM
4. 清零方向引脚
