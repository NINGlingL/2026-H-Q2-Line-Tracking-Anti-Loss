## 📋 编译和测试步骤

### 1️⃣ 确认Keil项目包含的文件

请确保以下文件都添加到Keil项目中：

**必需的源文件：**
- `empty.c` (主程序)
- `uart_bt.c` (蓝牙驱动)
- `moto.c` (电机驱动)
- `control.c` (蓝牙控制)
- `encoder.c` (编码器驱动)
- `icm20948.c` (陀螺仪驱动)
- `eight_ir.c` (循迹传感器)
- `ssd1306.c` (OLED显示)
- `ti_msp_dl_config.c` (系统配置)

**头文件：**
- 对应的 `.h` 文件都要在项目路径中

### 2️⃣ 编译项目

1. **打开Keil MDK**
2. **按F7编译**
3. **检查编译输出**：
   - 0 Error(s) ✅
   - 0 Warning(s) 最好
   - 如果有错误，告诉我错误信息

### 3️⃣ 下载到MCU

1. **按F8下载程序**
2. **观察OLED显示**

### 4️⃣ 测试流程

#### 启动测试
观察OLED依次显示：
```
Init System...
BT: OK
Motor: OK
Encoder: OK
ICM: OK (或FAIL)
Calib GZ... Keep still!  ← 保持静止！
GZ Calib OK
IR: OK
Smart Car v1.0
ICM:OK IR:OK
BT:OK MT:OK
Waiting BT...
```

#### 蓝牙连接测试
1. 手机打开蓝牙
2. 搜索HC-05设备
3. 配对（密码通常是1234）
4. 使用串口助手APP（推荐：Serial Bluetooth Terminal）

#### 蓝牙指令测试
发送以下指令测试：
```
S  → CMD应显示"STOP"，M:S 0%
5  → CMD显示"Spd 50%"，M:F 50% (如果之前是停止会自动前进)
F  → CMD显示"Forward 50%"，M:F 50%
+  → 速度增加到60%
-  → 速度减少到50%
L  → 左转
R  → 右转
B  → 后退
S  → 停止
```

#### 编码器测试
- 手动转动车轮
- 观察Enc值变化

#### 循迹测试
- 将循迹传感器放在黑线上
- 观察Pos值
- 观察8通道状态变化

## 🐛 可能遇到的编译错误

### 如果提示缺少头文件
```
error: cannot open source input file "xxx.h"
```
**解决**: 检查文件是否在项目目录，确认Keil路径设置

### 如果提示函数未定义
```
undefined symbol: xxx
```
**解决**: 确认对应的 `.c` 文件已添加到项目

### 如果提示宏未定义
```
error: undefined identifier 'BT_INST'
```
**解决**: 确认 `ti_msp_dl_config.h` 是最新的SysConfig生成版本
