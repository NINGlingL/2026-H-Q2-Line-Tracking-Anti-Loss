## 🔌 ICM20948模块接线（I2C模式）

### 必须接的引脚（I2C模式）

| ICM20948引脚 | 连接到MSPM0 | 说明 |
|-------------|------------|------|
| **VCC** | 3.3V | 电源（⚠️千万不要接5V！） |
| **GND** | GND | 地线 |
| **SCL** | **PB2** | I2C时钟 |
| **SDA** | **PB3** | I2C数据 |
| **AD0** | **GND** | I2C地址选择（接GND=0x68） |
| **NCS** | **3.3V** | 片选（拉高禁用SPI，启用I2C） |

### 可选引脚（暂时不需要）

| ICM20948引脚 | 接线 | 说明 |
|-------------|------|------|
| **INT** | 不接 | 中断输出（暂时不用） |
| **FSYNC** | 不接 | 帧同步（暂时不用） |
| **AUX_CL** | 不接 | 辅助I2C时钟（用于磁力计，我们不用） |
| **AUX_DA** | 不接 | 辅助I2C数据（用于磁力计，我们不用） |

## ⚠️ 关键要点

### 1. **NCS引脚必须接3.3V！**
```
NCS = 高电平 → I2C模式
NCS = 低电平 → SPI模式
```
如果NCS悬空或接错，ICM20948不会响应I2C！

### 2. **AD0引脚必须接GND！**
```
AD0 = GND → I2C地址 = 0x68
AD0 = 3.3V → I2C地址 = 0x69
```
我们的代码使用0x68，所以AD0必须接GND。

### 3. **INT引脚不需要！**
- INT是中断输出，用于数据就绪通知
- 我们用轮询方式读取，不需要中断
- **可以不接**

## 🔧 最简接线（6根线）

```
ICM20948          MSPM0G3507
--------          ----------
VCC      -------> 3.3V
GND      -------> GND
SCL      -------> PB2
SDA      -------> PB3
AD0      -------> GND
NCS      -------> 3.3V

不接：INT, FSYNC, AUX_CL, AUX_DA
```

## 🚨 常见错误

### 如果WHO_AM_I读不到0xEA：
1. ❌ **NCS没接或接错** → 最常见的问题！
2. ❌ **AD0悬空** → I2C地址不确定
3. ❌ **SDA/SCL接反**
4. ❌ **VCC接5V** → 可能损坏芯片
