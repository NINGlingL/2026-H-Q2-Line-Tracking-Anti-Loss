```
MCU (I2C) → ICM20948 (I2C Master) → AK09916磁力计
```

## 📊 两种循迹方案对比

### 方案1：只用循迹传感器（常规做法）
```c
// 只根据Position调整方向
if (ir_state.position > 0) {
    turn_right();  // 偏右了，右转修正
} else if (ir_state.position < 0) {
    turn_left();   // 偏左了，左转修正
}
```

✅ **优点**：简单，大多数循迹小车都这样做  
❌ **缺点**：转弯可能冲出轨道（如果速度快）

---

### 方案2：循迹 + 陀螺仪GZ（进阶）
```c
// 检测转弯状态
if (fabsf(gz) > 50) {
    // 正在转弯，减速
    motor_speed = 0.5 * normal_speed;
}

// 根据Position修正方向
adjust_direction(ir_state.position);
```

✅ **优点**：转弯更稳定，不易冲出  
⚠️ **要求**：GZ必须工作正常

---

## 🔧 如果用ICM20948，需要哪些参数？

| 参数 | 用途 | 是否必需 |
|------|------|---------|
| **Position（循迹传感器）** | 判断是否偏离轨道 | ✅ **必需** |
| **GZ（陀螺仪Z轴）** | 检测转弯角速度 | ⚠️ **推荐**（提高稳定性） |
| Roll/Pitch | 循迹不需要 | ❌ 不需要 |
| 加速度AX/AY/AZ | 循迹不需要 | ❌ 不需要 |
| 磁力计 | 循迹不需要 | ❌ 不需要 |
