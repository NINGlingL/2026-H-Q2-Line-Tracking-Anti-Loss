## 无源蜂鸣器（需要 PWM 频率控制音调）

```
3.3V ─── 蜂鸣器正极 ─── 蜂鸣器负极 ─── S8050集电极
                                      S8050发射极 ─── GND
PA8 (TIM1_CH1) ─── 1KΩ电阻 ─── S8050基极
```

CubeMX：PA8 → **TIM1_CH1 (PWM)**

| 蜂鸣器脚 | 接哪里 |
|----------|--------|
| 正极（+） | **3.3V** |
| 负极（-） | **三极管 S8050 集电极** |

```c
// 播放不同音调
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, 50);  // 占空比 50%
__HAL_TIM_SET_AUTORELOAD(&htim1, 1000);            // 频率 → 音高

HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);  // 开始响
HAL_TIM_PWM_Stop(&htim1, TIM_CHANNEL_1);   // 停止
```

---

## 为什么不能直接接 GPIO

| 肚子饿 | 什么原因 |
|--------|----------|
| GPIO 最大输出电流 | **8mA** |
| 蜂鸣器需要电流 | **20-30mA** |
| 直接驱动 | GPIO 烧坏 |

> **必须加三极管放大电流**，S8050（NPN）最常用，几毛钱一个。

---

## 总结

```
STM32 GPIO  ── 1KΩ ── S8050基极(B)
                         │
3.3V ── 蜂鸣器(+) ── (-) ── 集电极(C)
                              │
                           发射极(E) ── GND
```

- 有源蜂鸣器：GPIO Output，通断控制
- 无源蜂鸣器：PWM 输出，频率控制音调
- S8050 不能省，不然烧引脚

### 引脚分配总览

| 传感器 | 引脚 | 功能 |
|--------|------|------|
| 红外避障 1 | **PA11** | 障碍物检测 → OLED 显示 `OBSTACLE!` |
| 红外避障 2 | **PA12** | 障碍物检测 → OLED 显示 `OBSTACLE!` |
| 循迹模块 L | **PB12** | 左路循迹 → OLED 显示 `ON TRACK` / `OFF TRACK` |
| 循迹模块 R | **PB13** | 右路循迹 → OLED 显示 `ON TRACK` / `OFF TRACK` |
| OLED (I2C1) | **PB6**=SCL, **PB7**=SDA | 状态显示 |
| LED 指示 | **PB0** | 任一传感器触发就亮 |

### OLED 显示效果

```
┌───────────────────────────────┐
│      TraCKIng  CaR           │  ← 标题
│───────────────────────────────│
│ IR1: CLEAR              ○    │  ← 红外1 无触发=空心圆
│ IR2: OBSTACLE!          ●    │  ← 红外2 触发=实心圆
│───────────────────────────────│
│ L: ON TRACK  ●    ●=ON       │  ← 左路压线
│ R: OFF TRACK ○    ○=OFF      │  ← 右路离线
└───────────────────────────────┘
```
