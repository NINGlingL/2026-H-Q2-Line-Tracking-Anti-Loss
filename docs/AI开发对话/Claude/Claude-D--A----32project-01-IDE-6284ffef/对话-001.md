# 两路循迹模块接线与 STM32CubeMX 配置指南

## 一、两路循迹模块简介

常见的两路循迹模块（如 TCRT5000 红外对管模块）通常有 **4 个引脚**：

| 引脚 | 说明 |
|------|------|
| **VCC** | 电源正极（3.3V ~ 5V） |
| **GND** | 电源地 |
| **OUT1 / L** | 左路传感器输出（数字信号：黑线=HIGH，白底=LOW，视模块而定） |
| **OUT2 / R** | 右路传感器输出 |

> **注意**：有些模块信号逻辑相反（检测到黑线输出 LOW），具体看模块上的指示灯或实测。

---

## 二、接线方式（以 STM32F103C8T6 为例）

```
循迹模块          STM32F103C8T6
┌────────┐       ┌──────────────┐
│  VCC   │──────▶│  3.3V (或5V)  │
│  GND   │──────▶│  GND         │
│  OUT1  │──────▶│  PA0 (GPIO输入)│
│  OUT2  │──────▶│  PA1 (GPIO输入)│
└────────┘       └──────────────┘
```

> 选择 **PA0、PA1** 或者其他任意 GPIO 都可以，只要在 CubeMX 中配成输入模式。

---

## 三、STM32CubeMX 配置步骤

### 1. 新建工程
- 打开 STM32CubeMX → **New Project**
- 选择你的芯片型号（如 `STM32F103C8Tx`）

### 2. 配置 GPIO 输入引脚

以 PA0、PA1 为例：

1. 在 **Pinout view** 中找到 `PA0` 和 `PA1`
2. 分别点击，选择 **GPIO_Input**
3. 在左侧 **System Core → GPIO** 中，对 PA0 和 PA1 进行配置：

```
Pin Name    | Mode        | Pull-up/Pull-down
PA0         | Input mode  | Pull-up (或 No pull)
PA1         | Input mode  | Pull-up (或 No pull)
```

- **推荐加 Pull-up**：当模块输出为开漏（OD）时，悬空状态不会误触
- 如果模块本身有上拉电阻，选 **No pull** 即可

### 3. 配置调试串口（可选，便于调试）
- 启用 USART1（PA9=TX, PA10=RX），便于用串口打印传感器值

### 4. 时钟配置
- **Clock Configuration** → HCLK 设为 **72MHz**（SYSCLK = 72MHz，APB2 = 72MHz）

### 5. 生成代码
- **Project Manager** → 设置工程名、路径，Toolchain 选 **MDK-ARM**（Keil）或你用的 IDE
- 点击 **GENERATE CODE**

## 四、代码读取传感器

生成代码后，在主循环中读取：

```c
// 读取两路循迹传感器 (PA0, PA1)
uint8_t left  = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0);  // 左路
uint8_t right = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_1);  // 右路

// 判断状态（假设黑线=0，白底=1，根据实际模块调整）
if (left == 0 && right == 0) {
    // 两路都在黑线上 → 直行
} else if (left == 0 && right == 1) {
    // 左偏 → 右转修正
} else if (left == 1 && right == 0) {
    // 右偏 → 左转修正
} else if (left == 1 && right == 1) {
    // 全白 → 停止或寻找黑线
}
```

## 五、常见问题排查

| 问题 | 可能原因 |
|------|----------|
| 读到的值不变 | 没接 GND 共地，或引脚模式未设 Input |
| 值一直跳变 | 没有上拉，悬空状态不稳定 → 开启内部 Pull-up |
| 黑线白底逻辑反了 | 不同模块输出极性不同 → 代码里取反即可 |
| 指示灯不亮 | 模块供电不足（3.3V 模块接 5V 可能烧坏，确认电压） |

## 助手

# ST-LINK V2 固件升级报错 "未找到 upgrade.jar" 的解决方案

这是 STM32CubeProgrammer 较新版本（v2.15+）的已知问题 — ST 在新版中移除了内嵌的 Java 固件升级工具。

---

## 方案一：使用旧版 ST-LINK Utility（推荐，最简单）

直接下载 ST 官方的独立升级工具，不依赖 Java：

1. 下载 [STSW-LINK004 (STM32 ST-LINK Utility)](https://www.st.com/en/development-tools/stsw-link004.html)
2. 安装后打开 → 菜单栏 **ST-LINK → Firmware Update**
3. 点击 **Device Connect** → **Yes >>>>>** 即可升级
