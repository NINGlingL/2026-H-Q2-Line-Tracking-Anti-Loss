## 方案二：安装 Java 运行环境

如果坚持用 STM32CubeProgrammer 升级：

1. 下载安装 [JRE 8 (Java Runtime Environment)](https://www.java.com/download/)
2. 安装后将 Java 加入系统环境变量 `PATH`
3. 重启电脑后重新打开 STM32CubeProgrammer 尝试

cmd 中验证 Java 是否装好：

```cmd
java -version
```

应显示类似 `java version "1.8.0_xxx"` 的信息。

---

## 方案三：手动从安装目录修复

有时 STM32CubeProgrammer 安装不完整：

1. 进入安装目录，检查是否存在 `bin` 文件夹以及 `upgrade.jar`：
   ```
   C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin\
   ```
2. 如果缺失，重新下载安装包 → 以 **管理员身份** 重新安装

---

## 方案四：在 STM32CubeIDE 中升级

如果你安装了 STM32CubeIDE，它内置了 ST-LINK 升级功能：

1. 打开 STM32CubeIDE
2. 菜单 **Help → ST-LINK Upgrade**
3. 按提示操作即可

## 你需要下载的东西

### 方案一：ST-LINK Utility（最推荐，自带固件升级）

**官方下载页**：https://www.st.com.cn/zh/development-tools/stsw-link004

1. 打开页面 → 点击 **"获取软件"** 按钮
2. 同意协议，填邮箱
3. ST 会把下载链接发到你邮箱
4. 安装后打开软件 → 菜单 **ST-LINK → Firmware Update** 即可升级

> 目前最新版本是 **v4.6.0**

---

### 方案二：纯固件升级工具 STSW-LINK007（更轻量）

如果只需要升级固件、不需要烧录功能，用这个：

**官方下载页**：https://www.st.com/en/development-tools/stsw-link007.html

下载后直接运行 `ST-LinkUpgrade.exe`，点一下就能升级，无需 Java。

---

### 驱动也要装（如果还没装的话）

**STSW-LINK009 驱动**：https://www.st.com/en/development-tools/stsw-link009.html

---

## 总结

| 你要什么 | 下载哪个 |
|----------|----------|
| 升级固件 + 以后还要烧录调试 | **STSW-LINK004**（ST-LINK Utility） |
| 只想升级固件，别的不用 | **STSW-LINK007**（纯升级工具） |
| ST-LINK 插上电脑不识别 | 先装 **STSW-LINK009** 驱动 |

> ⚠️ 这些页面都需要填邮箱，ST 会把下载链接发过去。如果用 QQ 邮箱收不到，检查一下垃圾邮件箱。

**推荐直接下 STSW-LINK004**，装好以后既能升级固件，以后烧录程序也能用，一举两得。
