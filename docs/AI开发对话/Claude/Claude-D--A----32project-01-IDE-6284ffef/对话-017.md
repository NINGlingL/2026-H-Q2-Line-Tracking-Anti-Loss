| PID 的输入 | 来源 | 含义 |
|-----------|------|------|
| **误差** | 循迹模块 (TCRT5000) | 车偏离黑线的程度 |
| **目标值** | 0 | 黑线在正中间 |
| **输出** | 左右轮速度差 | 转向修正量 |

```c
// 最简单的循迹 PID
error = LEFT_SENSOR - RIGHT_SENSOR;  // 误差来自红外传感器
steering = Kp * error + Kd * (error - last_error);
MotorLeft  = base_speed + steering;
MotorRight = base_speed - steering;
```

> **全程不涉及 YAW。** 黑线在哪传感器直接告诉你，不需要知道车的绝对角度。

---

### YAW 什么时候有用？

| 场景 | 需要 YAW？ |
|------|-----------|
| **循迹跟线** | ❌ 不需要 |
| **90° 直角转弯** | 可选（传感器够多也能靠红外做） |
| **无黑线的空地导航** | ✅ 需要 YAW 做航向保持 |
| **平衡车** | ✅ 需要 Pitch + YAW |
| **目标瞄准/云台** | ✅ 需要 YAW |

---

### 结论

**你做循迹小车，MPU6050/ICM-20948 可以先放一边。** 核心控制链是：

```
TCRT5000 → 误差计算 → PID → TB6612 → 电机
```

先把传感器和电机调通，让车能沿着黑线跑起来。陀螺仪后面再加，用来做特技（比如检测到十字路口转 90°）。

## 电赛里陀螺仪的真实用途

以 **2025 国赛 E 题**（循迹小车+激光瞄准打靶）为例：

---

### 普通循迹 → 用不上

```
┌─────────────────────────────┐
│ 红外传感器 → PID → 电机     │  ← 全程不需要陀螺仪
└─────────────────────────────┘
```

光循迹的话，陀螺仪就是个摆设。

---

### 发挥题才是它的战场

2025 E 题的发挥部分要求：

| 题目要求 | 陀螺仪干什么 |
|----------|-------------|
| **小车行驶中激光持续射靶心** | 车在动、角度在变，云台要根据 **YAW 变化量** 反向补偿，保持激光指向不变 |
| **同步画圆** | 激光要在靶上画圆，云台角度控制需要精确知道旋转了多少度 |

```
车转弯 +30°  →  YAW 检测到 +30° →  云台反向转 -30° →  激光始终对准靶
```

简单说：**车负责走线，陀螺仪负责告诉云台"我现在朝向哪"，让激光不受车身转弯影响。**

---

### 往年控制类赛题中陀螺仪的角色

| 题型 | 用途 |
|------|------|
| 循迹+瞄准 | YAW → 云台角度补偿 |
| 平衡车 | Pitch/Roll → 直立控制 |
| 无人机 | 3轴姿态 → 飞控核心 |
| 倒立摆 | Pitch 角度 → 平衡 PID |
| 风力摆 | 角度反馈 → 位置控制 |

---

### 对你现在的意义

| 阶段 | 要不要陀螺仪 |
|------|-------------|
| **先让车跑起来（循迹）** | ❌ 完全不需要 |
| **发挥题加云台瞄准** | ✅ 那时候再加 |

**结论：现在别管 ICM-20948 了，集中精力把循迹传感器 + TB6612 电机控制调通。** 等车能沿着黑线跑之后，再根据赛题要求决定要不要加陀螺仪。
