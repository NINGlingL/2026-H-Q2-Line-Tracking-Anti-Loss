## 用户

那可以通过一个GPIO OUT引脚和一个GPIO INPUT引脚来实现小灯亮灭吗

## 助手

**可以，而且很简单。**

LED 本质就是一个发光二极管，用 GPIO Output 就能控制亮灭。

### 接线

```
STM32 PA0 (GPIO_Output) ─── 220Ω电阻 ─── LED正极(长脚) ─── LED负极(短脚) ─── GND
```

> 电阻一定要串，不然烧 LED 或者 STM32 引脚。

### CubeMX 配置

| 引脚 | 模式 | 用途 |
|------|------|------|
| PA0 | **GPIO_Output** | 控制 LED |
| PA1 | **GPIO_Input** + Pull-up | 读传感器 |

两个互不影响，各干各的。

### 代码

```c
// 亮
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_SET);

// 灭
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_RESET);

// 读传感器
uint8_t val = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_1);
```

### 常见玩法：传感器触发 LED

```c
if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_1) == 0) {
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_SET);  // 检测到 → 亮灯
} else {
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_RESET); // 没检测到 → 灭灯
}
```

### 注意

| 项目 | 值 |
|------|-----|
| 限流电阻 | 220Ω ~ 470Ω（越大越暗） |
| LED 工作电压 | 1.8V ~ 3.3V（不同颜色不同） |
| 最大翻转速度 | ~50MHz（GPIO 本身够快） |

所以一个 Output 管灯，一个 Input 读传感器，完全没问题，这也是 STM32 最基础的玩法。

## 用户

不是我的意思是，GPIO OUTPUT - LED - GPIO INPUT 直接在两个引脚之间插一个灯

## 助手

**不行，点不亮。**

原因很简单：GPIO Input 引脚内部是**高阻态**（等效电阻几十 MΩ），相当于断路。LED 需要电流从高电平**流到 GND**，但 Input 引脚不是 GND，电流没地方走。

```
PA0 (OUT) ── 220Ω ── LED ── PA1 (IN)
                               ↓
                          这里≈断路
                          LED根本不会亮
```

### 两种改法让它工作

**方案一：LED 一端接 GND，Input 并到中间来读电压**

```
PA0 (OUT) ── 220Ω ──┬── LED ── GND
                    │
                    └── PA1 (IN)   ← 读这里的电平
```

- 灯亮时 PA1 读到 HIGH（实际约 1.8V，接近阈值）
- 灯灭时 PA1 读到 LOW

> ⚠️ LED 导通时压降 ~1.8V，PA1 读到的电压在临界区，3.3V 系统下可能判不准。换 5V 耐受引脚配合 5V 供电更稳，或者加个三极管。

**方案二：直接串电阻接 GND，Input 跟 LED 无关**

```
PA0 (OUT) ── 220Ω ── LED ── GND    ← 灯靠这条回路亮
PA1 (IN)  ── 循迹/避障模块 OUT      ← 各自独立
```

这才是标准做法，灯管灯，传感器管传感器。

### 结论

GPIO Input 不是 GND，LED 必须有一端接地才能亮。两个引脚之间串个灯行不通。
