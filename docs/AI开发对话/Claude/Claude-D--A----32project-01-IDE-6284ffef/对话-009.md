### TB6612 vs L298N 注意

TB6612 控制每个电机需要 **3 个脚**（IN1、IN2、PWM），比 L298N 多一个 PWM 调速脚：

```
TB6612 引脚         MSPM0     功能
├── AIN1  ────────  ?       左电机方向1
├── AIN2  ────────  ?       左电机方向2
├── PWMA  ────────  ?       左电机PWM调速
├── BIN1  ────────  ?       右电机方向1
├── BIN2  ────────  ?       右电机方向2
├── PWMB  ────────  ?       右电机PWM调速
└── STBY  ────────  ?       使能（拉高才工作）
```

### 建议引脚分配（在 UART 项目基础上补全）

天猛星 MSPM0G3507 是 **LQFP-64**，空闲引脚很多。建议：

```
GPIO_Input:
  PB4  → 循迹 L (左路)
  PB5  → 循迹 R (右路)  
  PB6  → 红外避障1
  PB7  → 红外避障2

GPIO_Output:
  PB1  → 蜂鸣器（有源）
```

> 你可以在 SysConfig 里直接添加这些 GPIO 实例。
