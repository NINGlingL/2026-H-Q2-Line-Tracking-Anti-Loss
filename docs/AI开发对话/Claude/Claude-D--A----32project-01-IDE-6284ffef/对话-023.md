传感器模块的阈值判断发生在**模块硬件上**，不在 MCU 代码里。你能调的途径有两个：

---

### 1. 硬件调（最直接）

模块上每个通道旁边都有**电位器（十字螺丝状）**：

```
模块正面:                          模块背面:
┌─────────────────────────┐       ┌─────────────────────────┐
│ ○ ○ ○ ○ ○ ○ ○ ○        │       │ 8个小电位器 → 逐个拧      │
│ LED LED LED ...         │       │                          │
│ 1  2  3 ...  8         │       │ 顺时针=更灵敏（容易触发）   │
│                         │       │ 逆时针=更迟钝（不触发）    │
│      ○ ○                │       └─────────────────────────┘
│    电位器                │
└─────────────────────────┘
```

**调法**：传感器放在黑线上，拧那个通道的电位器直到 LED **刚好亮**，再往回拧一点点。8路逐个校准。

---

### 2. 软件调 — 如果你模块支持命令

有些模块（如感为科技）支持串口调阈值。你的模块是什么型号？如果是常见的 `$命令,参数,参数#` 协议，可能支持：

```
$T,通道号,阈值#      ← 调某个通道的灵敏度
$A,阈值#             ← 调所有通道
```

告诉我模块型号，我帮你找协议，然后在 `eight_ir.c` 里加上调阈值的代码。
