### ⚠️ OLED 驱动缺的东西（和 STM32 版对比）

MSPM0 版 OLED 目前**只有**：像素点 + 水平线 + 6x8字符 + 数字显示。

**没有的**（需要自己写或用笨办法）：
- 圆/实心圆
- 矩形/实心矩形
- 对角线
- 帧缓冲模式（只能先 Clear 再画，不能 NewFrame/ShowFrame）

## 1. 还需要 SysConfig 图形化配置吗？

**不一定需要。** 有两种做法：

| 方式 | 做法 | 适合 |
|------|------|------|
| **A: SysConfig 里加** | 打开 GUI → 拖 GPIO → 保存 → 自动重新生成 `ti_msp_dl_config.c` | 引脚大改、新增外设 |
| **B: 代码里直接写** | `DL_GPIO_initDigitalInput(PB4_PIN)` 一行搞定，不走 SysConfig | **加几个 GPIO 输入输出** ← 你现在的场景 |

对于你只需要加 4 个 GPIO Input（循迹×2+红外×2）+ 1 个 GPIO Output（蜂鸣器），**方式 B 就够了**，不用开 SysConfig。

> 代码示例：
> ```c
> DL_GPIO_initDigitalInput(DL_GPIO_PIN_4);  // PB4 设为输入
> DL_GPIO_setPullResistor(GPIOB, DL_GPIO_PIN_4, DL_GPIO_PULL_UP); // 上拉
> ```

## 2. 我怎么知道芯片型号的？

从你的 `empty.syscfg` 文件里读出来的：

```js
@v2CliArgs --device "MSPM0G3507" --package "LQFP-64(PM)"
```

所以就是：**MSPM0G3507，LQFP-64 封装，天猛星开发板**。
