## 核心区别

| | **5路无MCU** | **8路有MCU** |
|------|------------|------------|
| 输出 | 5个独立 GPIO 高低电平 | 通常 I2C/UART 数字协议 |
| 本质 | 5个红外对管直接输出 | MCU 处理后再输出 |
| 响应 | 即时（模拟直出） | 有延迟（MCU 处理周期） |
| 电赛能用？ | ✅ **可以** | ❌ **多数禁止** |

---

### 5路无MCU（推荐）

```
每个红外对管 → 独立 GPIO → STM32/MSPM0 直接读
              
      VCC ───┬──┬──┬──┬──┐
             │  │  │  │  │
            [1][2][3][4][5]   ← 5路红外管
             │  │  │  │  │
            OUT OUT OUT OUT OUT
             ↓  ↓  ↓  ↓  ↓
            5个 GPIO Input (如 PA0~PA4)
```

读法：`HAL_GPIO_ReadPin()` 或 `DL_GPIO_readPins()`，读到的就是 0 或 1。

---

### 8路有MCU（比赛可能违规）

```
8个红外管 → 自带MCU → UART/I2C → STM32 收数据

     ┌────────────────────────┐
     │  模块自带MCU（如STM8）    │
     │  8路传感器 → ADC → 阈值   │
     │  → 封装成 I2C/UART 协议   │
     │  → 输出数字值 (0~255)    │
     └────────────────────────┘
              ↓
         I2C/UART 两根线
```

读法：要发 I2C 读命令或串口解析协议。

---

### 2025 电赛 E 题的规定

> "不能用带 MCU 的巡线模块"

所以 **只能用无 MCU 的**（5路/8路都可以，但不能自带 MCU）。

---

### 为什么比赛禁 MCU 模块？

| 原因 | 说明 |
|------|------|
| 考核的是**你**的算法 | 如果模块自带 MCU 帮你算好了偏差值，PID 部分就变成调包了 |
| 公平性 | 不同模块输出的数据格式不同，有的甚至直接给 PWM，没法统一评分 |
| 核心考点 | 从原始传感器信号 → 滤波 → 偏差计算 → PID，全链路都在你的主控上完成 |

---

### 你应该买/用的

**5路/8路 灰度传感器模块，无 MCU 版本**。淘宝关键词：

> "灰度传感器 无MCU"、"八路巡线模块 模拟输出"、"TCRT5000 五路"

要点：确认每个通道是**独立 GPIO 引脚输出**，不是 I2C/UART 通信。
