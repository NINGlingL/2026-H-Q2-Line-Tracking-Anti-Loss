## 🔴 立即拔掉 USB！两个都烫 = 短路

DAP 烧录器和芯片**同时发烫**只有一个原因：**接线短路**。

---

### 最可能的错误

```
DAP 烧录器          MSPM0 板子
┌─────────┐        ┌──────────┐
│ 3.3V ───┼────────│ 3.3V     │   ← 这条线可能接反了
│ SWDIO ──┼────────│ SWDIO    │
│ SWCLK ──┼────────│ SWCLK    │
│ GND  ───┼────────│ GND      │   ← 这条线可能断了/接错了
└─────────┘        └──────────┘
```

**常见错误**：

| 错误 | 结果 |
|------|------|
| 3.3V 和 GND 接反 | 正负极短路 → 两边都烫 |
| DAP 的 3.3V 接到了板子的 GND | 短路 |
| 杜邦线插错一排（偏移了一格） | 电源串到信号线 |
| 面包板/底板上有锡渣桥接了 VCC-GND | 短路 |

---

### 你现在要做

```
1. 立刻拔 USB（已经说了）
2. 用万用表蜂鸣档测 DAP 烧录器的 3.3V 和 GND 之间是否短路
3. 用万用表测 MSPM0 板子的 3.3V 和 GND 之间是否短路
4. 仔细检查杜邦线：每根线两端对应关系对不对
5. 重新插线，只接 4 根 (3.3V, GND, SWDIO, SWCLK)
6. 再上电，摸一下还烫不烫
```

---

> **先别烧程序了，把硬件查清楚。** 正常情况芯片和烧录器都应该是凉的。
