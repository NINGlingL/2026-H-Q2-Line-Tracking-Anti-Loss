## 🔴 硬件有问题

**只接供电、芯片就发烫 + 电压掉到 2.8V = 短路或芯片已损坏。**

3.3V 掉到 2.8V 说明电流非常大，电源带不动了。

---

### 断电后立刻做

**万用表打到电阻档（200Ω），测板子 VCC 和 GND 之间的电阻：**

| 读数 | 判断 |
|------|------|
| **<10Ω** | 严重短路 — 检查焊点、锡渣、电容是否击穿 |
| **10~100Ω** | MCU 内部损坏可能性大 |
| **>1kΩ** | 正常，问题可能在别处 |

---

### 三步锁定问题

```
1. 拔掉所有外设, 断电
2. 万用表蜂鸣档测 VCC-GND
3. 手摸板子, 是 MCU 烫还是旁边 LDO(稳压)烫?
```

| 哪个烫 | 说明 |
|--------|------|
| **LDO 烫** | 后级短路，MCU 或其他元件把电压拉低 |
| **MCU 烫** | 芯片内部损坏 |
| **两个都烫** | 严重短路，继续用可能烧更多东西 |

---

### 你现在需要

1. 万用表测 VCC-GND 电阻
2. 确定发热源
3. 如果是 MCU 坏了 → 换一块天猛星板子（比赛多备几块是常识）
4. 如果是焊点短路 → 烙铁重新拖一下

**比赛倒计时只有 1 天了，如果确认芯片坏了，立刻换备板。**

---

### 死因推测

**大概率是你的接线问题导致的：**

| 可能原因 | 后果 |
|----------|------|
| 3.3V 接到 GND → 电源反向 | 瞬间击穿 |
| 杜邦线插歪一排 | 5V/信号串到不该去的地方 |
| 面包板底下有锡渣桥接 | VCC-GND 短路 |
| DAP 烧录器的 VCC 输出不是 3.3V | 过压烧片 |
