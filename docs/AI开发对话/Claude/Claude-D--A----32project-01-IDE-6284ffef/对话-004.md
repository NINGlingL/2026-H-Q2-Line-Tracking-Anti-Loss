## 用户

红外避障的OUT+引脚应该接的是GPIO输出引脚是吗

## 助手

**不对，应该接 GPIO 输入（Input）引脚。**

红外避障模块的 OUT 是**传感器对外输出信号**，STM32 要**读取**这个信号判断有没有障碍物，所以：

| 模块引脚 | STM32 引脚 | GPIO 模式 |
|----------|-----------|-----------|
| VCC | 3.3V / 5V | — |
| GND | GND | — |
| **OUT** | 任意 GPIO（如 PA0） | **GPIO_Input** |

### CubeMX 配置

选一个空闲引脚 → 设为 **GPIO_Input** → 开启内部 Pull-up：

```
Pin       | Mode       | Pull-up/Pull-down
PA0       | Input mode | Pull-up
```

> 开 Pull-up 原因：传感器输出一般是开漏（NPN），没障碍物时悬空，上拉保证读到确定的高电平。检测到障碍物时传感器拉低 → STM32 读到 0。

### 代码读取

```c
// 读取红外避障传感器
uint8_t obstacle = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0);

if (obstacle == 0) {
    // 检测到障碍物（LOW = 有障碍，视模块极性而定）
}
```

---

**IN → 输入，OUT → 输出**。模块叫 OUT 是因为它输出信号，但对 STM32 来说就是 GPIO Input，反过来接就对了。

## 用户

那两路循迹模块的R0和L0接什么引脚

## 助手

和红外避障一样，**接 GPIO Input**。

两路循迹模块（以常见的 TCRT5000 为例）：

| 模块引脚 | 含义 | STM32 接法 |
|----------|------|-----------|
| VCC | 电源 | 3.3V / 5V |
| GND | 地 | GND |
| **R0** | 右路传感器输出 | **GPIO_Input**（如 PA0） |
| **L0** | 左路传感器输出 | **GPIO_Input**（如 PA1） |

> R0 = Right Out，L0 = Left Out，名字里带 "Out" 是因为模块**向外输出**信号，对 STM32 来说就是读入。

### CubeMX 配置两路

```
Pin       | Mode           | Pull-up/Pull-down
PA0       | GPIO_Input     | Pull-up        ← 接 R0
PA1       | GPIO_Input     | Pull-up        ← 接 L0
```

### 代码读取

```c
uint8_t right = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0);  // R0
uint8_t left  = HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_1);  // L0

// 根据模块极性判断（模块上 LED 亮 = 检测到黑线，通常输出 LOW）
if (left == 0 && right == 0)   { /* 两路都压线 → 直行 */ }
if (left == 1 && right == 0)   { /* 右偏 → 左转修正 */ }
if (left == 0 && right == 1)   { /* 左偏 → 右转修正 */ }
```

总结：**只要是传感器输出信号给 STM32，统统配成 GPIO_Input**，OUT 只是模块那边的命名，别被它误导。
