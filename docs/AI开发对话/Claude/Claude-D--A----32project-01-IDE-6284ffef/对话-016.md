## 当前算法分析

```c
// 就是纯陀螺仪 Z 轴积分，没有任何修正
s_yaw += data.gyro_z * elapsed * 0.001f;
```

**这就是原因**：

| 问题 | 原因 |
|------|------|
| **YAW 会漂移** | MPU6050 是 **6 轴**（3加速度+3陀螺），没有磁力计 |
| **加速度计帮不了 YAW** | 加速度计只能测重力方向（修正 Pitch/Roll），绕 Z 轴的旋转它测不到 |
| **零偏校准不够** | 校准时轻微晃动就会偏 |

简单说：**六轴 IMU 的 YAW 靠陀螺仪纯积分，一定漂**，这是物理限制，不是代码 bug。

---

## 你的真实硬件是 ICM-20948

你之前说过用的是 **ICM-20948**（9 轴：加速度+陀螺+磁力计）。磁力计能测地磁场方向，就能**绝对修正 YAW**，不会漂。

但现在的驱动是 MPU6050 的，ICM-20948 寄存器地址不完全一样。
