### 使用方法

**方式一：直接打开使用**
1. 双击 `MDK-ARM\MSPM0G3507.uvprojx` 在 Keil 中打开
2. Keil 会自动通过 RTE 添加 CMSIS Core（Cortex-M0+ 启动代码）
3. 编译即可（当前 main.c 使用寄存器直接访问 GPIO）

**方式二：使用 TI DriverLib（推荐）**
1. 从 TI 官网下载 MSPM0 SDK：https://www.ti.com/tool/MSPM0-SDK
2. 安装到默认路径 `C:\ti\mspm0_sdk_2_03_00_07\`
3. 运行 `setup_sdk.bat` 自动创建符号链接
4. 将 `Drivers/MSPM0_DriverLib` 和 `Drivers/MSPM0_Devices` 中的文件添加到 Keil 工程
5. 在工程选项中添加 include 路径并定义 `DeviceFamily_ID=DeviceFamily_ID_G3X0X`
