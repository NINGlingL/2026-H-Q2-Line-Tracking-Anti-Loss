## 助手

- 基于 Rust 的 probe-rs，支持 DAPLink
- 支持 ARM Cortex-M 和 RISC-V
- 缺点：需要 Rust 工具链（`cargo build`），MSPM0 具体支持待验证

### ❌ 不适用

| 方案 | 原因 |
|------|------|
| `@arm/mcp-server` | npm 上似乎未公开发布 |
| cortex-mcp-bridge | 需要 VSCode + Cortex-Debug 插件，非独立方案 |
| stm32-mcp | 仅 STM32 |

---

## 我的建议

**先试 `openocd-mcp`**。理由：

1. 原生支持 CMSIS-DAP，无需 J-Link
2. Windows 有 `setup.bat`，安装简单
3. OpenOCD 已官方支持 MSPM0G3507
4. Python 生态，不依赖 Rust/Cargo
