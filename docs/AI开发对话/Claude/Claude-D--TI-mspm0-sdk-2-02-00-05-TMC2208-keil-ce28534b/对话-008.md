## 助手

## VREF 调多少：**0.5~0.6V**

TMC2208 配 0.11Ω 感测电阻的模块，规律是 **Vref(伏) ≈ 电机最大电流(安)**：
- 你这电机 28HS30-0604A 额定 0.6A → 满额 Vref ≈ 0.6V；
- 负载很轻（杆+小球），**先调 0.5V** 就够，跑起来顺畅不丢步就别再加，电机不发烫为准；
- 上限别超过 1.2V，安全值 ~90%。

## 往哪边转：**没法直接告诉你，必须用万用表量着转**

这是关键——**电位器往哪边转是增是减，取决于模块板上的接线，没有统一答案**。唯一可靠的做法：

1. 上电（**先别接电机**，只接 G3507 和电源更安全）；
2. 万用表打到直流电压挡，**红表笔点 VREF 测试点**（电位器旁边，模块上通常有 VREF 丝印，或直接点电位器中间那根脚），**黑表笔点 GND**；
3. 拿小螺丝刀**慢慢拧**电位器，眼睛盯着电压读数：
   - 电压往上涨 → 方向对了，继续到 0.5V 停；
   - 电压往下跌 → 拧反了，掉头拧回去。
4. 拧到位后，再接电机测试。

> 一句话：**方向靠"拧着看电压"来确定，不是靠记方向**。别凭感觉盲拧，拧到 1.2V 以上电机会烫。

## 调完 VREF 后，上电如果还不转，按这个顺序查

1. **VM 有没有 12V**（模块电源脚）；
2. **EN 有没有被拉低**（我们程序 EN=PA15，上电 `tmc2208_enable()` 会拉低；量 PA15 应为 0V）；
3. **PA8 有没有方波**（50% 占空比，我们程序里电机会自动在 ±5mm 往复，PA8 应该一直有脉冲；用示波器或量电压应看到 ~2.5V 平均）；
4. **CLK 到 GND**（如果之前按"接 GND"方案接了）；
5. 电机线两组线圈有没有接对（万用表通断配对）。

## 助手

对，**就是那个小螺丝**，但准确说它是"**电位器**"（可调电阻），不是普通螺丝：

**长这样：**
- 一个**小方块/小圆柱**，顶面有个**十字或一字槽**（用最小号螺丝刀拧）；
- 位置在模块正面上方或靠近电机输出脚那一侧，旁边**通常印着 VREF** 字样；
- 颜色一般是银色/金色的金属顶帽，很小（2mm 左右）。

**怎么和普通螺丝区分：**
- 固定用的普通螺丝在板子四角或接口处，拧它电流不会变；
- VREF 这个"螺丝"是**可以无级旋转**的可调电阻，拧一圈电流就变一圈。

**确认方法：** 上电后用万用表电压挡，红表笔点它**中间那根脚**、黑表笔点 GND，然后拧它——**电压会跟着变**，那就是它。

> 注意：拧的时候用**小号螺丝刀**轻轻拧，别把槽拧花了；调完可以用指甲油/热熔胶固定（比赛现场震动可能把它拧跑了）。

你先确认一下模块上有没有 VREF 字样或那个小方块，拧它量电压，调到 0.5V 左右，然后告诉我上电后电机转不转。

## 用户

## 助手

**要调，而且必须调低。** 1.2V 太大了。

## 为什么

- Vref 1.2V ≈ 电流 1.2A 峰值；
- 你这电机额定只有 **0.6A**，等于**给满了两倍电流** → 电机发烫、长时间可能烧/退磁；
- 1.2V 也正好是 TMC2208 模块的电流上限，说明现在电位器在最右边。

## 怎么调

1. 万用表红表笔点 VREF 中间脚、黑表笔点 GND，保持量着；
2. **朝电压减小的方向拧**（拧反了电压会涨，看到涨就掉头）；
3. 目标 **0.5V 左右**——杆+球负载很轻，0.5V（≈0.5A）完全够用，电机凉快；
4. 万一之后发现丢步/力矩不够，再往 0.6V 微调，别再高。

## 调完后确认

- VREF ≈ 0.5V；
- 上电 → 程序里电机会在 ±5mm 往复，看它转不转、方向对不对。

调好告诉我现象。如果调完电机还是不转，就按之前给的顺序查：**VM 12V → EN 拉低(PA15=0V) → PA8 有没有方波 → CLK 到 GND**。
