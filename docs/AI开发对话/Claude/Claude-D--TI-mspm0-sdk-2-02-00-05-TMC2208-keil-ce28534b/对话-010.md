## 系统结构

```
视觉 20Hz ──P:12.34,V:56.78──► 串口解析 ──► 球位置+速度
                                               │
                        目标: O→+5→-5 (任务3轨迹状态机)
                                               ▼
                           PID (PD为主, 视觉速度直接当D项)
                                               ▼
                         杆端抬升量(mm) → 步数 → 步进电机 (平滑重定位)
```

**关键改进**：`tmc2208_move_to` 改成**移动中平滑改目标**（同方向不重置速度），球控每 50ms 更新一次目标时电机不顿挫、不扰动小球。

## 测试流程

1. **上电前把水管调到水平**（丝杆螺母在 6.5cm 高度）——程序把当前位置当 0；
2. 上电，小球放 O 点附近，OLED 显示 `Waiting vision`；
3. 视觉跑起来 → OLED 切到 `BALL CONTROL`，球自动往 **O+5** 走，稳住后自动折返 **O-5**，循环；
4. 看 OLED 第 7 行 `T:` 时间，目标 ≤5s。

## 调参口诀（第一次跑观察 Er 和球）

- 球**一启动就朝反方向跑** → `LIFT_SIGN` 改成 `-1`；
- 球**来回震荡收不住** → 减 KP（如 2.0）、加 KD（如 2.5）；
- 球**太肉、半天到不了目标** → 加 KP（如 4.0）、或加 `LIFT_LIMIT_MM`；
- 球**停在目标附近有固定偏差** → 加 KI（如 0.5）；
- 每段 2.5s 超时强制切换，卡住也不会死循环（但分数会差，正常应该 1s 内到位）。

OLED 每行含义：`Ball`视觉位置 / `Tgt`目标 / `Err`误差 / `Vel`球速 / `Lift`PID输出(mm) / `Stp`步进位置 / `Phs`阶段 / `T`已用时间。
