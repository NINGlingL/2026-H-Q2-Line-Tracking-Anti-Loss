## 助手

查清楚了，给你确定接法。这几个脚如果接错/悬空会导致电机不转或无力矩，一定要按这个接：

## TMC2208 模块这几个脚的接法（STEP/DIR 模式）

| 模块引脚 | 接法 | 原因 |
|---------|------|------|
| **MS1** | → **GND** | 1/8 细分（1600步/转 → 800步/mm） |
| **MS2** | → **GND** | 同上 |
| **PDN** (PDN_UART) | → **VIO (3.3V)** | 禁用"静止自动省电/降力矩"，电机静止时保持锁紧力矩 |
| **CLK** | → **GND** | **选内部时钟，必须接 GND，不能悬空** |
| **USART** | 不接 | STEP/DIR 模式下 UART 功能不用；PDN 就是那个单线 UART 脚，以后要配寄存器再说 |

## 为什么

**CLK → GND**：TMC2208 用内部时钟时 CLK 必须拉 GND（短接线），悬空虽然内部有下拉但数据手册明确"不推荐"。很多模块 PCB 上已经内部连了 GND，但你这块把 CLK 引到排针了，**必须自己接 GND**，否则电机可能完全不转。

**PDN → VIO**：PDN 是"电源管理/单线 UART"复用脚。STEP/DIR 模式下它只控制静止时是否自动降电流：
- 接 **GND** = 静止自动降力矩（省电但杆会松）❌
- 接 **VIO(3.3V)** = 静止保持满力矩 ✅ ← 控球必须要这个，杆不能松
- 悬空 = 看模块上拉/下拉电阻，结果不确定 ❌

所以接 **VIO**，确定性最好。

**MS1/MS2 → GND**：MS 表如下，我们取 00 = 1/8：

| MS1 | MS2 | 细分 | 步/转 |
|-----|-----|------|-------|
| 0 | 0 | **1/8** | 1600 |
| 0 | 1 | 1/16 | 3200 |
| 1 | 0 | 1/4 | 800 |
| 1 | 1 | 1/2 | 400 |
