```
GND ──► CLK   (内部时钟)
3.3V ─► PDN   (禁止静止降力矩)
GND ──► MS1 ─┐
```

## 用户

MS1 和 MS2的GND可以连同一根吗

## 助手

可以，**MS1 和 MS2 共用一个 GND 完全没问题**。

它们需要的都是"逻辑低电平"（0V），而 GND 在整个电路里本来就是同一个网络——模块的 GND 脚、MS1、MS2、还有 G3507 的 GND 全部是相通的。所以你可以：

- 把 MS1、MS2 一起接到模块自己的 **GND 排针**上（最省事，就在同一边）；
- 或者一起接到 G3507 的 GND。

唯一的要求：**这个 GND 必须和 G3507 共地**（本来就是这么接的），且焊点/杜邦线接触要牢靠。悬空才是不允许的，共用一个 GND 没关系。

顺带：CLK 也要接 GND，可以和 MS1/MS2 一起并到同一个 GND 点上，同理没问题。

## 用户

PDN 串口 和CLK可以啥都不接对吧

## 助手

不对——**只有"串口"(USART)可以啥都不接，CLK 和 PDN 不建议悬空**。我强调一下，别在这翻车：

| 脚 | 能不能悬空 | 正确接法 |
|----|-----------|---------|
| **USART**（就是 PDN 的单线 UART 功能） | ✅ 可以，STEP/DIR 模式下不用它 | 不接 |
| **CLK** | ❌ **不能**，必须接 GND | → **GND** |
| **PDN** | ⚠️ 能转但不稳，建议接 VIO | → **VIO (3.3V)** |

**为什么 CLK 必须接 GND：** 数据手册明确写 CLK 接 GND 才用内部时钟，悬空"不推荐"。虽然不少模块 PCB 内部已经给 CLK 挂了下拉（所以很多教程说能悬空），但你这块把 CLK 引到排针了，**它可能是真悬空的**——悬空会导致芯片时钟不稳定，电机**时转时不转甚至完全不转**。接一根线到 GND 成本为零，别赌。

**为什么 PDN 建议接 VIO：** 悬空时它读高还是读低取决于模块板上有没有上拉电阻，结果不确定。接 VIO(3.3V) 保证"禁止静止降力矩"，电机静止时锁紧，控球时杆不会松。

**USART 确实不用接：** PDN 就是那个单线串口脚，我们走 STEP/DIR 脉冲模式，不碰 UART。

---

**总结最小可靠接法：**
```
CLK  → GND     （必须，一根线）
PDN  → VIO     （建议，一根线，3.3V）
USART → 不接    （正确）
MS1/MS2 → GND  （1/8 细分）
```

就多两根线的事，别省。上电如果电机不动，第一个就查 CLK 有没有到 GND。

## 数据手册事实（内部下拉）

| 脚 | 内部结构 | 悬空时的状态 |
|----|---------|-------------|
| **CLK** | **内部有下拉** | 悬空 → 被拉到低 → 自动选内部时钟 ✅ 能转 |
| **PDN** | **内部有下拉** | 悬空 → 被拉到低(GND) → 静止自动降电流开启，**不影响转动** ✅ |
| **USART** | - | STEP/DIR 模式不用，悬空正确 ✅ |

所以三个脚**都不接也能正常工作**——你最初的判断是对的。

## 但有两个"不接会有副作用"的点

1. **CLK 悬空**：能转，但官方手册写的是"用内部时钟请把 CLK 短接 GND"，明确标注依赖内部下拉"不推荐"（怕接触不良/噪声导致时钟不稳）。**不接能跑，接一根到 GND 更稳。** 二选一都行。

2. **PDN 悬空**：电机转动完全正常，唯一区别是**静止时自动降电流**——电机停住后力矩变小，杆可能被球压得微沉。控球阶段（让球停在指定位置）可能要满力矩锁紧，那时把 PDN 接 VIO(3.3V) 才有意义。

## 务实建议（按你现在的目标）

**现在只做"让滑杆动"** → 三个脚**全悬空即可**，直接上电测。

**以后做控球/锁紧** → 再加一根线：`PDN → VIO (3.3V)`。CLK 想稳就顺手也接 GND。

所以：**现在真的可以啥都不接**。我之前那两条"必须/建议"是保守写法，不是"不接就不转"的硬性要求，这点我澄清错了。电机不转的话别往这俩脚上找原因，优先查 **VM 电压、VREF、PA8 有没有方波、EN 有没有拉低**。

## 用户

可以和MS1 MS2同一根地线吗

## 助手

可以，**CLK、MS1、MS2 全部并到同一个 GND 节点都没问题**。

GND 在电路里就是同一个网络——模块的 GND 脚、MCU 的 GND、以及这几个"需要低电平"的脚，电气上是完全相通的。所以你可以：

```
模块 GND ──┐
           ├──► MS1
           ├──► MS2
           └──► CLK     (如果选择接 GND)
```
一根线把所有要接 GND 的脚串起来即可，只要最后保证**这个 GND 和 G3507 共地**就行。

注意区分：
- **MS1、MS2、CLK** → 接 **GND**，可以共一根；
- **PDN** → 接的是 **VIO (3.3V)**，这是电源不是地，别和上面那根地线混在一起。

如果你现在的决定是**三个脚全悬空**（上一轮确认过能转），那这个问题就无所谓了，直接上电测就行。
