## 助手

**1. 被控对象的物理模型**
球在倾斜杆上纯滚动：`ẍ = (5/7)·g·sin(θ) ≈ 7·θ`（θ 为杆倾角）。这是一个**双积分对象（无自恢复力、开环不稳定）**。

由此推出一个硬结论：**纯 P 控制必振**。P 控制得到 `ẍ = -Kp·x`，那是无阻尼简谐振荡。所以 **D 项（球速度反馈）是必需的**——P 定刚度、D 定阻尼，I 用于克服凹槽静摩擦的稳态偏差。建议 PD 为主、I 很小且带抗饱和。

**2. 两级控制结构（我的建议）**
```
外环（20Hz）：球位置误差 → 目标倾角/目标杆端高度     ← PID
内环（高频）：目标高度 → 步进位置（梯形/S形加减速）  ← 步进伺服
```
关键要求：**内环带宽要远高于外环**。外环 50ms 才更新一次，内环如果 200ms 才跟上，控制就废了。步进加减速要快而平滑（加速度曲线要缓，否则急动会扰动球）。

**3. 20Hz 是最大的硬约束**
视觉端固定 50ms 发一次、且只发位置不发速度。后果：
- 球速度只能 MCU 端对位置差分得到，噪声大，需要低通滤波；
- 整个回路还有延迟（曝光+推理+串口间隔 ≈ 40~80ms），对双积分对象来说这个延迟会限制能用的增益/阻尼；
- 静态（任务3）没问题；**移动中（任务4-6）车体加减速/过弯离心会变成强扰动，这是最难的**。建议先把静态做到稳，再上动态。

如果未来允许动视觉端，强烈建议让它**连速度一起发**（一行两个数），闭环会好做很多——但你说了那份文件不能改，所以我按 20Hz 位置-only 设计。

## 四、硬件与接口设计要点

**1. TMC2208 用 STEP/DIR 模式（推荐）**
- 比走 TMC2208 单线 UART 寄存器配置简单可靠得多；UART 顶多用来配细分/电流，控制仍走 STEP/DIR。
- 细分建议 1/8 或 1/16（丝杆 4mm 导程下，1/16 细分 ≈ 800 step/mm，分辨率远超 1cm 误差要求）。
- STEP 脉冲用 MSPM0 定时器产生（PWM 或定时中断翻转 GPIO），做梯形加减速；DIR、EN 各占一个 GPIO。
- 电流：电机 0.6A，TMC2208 模块按 VREF≈0.42A·1.77 量级调（具体看模块感测电阻），别按满额定。
- 电源：模块 VMOT 建议 12V（丝杆负载很轻，12V 足够）；逻辑侧确认 3.3V 电平兼容（多数 TMC2208 模块可以）。

**2. 电机与机构的校准（成败关键，必须实测）**
- 确认 28HS30-0604A-013 是不是**带丝杆**（型号里 0604 有两种解释：0.6A/4线，或 6mm丝杆/4mm导程——你说"上升下降"，我倾向丝杆型，但要实测）。
- **标定步数↔位移**：丝杆导程 + 步距角(1.8°) + 细分 → steps/mm。例如 4mm 导程 + 1/16 细分 = 3200/4 = 800 step/mm。
- **标定杆端高度↔倾角**：杆长 25cm，θ = asin(Δh/25)。右端每抬 1mm ≈ 0.23°。
- **标定视觉坐标↔物理位置**：O 点对应的 cm 值（Python 里 O 在 12.5cm 附近，但安装偏移要实测），以及 + 方向与"抬升/下降"的对应关系（**方向符号接反是最常见的首日坑**）。
- 安装尺寸别超：车身 ≤35×25cm，杆不超车身。

**3. 安全与零位**
- 丝杆升降必须处理**零位/限位**：有没有限位开关？如果没有，至少要软限位 + 上电手动回中，防止电机顶死机构。
- 球控要求杆端随时能出力，所以 **EN 保持使能**（别释放力矩，否则球会把杆压下去）。

## 五、软件架构与迁移建议

从 vision/keil 迁移过来的是：**UART0 配置 + 环形缓冲 + 中断**（`ti_msp_dl_config.c/h` 的 UART 部分 + `empty.c` 里的 ring buffer 段）。其余全新写，建议至少分 3 个模块：

1. **串口解析**：行缓冲 → 收到 `\n` → `atof`；处理超时（如 300ms 无新数据 → 判丢球/掉线，PID 转安全模式）。
2. **电机驱动**：定时器产生 STEP + 梯形/S形加减速 + 软限位 + 零位。
3. **控制核心**：PID（PD为主+抗饱和）、目标轨迹生成（任务3是 0→+5→-5 的梯形速度轨迹，别用阶跃，否则必过冲）、状态机（待机/回中/寻零/运行/急停）。

## 六、建议的落地路线（里程碑）

## 一、G3507 引脚总表

| 功能 | G3507 引脚 | 对应模块引脚 | 说明 |
|------|-----------|-------------|------|
| **STEP** | **PA8**（TIMA0_CCP0） | TMC2208 STEP | 定时器 PWM 输出步进脉冲 |
| **DIR** | **PA16** | TMC2208 DIR | 普通 GPIO，高/低定方向 |
| **EN** | **PA17** | TMC2208 EN | 普通 GPIO，**低有效**（拉低=使能） |
| MS1 | 接 **GND** | TMC2208 MS1 | 硬接 GND = 1/8 细分（1600 步/转） |
| MS2 | 接 **GND** | TMC2208 MS2 | 同上 |
| PDN_UART | **悬空** | TMC2208 PDN | STEP/DIR 模式不用，悬空即可 |
| CLK | **悬空** | TMC2208 CLK | 用内部时钟 |
| UART0 TX | **PA10** | MaixCam RX (A22) | 115200 |
| UART0 RX | **PA11** | MaixCam TX (A21) | 115200 |
| (可选调试) | PA0 / PA1 | OLED (I2C0 SDA/SCL) | 想显示球坐标/状态就用，把 vision 里的 SSD1306 搬过来 |

> PA8 若你的板子没引出，备选 **PA12**（PINCM34，TIMA0_CCP3 / TIMG0_CCP0）也能当 STEP。DIR/EN 也可用 PA21/PA22 替换。避开 PA19/PA20（SWD 调试口）。
