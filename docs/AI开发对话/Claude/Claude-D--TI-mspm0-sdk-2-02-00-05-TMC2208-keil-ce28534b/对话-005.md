## 驱动原理

- **STEP**：TIMA0 PWM 输出 PA8，一个 PWM 周期 = 一个步进脉冲（50% 占空比，`LOAD=interval-1, CC=LOAD/2`）；
- **加减速**：TIMA0 zero 事件中断每个脉冲触发一次，在里面算梯形曲线（Euler 离散），动态改 LOAD/CC 实现平滑加速→匀速→减速；
- **DIR/EN**：PA13/PA15 GPIO，方向先定再发脉冲；EN 低有效；
- **软限位**：默认 ±40000 步（=±50mm），防顶死丝杆。

## 上电后会发生什么

电机在 **±5mm（±4000 步）之间来回往复移动**，OLED 显示：
```
TMC2208 STEPPER
State:MOVING   EN:ON
Pos: +5.00 mm
Stp:+04000
Tgt:-04000
Spd: 8000 /s
Dir:+  (1/8, 800/mm)
```
Spd 你会看到它从 200 爬到 8000 再降下来——那就是加减速曲线在工作。
