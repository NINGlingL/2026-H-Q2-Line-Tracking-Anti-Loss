## 推荐：Click'n'Translate

| 对比 | PopTrans | Click'n'Translate |
|------|----------|-------------------|
| 安装方式 | Python + venv + 依赖 + 模型 | **解压即用**，单文件 exe |
| 大小 | ~1.5GB（模型+依赖） | ~50MB |
| 翻译 | 离线腾讯模型 | Google + 离线 Argos 可选 |
| OCR | RapidOCR | Windows 原生 + Tesseract |
| 快捷键 | `Ctrl+Alt+Q` 划词 / `Ctrl+Alt+E` OCR | `Ctrl+Alt+T` OCR翻译 / `Ctrl+Alt+C` OCR复制 |

下载页面：https://github.com/jabrailkhalil/clickntranslate/releases
