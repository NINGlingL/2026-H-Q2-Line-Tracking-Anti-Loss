## 助手

先别急着准备工具——得先搞清楚你想做什么样的 APP。不同类型的 APP，工具完全不同：

| APP 类型 | 举例 | 需要的工具 |
|----------|------|-----------|
| 🖥️ Windows 桌面应用 | 翻译工具、串口助手 | VS Code / Visual Studio，C# 或 Python |
| 🌐 Web 应用 | 网页版计算器、数据看板 | VS Code，HTML/CSS/JS 或 React |
| 📱 手机 APP | 记账工具、学习助手 | Flutter / React Native / 原生开发 |
| 🔧 嵌入式工具 | STM32 上位机、串口调试 | 同桌面应用，可能 + Qt |
| 🤖 命令行工具 | 自动化脚本、批处理 | 纯文本编辑器 + Python/Go |

所以先回答几个问题：

1. 想做什么 APP？（具体功能）
2. 在什么平台用？（电脑 / 网页 / 手机）
3. 有编程语言偏好吗？（你学过 Python 的话，可以优先用 Python）

说清楚了再告诉你需要准备什么。

## 先确认三件事

### 1. 你的手机是 Android 还是 iPhone？

| 平台 | HC-05 支持情况 |
|------|---------------|
| Android | ✅ 原生支持 SPP 蓝牙 |
| iPhone | ❌ **不支持**经典蓝牙 SPP，只能连 BLE（低功耗蓝牙）模块 |

> 如果是 iPhone，HC-05 根本连不上，得换成 HM-10 或 BT-04 这类 BLE 模块。

### 2. 想实现什么交互功能？

- 串口收发（类似串口助手的无线版）？
- 控制引脚（发指令开关 LED、读传感器数据）？
- 还是搭配你之前的小车/Balance-Car 项目？
