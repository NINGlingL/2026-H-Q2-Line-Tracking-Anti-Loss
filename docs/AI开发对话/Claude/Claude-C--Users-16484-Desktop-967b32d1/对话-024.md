## 使用步骤

### 1. 切到工作目录

```bash
cd D:/数学建模
```

### 2. 一句话启动

在 Claude Code 里说：

> `/1start-mathmodel 帮我开始做数学建模`

或者更具体：

> `/1start-mathmodel 我要参加华数杯，题目PDF在 D:/数学建模/华数杯/A题.pdf`

### 3. 回答 4 个问题

启动后它会问你：

| 问题 | 你的回答 |
|------|---------|
| 排版引擎？ | Typst（推荐） / LaTeX |
| 竞赛类型？ | 华数杯 / 国赛 / 美赛... |
| 论文语言？ | 中文 |
| 子问题数？ | 已知 3 个 / 待分析 |

### 4. 自动执行 6 阶段

```
/1start-mathmodel       ← 你启动
     │
     ├── /2analysis-modeling   → 读题 → 拆解 → 选模型 → 出建模报告
     ├── /3coding-visual       → 写代码 → 跑结果 → 画数据图
     ├── /4drawio              → 画技术路线图、流程图
     ├── /5writing             → 写论文（参考建模报告 + 结果 + 图表）
     └── /6verity              → 9步验收 → 出提交版PDF
```

每个阶段都会在工作目录下生成文件：

```
D:/数学建模/
├── plan.md                    ← 总体方案
├── todo.md                    ← 待办进度
├── ANALYSIS_MODELING_REPORT.md ← 建模报告
├── RESULTS_REPORT.md          ← 计算结果
├── figures/                   ← 图表
├── drawio/                    ← 流程图
├── paper/                     ← 论文草稿
└── final_verify_report.md     ← 验收报告
```

## 和 mathmodel-skill 的区别

| | MathModelAgent | mathmodel-skill |
|------|------|------|
| 启动 | `/1start-mathmodel` | 说"开始建模" |
| 交互 | 问 4 个问题，之后全自动 | 10 个阶段，每步都要你确认 |
| 代码 | 自己写+自己跑 | 只生成代码，不执行 |
| 适合 | 出论文 | 学流程 |
