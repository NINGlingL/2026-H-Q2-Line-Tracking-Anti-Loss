## 怎么用

### 第一次启动

双击 `启动PopTrans.bat`，**首次运行会自动下载翻译模型（约 1.13GB）**，需要等几分钟。之后就可以离线用了。

### 日常使用

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| **选中翻译** | `Ctrl+Alt+Q` | 在任何地方选中文字，按快捷键弹窗翻译 |
| **OCR 截图翻译** | `Ctrl+Alt+E` | 框选屏幕区域，识别图片/PDF/视频中的文字并翻译 |
| 关闭弹窗 | `Esc` 或点击窗外 | — |

程序启动后缩到系统托盘（右下角图标），不占任务栏。右键托盘图标可以改快捷键。

### 和 Snipaste 配合

1. Snipaste 截图 → 贴到屏幕上
2. `Ctrl+Alt+Q` → 划选贴图上的文字 → 翻译弹窗

或者直接 `Ctrl+Alt+E` → 框选屏幕上任意区域 → OCR + 翻译。
