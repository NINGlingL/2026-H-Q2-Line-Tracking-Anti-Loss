## 助手

它是 **一套 Skill 集合**，不是 MCP。

---

安装方式就说明了它的本质：

```bash
npx skills add jihe520/MathModelAgent --all
```

安装后你得到的是 6 个独立的 Skill 文件，放在 `~/.claude/skills/` 下：

| 子 Skill | 干的活 |
|----------|--------|
| `1start-mathmodel` | 总控入口，一键启动全流程 |
| `2analysis-modeling` | 分析题目、选模型（建模手） |
| `3coding-visual` | 写代码、跑结果、画图（代码手） |
| `4drawio` | 画技术路线图、流程图 |
| `5writing` | 写论文（论文手） |
| `6verity` | 9 步自动验收 |

## 和你已有的对比

| | MathModelAgent | mathmodel-skill |
|------|------|------|

## 总结

```
不是 MCP Server（不操作外部工具）
不是独立软件
就是 6 个 SKILL.md 文件 + 3 个 Agent 配置文件
```

**相当于 mathmodel-skill 的"增强版"**——多了代码自动执行、DrawIO 画图、9 步验收、华数杯模板这些功能。但交互上偏自动，不像 mathmodel-skill 那样一步步教你。
