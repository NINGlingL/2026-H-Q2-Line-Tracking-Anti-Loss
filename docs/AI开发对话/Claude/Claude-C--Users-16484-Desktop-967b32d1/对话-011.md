## 二、用 mathmodel-skill 打比赛

这个 skill 是**10 阶段全流程**的竞赛辅助。触发方式很简单——对我说：

> **"开始建模"** 或 **"我准备参加华数杯"**

然后它会：

1. **先问你 5 个问题**：哪个竞赛、什么题、队员情况、截止时间、题目 PDF
2. **然后按阶段推进**：

```
S0 预检    → 检查工具链、模板是否就绪
S1 赛题解析 → 分析题目、拆解问题、查文献
S2 模型选择 → 对比候选模型、建决策树
S3 数据处理 → 清洗、异常检测、标准化
S4 基准模型 → 跑基线、灵敏度分析
S5 进阶调优 → 参数优化、模型融合
S6 论文草稿 → 摘要+正文+附录
S7 可视化   → 图表美化、论文配图
S8 终稿审核 → 查重检查、一致性校验
```

3. **全程问答式**——你不需要敲任何命令，只需要选编号（1/2/3/4）或回复简单信息
