## 一、学知识 —— 透彻理解数学建模方法

### 强烈推荐：[panpanc/math-skills](https://github.com/panpanc/math-skills)

专门为**结构化数学学习**设计的 skill 套装，13 个子技能。最匹配你说的"清楚透彻地将方法讲出来"：

| 子技能 | 做什么 | 你的使用场景 |
|--------|------|-------------|
| `bottom-up` | 从微积分/线代基础开始，逐步构建一个概念 | 学"主成分分析"时，从协方差矩阵推导讲起 |
| `deep-explain` | 解释每个符号、构造选择、思维模型和常见困惑点 | 看不懂论文里的优化模型时，让它拆解 |
| `dependency-map` | 画一个知识点的前置依赖 DAG 和学习路径 | 学"图论优化"前，先看需要什么前置知识 |
| `mental-models` | 提取10-20个可复用的推理模式 | 总结"什么情况下用灰色预测 vs 时间序列" |
| `reinvent-from-scratch` | 通过失败的尝试→修正→迁移来重新发现一个概念 | 深入理解一个算法为什么这样设计 |
| `abstraction-levels` | 从具体到抽象看同一个概念 | 理解"拉格朗日乘子法"从几何直觉到优化理论 |
| `field-mental-models` | 映射整个数学领域的核心推理模式 | 全面梳理数学建模的思维方式 |

**安装：**
```bash
git clone https://github.com/panpanc/math-skills.git ~/.claude/skills/math-skills
```
