## 关于你的国产核心板

和 TI 官方 LaunchPad 的区别只有两点：

- **没有板载调试器** → 需要一个 DAP-Link（~15 元）或 J-Link OB（~30 元），通过 SWD 四根线连接
- **LED/按键引脚可能不同** → 用 SysConfig（双击 `.syscfg`）修改引脚映射即可
