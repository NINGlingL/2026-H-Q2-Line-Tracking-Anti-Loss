### 居中显示文字

```c
// 8x6 ASCII: x = (128 - strlen*6) / 2
uint8_t len = strlen("Center Me");
OLED_PrintASCIIString((128 - len*6)/2, 28, "Center Me", &afont8x6, OLED_COLOR_NORMAL);

### 滚动显示长文字

```c
static int16_t scroll_x = 128;
OLED_NewFrame();
OLED_PrintASCIIString((uint8_t)scroll_x, 28, "Scrolling text...", &afont12x6, OLED_COLOR_NORMAL);
OLED_ShowFrame();
scroll_x -= 2;
if (scroll_x < -120) scroll_x = 128;
HAL_Delay(30);
```

### 闪烁效果

```c
static uint8_t visible = 1;
static uint32_t last_tick = 0;
if (HAL_GetTick() - last_tick > 500) {  // 每500ms翻转
    visible = !visible;
    last_tick = HAL_GetTick();
}
OLED_NewFrame();
if (visible) OLED_PrintASCIIString(40, 28, "BLINK!", &afont12x6, OLED_COLOR_NORMAL);
OLED_ShowFrame();
```

## 八、常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 屏幕全黑 | 接线错误 / 地址不对 | 检查 3.3V 供电，试试 `0x7A` |
| 编译报 `#endif without #if` | `hal_detect.h` bug | 已修复，确保用最新版 |
| 中文显示空白 | 字模没生成或 `len` 不对 | 确认 `font16x16` 的 `len` |
| 中文只显示第一个字 | UTF-8 字符串不对 | 用 `\xe5\xba\x8a...` 格式 |
| 画面闪烁 | `ShowFrame` 太慢 | `HAL_Delay(16)` 约 60fps |
| 想把屏幕倒过来 | 初始化参数 | 改 `ssd1306.c` 中 `0xC8`→`0xC0` |

---

总结一句话：**复制 5 个文件 → CubeMX 开 I2C1 → `OLED_Init` → `NewFrame/画/ShowFrame` 循环 → 中文走取模工具**。这套驱动库可以用于 F0/F1/F4/G0/H7… 所有 STM32 系列，换芯片不用改驱动。

## 用户

那我是否可以取完模后将数据储存到font.c文件中然后调用OLED库将图像或者字符打出来？

## 助手

**完全可以！** 取模工具 → font.c → 调用 API，这就是这套驱动库的标准工作流。不仅中文，**图片/图标也可以**。

---

## 两种用法：文字 vs 图片

### 一、文字（中文字符）

你在取模工具中选 **16×16 中文字体**，生成的数据加到 `zh16x16` 数组里，然后调用：

```c
OLED_PrintString(x, y, "你的文字", &font16x16, OLED_COLOR_NORMAL);
```

### 二、图片/图标

你在取模工具中选 **图片取模**，生成的数据可以两种方式存储：

#### 方式A：存成 `Image` 结构体（推荐，已有示例）

打开 `font.c`，末尾已经有现成的例子——`bilibiliImg`：

```c
// font.c 中已有的示例
const uint8_t bilibiliData[] = {
    0x00,0x00,0x00,0x00,0x80,0x80, ...
};
const Image bilibiliImg = { 28, 28, bilibiliData };
```

在 `font.h` 中声明：

```c
extern const Image bilibiliImg;
```

然后 main.c 中直接画：

```c
OLED_DrawImage(50, 18, &bilibiliImg, OLED_COLOR_NORMAL);  // 在(50,18)画28×28的图
```

取模工具 → 图片取模 → 设置宽度高度 → 生成数据：

```c
// 1. 在 font.c 中存数据
const uint8_t myLogoData[] = {
