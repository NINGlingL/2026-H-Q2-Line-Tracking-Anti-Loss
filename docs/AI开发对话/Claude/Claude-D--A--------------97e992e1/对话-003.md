### 2.3 取消注释

生成后，你已经有了 `#include "i2c.h"` 和 `MX_I2C1_Init()` 的调用。我把 main.c 中的注释提醒去掉——你直接在 main.c 中删除这两处的 `/* */` 注释符号即可：

**位置1** — 文件顶部的 include：
```c
/* ⚠️ 在 CubeMX 中启用 I2C1 后, 取消下一行的注释 */
/* #include "i2c.h" */        // ← 删除 /* 和 */，变成 #include "i2c.h"
```

**位置2** — main() 函数中的初始化：
```c
/* ⚠️ 需要在 CubeMX 中启用 I2C1 后重新生成代码!
 *    然后取消下一行注释: */
/* MX_I2C1_Init(); */          // ← 删除 /* 和 */，变成 MX_I2C1_Init();
```

> 💡 **如果 CubeMX 生成代码后这两行已经是取消注释的状态**，那就不用改了。

## 第 3 步：硬件接线

在烧录程序之前，先把 OLED 屏幕接好：

```
SSD1306 模块        STM32F103C8T6 (BluePill)
───────────         ──────────────────────
  VCC    ────────   3.3V (不是5V!)
  GND    ────────   GND (任意GND引脚)
  SCL    ────────   PB6
  SDA    ────────   PB7
```

用杜邦线 4 根连接即可。

> ⚠️ **关键**：你的 OLED 模块背面一般有 I2C 地址选择电阻。如果 SA0 电阻在 **0x78** 位置就不用改代码；如果在 **0x7A** 位置，需要把 main.c 中的 `OLED_Init(&hi2c1, 0x78)` 改成 `OLED_Init(&hi2c1, 0x7A)`。
