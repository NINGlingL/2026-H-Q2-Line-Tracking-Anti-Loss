## 三、完整 API 速查表

### 3.1 初始化与控制

| 函数 | 说明 |
|------|------|
| `OLED_Init(&hi2c1, 0x78)` | 初始化，绑定 I2C1，地址 0x78 |
| `OLED_DisPlay_On()` | 唤醒屏幕 |
| `OLED_DisPlay_Off()` | 关闭屏幕（低功耗） |
| `OLED_SetColorMode(mode)` | `OLED_COLOR_NORMAL`（黑底白字）或 `OLED_COLOR_REVERSED`（反色） |

### 3.2 帧操作

| 函数 | 说明 |
|------|------|
| `OLED_NewFrame()` | 清空显存（1024 字节归零） |
| `OLED_ShowFrame()` | 整帧推送到屏幕（8 页 × 128 列） |

### 3.3 像素

| 函数 | 说明 |
|------|------|
| `OLED_SetPixel(x, y, color)` | 画一个点，x: 0~127，y: 0~63 |

### 3.4 几何图形

| 函数 | 说明 |
|------|------|
| `OLED_DrawLine(x1,y1, x2,y2, color)` | 直线 |
| `OLED_DrawRectangle(x, y, w, h, color)` | 空心矩形 |
| `OLED_DrawFilledRectangle(x, y, w, h, color)` | 实心矩形 |
| `OLED_DrawCircle(x, y, r, color)` | 空心圆 |
| `OLED_DrawFilledCircle(x, y, r, color)` | 实心圆 |

## 五、添加自定义中文的流程

### 5.1 取模工具

打开 **https://led.baud-dance.com** → 文字取模 → 16×16 中文：
- 取模方式：**列行式**
- 字节序：**高位在前（MSB）**
- 输出格式：**C 语言数组**

### 5.2 输入你要的所有不重复汉字

比如 "你好世界" → 输入框输入这 4 个字。

### 5.3 把生成的数据填入 font.c

打开 `Core/Src/font.c`，找到末尾：

```c
// 替换前：
const uint8_t zh16x16[][36] = {
    /* 0 波 */ {...},   // ← 删掉这些旧的
    /* 1 特 */ {...},
    /* 2 律 */ {...},
    /* 3 动 */ {...},
};
const Font font16x16 = {16, 16, (const uint8_t *)zh16x16, 4, &afont16x8};
//                                                            ↑ 这里 4 = 旧字符数

// 替换后：
const uint8_t zh16x16[][36] = {
    /* 0 你 */ {...},   // ← 粘贴取模工具生成的数据
    /* 1 好 */ {...},
    /* 2 世 */ {...},
    /* 3 界 */ {...},
};
const Font font16x16 = {16, 16, (const uint8_t *)zh16x16, 4, &afont16x8};
//                                                            ↑ 改成新字符数
```

> 关键：**`len` 必须改成实际字符数量**，顺序要和取模工具输入的顺序一模一样。

### 5.4 在 main.c 中使用

```c
OLED_PrintString(0, 0, "你好世界", &font16x16, OLED_COLOR_NORMAL);
```
