### 电赛角度怎么选

电赛 4 天 3 夜，省半天时间意味着你可以多调试一轮、多写一版报告、多睡两小时觉。这 35 块钱的差价在比赛里是最值的投资。

**但你不白学**——用 MPU6050 写一遍姿态解算，你会真正理解四元数、互补滤波、IMU 的特性。以后遇到自带解算模块不够用的情况（比如需要更高采样率、需要融合 GPS），你就能自己上了。

所以结论：**比赛用自带解算的，平时学的时候自己写一遍。两者都要会。**

## 电赛控制题陀螺仪推荐

### 首选：WT901 / HWT101（串口 9 轴模块）

| 项目 | 参数 |
|------|------|
| 价格 | 50~60 元 |
| 接口 | UART 串口 |
| 输出 | **直接读 roll/pitch/yaw 角度值** |
| 磁力计 | ✅ 有，yaw 不漂 |
| 代码量 | ~30 行 |

```
模块一发 → 串口收到 → 直接就是角度 → 拿去控制
你不需要写一行姿态解算代码
```

---

### 次选：ICM-20948（SPI 9 轴芯片）

| 项目 | 参数 |
|------|------|
| 价格 | 25~35 元（模块板） |
| 接口 | SPI（10MHz）或 I2C |
| 输出 | 原始数据，需自己写 Mahony |
| 磁力计 | ✅ 有 |
| 噪声 | 比 MPU6050 低一个数量级 |

---

### 备选：MPU6050（6 轴）

| 项目 | 参数 |
|------|------|
| 价格 | 8~15 元 |
| 接口 | I2C 400kHz |
| 输出 | 原始数据，需自己写 Mahony |
| 磁力计 | ❌ 没有，**yaw 每秒漂 1~2°** |
| 适用 | 只需 roll/pitch，或任务不超过 30 秒 |

---

### 一句话总结

| 场景 | 用什么 |
|------|--------|
| 需要航向精准（小车直行、云台瞄准） | **WT901 / HWT101** |
| 需要高性能 + 自己写融合 | **ICM-20948** |
| 只要倾角、任务短 | MPU6050 够用 |
| 做无人机 | ICM-42688-P 或飞控自带 IMU |
