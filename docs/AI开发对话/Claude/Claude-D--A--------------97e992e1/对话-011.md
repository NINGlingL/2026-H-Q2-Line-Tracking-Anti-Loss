## 怎么看偏差 & 怎么调

烧录后看屏幕，判断方向和大小：

| 你看到的现象 | 改这个值 |
|-------------|---------|
| 图标偏右，左边空白多 | `DISP_OFFSET_X` → `-2` |
| 图标偏左，右边空白多 | `DISP_OFFSET_X` → `+2` |
| 图标偏下，上方空白多 | `DISP_OFFSET_Y` → `-2` |
| 图标偏上，下方空白多 | `DISP_OFFSET_Y` → `+2` |

修改在 main.c 顶部这两行，改完重新编译烧录：

```c
#define DISP_OFFSET_X   0    // ← 水平偏移 (改这里)
#define DISP_OFFSET_Y   0    // ← 垂直偏移 (改这里)
```

**十字线交叉点就是屏幕几何中心 (64, 32)**，图标中心应该和它重合。你对比一下十字线和图标的相对位置，告诉我图标往哪个方向偏了几像素，我帮你调。

## 🔧 CubeMX 需要确认的配置

在 `01-IDE.ioc` 中检查：

| 外设 | 配置 |
|------|------|
| **I2C2** | 模式=I2C, PB10=SCL, PB11=SDA, 速度=400kHz |
| **PA10** | GPIO_EXTI10, 下降沿触发 (Falling), 上拉(Pull-up) |
| **NVIC** | EXTI line 10 中断使能打勾 ✅ |

> 如果还没配，配好后 **Generate Code** 重新生成。
