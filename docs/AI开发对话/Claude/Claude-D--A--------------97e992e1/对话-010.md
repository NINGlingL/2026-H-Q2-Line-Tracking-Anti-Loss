## 实际操作演练：画一个自定义图标

假设你在 **https://led.baud-dance.com** 取模一个 16×16 的笑脸图标：

### 第 1 步：取模工具设置

| 参数 | 值 |
|------|-----|
| 类型 | **图片取模** |
| 宽度 | 16 |
| 高度 | 16 |
| 取模方式 | 列行式 |
| 字节序 | 高位在前 |

### 第 2 步：把数据放进 font.c

```c
// 加到 font.c 末尾 (bilibiliImg 后面)

const uint8_t smileData[] = {
    0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,
    0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,
    0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,
    0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,
};

const Image smileImg = { 16, 16, smileData };
```

### 第 3 步：在 font.h 中声明

```c
extern const Image smileImg;
```

### 第 4 步：在 main.c 中调用

```c
OLED_NewFrame();
OLED_DrawImage(56, 24, &smileImg, OLED_COLOR_NORMAL);  // 屏幕中央画16×16笑脸
OLED_ShowFrame();
```

## 一个工程里可以同时放很多资源

`font.c` 就像一个资源仓库，你可以往里堆任意多的东西：

```
font.c 文件结构：
├── ascii_8x6[]         ← 内置 ASCII 8×6 字模
├── ascii_12x6[]        ← 内置 ASCII 12×6 字模
├── ascii_16x8[]        ← 内置 ASCII 16×8 字模
├── ascii_24x12[]       ← 内置 ASCII 24×12 字模
├── zh16x16[][]         ← 你的中文字库 (自己加)
├── bilibiliData[]      ← 内置示例图片
├── smileData[]         ← 你的图标1
├── heartData[]         ← 你的图标2
├── logoData[]          ← 你的 logo
└── ...
```

## API 对比一览

| 你想显示的 | 取模工具选 | 存到 font.c 的类型 | 调用函数 |
|-----------|-----------|-------------------|---------|
| 英文字符 | 不需要（内置） | 不用改 | `OLED_PrintASCIIString()` |
| 中文字符 | 16×16 中文取模 | `zh16x16[][]` + 改 `font16x16` | `OLED_PrintString()` |
| 任意图片/图标 | 图片取模 | `Image` 结构体 | `OLED_DrawImage()` |

---

所以回答你的问题：**是的，取模 → 存 font.c → 调用 OLED_DrawImage / OLED_PrintString → 屏幕上就出来了。** 不管是文字还是图案，流程完全一样。
