## 🔄 程序工作流程

```
启动
 ├─ OLED_Init(&hi2c1)       → 初始化屏幕
 ├─ MPU6050_Init(&hi2c2)    → 复位IMU → 校准零偏 → 配置200Hz
 ├─ 显示启动画面 (1.5s)
 │
 └─ 主循环:
      │
      ├─ PA10 中断触发? ──→ mpu_data_ready = 1
      │                         ↓
      ├─ mpu_data_ready == 1? ──→ MPU6050_GetAttitude()
      │    (含 Mahony 互补滤波姿态解算)
      │
      └─ OLED 刷新 (30fps)
          显示 accel/gyro/roll/pitch/yaw/temp
```

两种读取模式自动切换：
- **INT 正常工作** → 每秒读 200 次（中断驱动）
- **INT 未触发超过 50ms** → 自动降级为定时轮询

## 🛠️ 编译前检查

1. 确认 `Core/Src/filter.c` 在工程中，如果没有 → 从 `通用驱动库` 复制过来
2. 确认 CubeMX 中生成了 `MX_I2C2_Init()` 和 PA10 的 EXTI 初始化
3. **链接器设置**：如果报 `undefined reference to sqrtf/sinf`，在 CubeIDE 中：
   - 右键工程 → Properties → C/C++ Build → Settings → MCU GCC Linker → Miscellaneous → Linker flags 加 `-lm`

现在去编译烧录，接线正确的话屏幕上就会实时显示 MPU6050 的 6 轴数据 + 姿态角。
