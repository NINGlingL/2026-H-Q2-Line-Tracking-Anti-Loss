### 核心问题：MCP 工具未配置

当前 `embedded-debugger-mcp` 只有 CLI 模式可用（doctor、probes list、config show），**连接芯片、读写内存、故障诊断**等调试功能全在 MCP 工具里，但这些工具还没有配置到你的 MCP 客户端中。

你需要在 Clawd 的 MCP 服务器配置里加一项：

```json
{
  "embedded-debugger": {
    "command": "C:\\Users\\16484\\.cargo\\bin\\embedded-debugger-mcp.exe",
    "args": ["serve"]
  }
}
```

这个 `serve` 子命令会启动 MCP 服务端（通过 stdio 通信），之后 `list_probes`、`connect`、`read_memory`、`diagnose_fault`、`unwind_exception` 等工具就全部可用了。
