   - 现在改成 `uint16_t` 下标，手动按 2048 回绕。

   - 新增 `dly_poll()`；
   - 主循环末尾的 `100ms` 延时期间也持续调用 `EightIR_Poll()`；
   - 开机 `1000ms` 等待期间也持续处理串口。
