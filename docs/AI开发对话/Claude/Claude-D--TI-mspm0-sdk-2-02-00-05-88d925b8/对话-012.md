### 控制架构

```
循迹传感器 → 位置误差 → PID(微分onMeasurement+积分分离+NaN保护)
    ↓                          ↓
 OLED仪表盘              差分驱动: L=base-pid, R=base+pid
 (5Hz 刷新)                    ↓
串口CSV输出               TB6612 → 左/右电机
(10Hz)                         ↓
                          编码器反馈 (实时计数)
```

### OLED 仪表盘

```
LS: 3 trig  Pos:+25     ← 循迹状态
1 2 3 4 5               ← 传感器编号
. . X X .               ← 触发状态
L:+350 R:+450           ← 左右PWM
Pos:+25  PID:+100       ← 位置+PID输出
EL:1234  ER:1250        ← 编码器计数
[RUNNING]               ← 运行状态
```

### 你要做的

1. **SysConfig 生成代码** → 打开 `empty.syscfg` → 确保外设配置正确 → 生成 `ti_msp_dl_config.h/.c`
2. **Keil 编译** → 打开工程 → F7 Rebuild
3. **调 PID** → 场地实测，先调 Kp (从 1.0 开始)，再加 Kd，最后加 Ki
4. **极性确认** → `line_sensor.c` 顶部的 `LS_ACTIVE_LOW` 根据实际模块改 0 或 1
