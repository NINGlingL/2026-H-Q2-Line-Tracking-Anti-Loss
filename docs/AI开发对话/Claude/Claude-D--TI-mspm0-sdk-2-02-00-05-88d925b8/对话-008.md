### ⚠️ ssd1306.c 和你的配置不兼容

`ssd1306.c` 里硬编码用的是 `I2C_1_INST`，但你 SysConfig 生成的是 `OLED_INST`（映射到 I2C0）。直接用编译不过。

**需要改 4 处**（把 `I2C_1_INST` → `OLED_INST`）：
```c
// ssd1306.c 第114行
DL_I2C_fillControllerTXFIFO(OLED_INST, data, len);    // 原来是 I2C_1_INST
// 第116行  
DL_I2C_startControllerTransfer(OLED_INST, ...);        // 原来是 I2C_1_INST
// 第118行
while (DL_I2C_getControllerStatus(OLED_INST) & ...);   // 原来是 I2C_1_INST
// 第119行
while (!(DL_I2C_getControllerStatus(OLED_INST) & ...)); // 原来是 I2C_1_INST
// 第120行
DL_I2C_flushControllerTXFIFO(OLED_INST);               // 原来是 I2C_1_INST
```

改完之后，`empty.c` 的循迹显示代码可以这样写：

```c
#include "ti_msp_dl_config.h"
#include "ssd1306.h"

// 循迹传感器引脚掩码 (全部在 GPIOB 上)
#define LS_MASK (DL_GPIO_PIN_5 | DL_GPIO_PIN_6 | DL_GPIO_PIN_7 | \
                 DL_GPIO_PIN_8 | DL_GPIO_PIN_9)
#define LS_SHIFT 5  // 从 PB5 开始

int main(void)
{
    SYSCFG_DL_init();
    SSD1306_Init();
    SSD1306_Clear();

    while (1) {
        // 一次性读取 5 路循迹
        uint32_t raw = DL_GPIO_readPins(GPIOB, LS_MASK);
        
        // 解码: 位[5:9] = 对应 PB5~PB9
        uint8_t status = (uint8_t)((raw >> LS_SHIFT) & 0x1F);

        // 显示到 OLED
        SSD1306_ShowString(0, 0, "Xun Ji Status");
        SSD1306_ShowString(1, 0, "1 2 3 4 5");
        
        char line[12];
        for (int i = 0; i < 5; i++) {
            // 假设 LOW=触发(黑线), HIGH=未触发(白底)
            line[i * 2]     = (status & (1 << i)) ? 'O' : 'X';
            line[i * 2 + 1] = ' ';
        }
        line[10] = '\0';
        SSD1306_ShowString(2, 0, line);
        
        SSD1306_Update();
        
        delay_cycles(CPUCLK_FREQ / 10);  // 100ms 刷新
    }
}
```

OLED 上会显示类似这样：
```
Xun Ji Status
1 2 3 4 5
X O O X O      ← X=触发(黑线) O=未触发
```
