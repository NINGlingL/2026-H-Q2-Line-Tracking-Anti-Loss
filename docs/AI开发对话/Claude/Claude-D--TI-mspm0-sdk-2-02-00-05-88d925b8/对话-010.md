### `line_sensor` API 一览

| 函数 | 功能 | 返回值 |
|------|------|--------|
| `LineSense_Init()` | 初始化 | - |
| `LineSense_Read()` | 读 5 路原始值 | `bit[0:4]` 1=触发 |
| `LineSense_ReadChannel(n)` | 读第 n 路 (1~5) | 0 或 1 |
| `LineSense_IsOnLine()` | 是否有线 | true/false |
| `LineSense_GetTriggerCount()` | 触发了几路 | 0~5 |
| **`LineSense_GetPosition()`** | **加权位置 (PID 用)** | **-100~+100, 127=离线** |
| `LineSense_GetDirection()` | 简化方向 | -1/0/+1 |
| `LineSense_Display(page)` | OLED 显示 | 占 3 行 |
