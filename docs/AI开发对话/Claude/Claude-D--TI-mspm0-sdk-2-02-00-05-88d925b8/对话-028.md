**关于 MCP 工具：**

当前环境里只有 `mcp__stm32__*` 这套工具（来自 stm32 MCP 服务器），它只认 ST-Link 探针，不认 CMSIS-DAP。

你刚才配的 embedded-debugger MCP 服务器如果连接成功，会出现类似 `mcp__embedded__*` 的工具，支持：
- 连接探针 (`connect`)
- 读写内存 (`read_memory`, `write_memory`)
- 烧录 (`flash_program`, `flash_erase`)
- 读故障寄存器 (`diagnose_fault`)
- RTT 调试输出 (`rtt_attach`)

但目前这些工具都没出现——MCP 服务器没挂上。你要检查一下 MCP 配置吗？
