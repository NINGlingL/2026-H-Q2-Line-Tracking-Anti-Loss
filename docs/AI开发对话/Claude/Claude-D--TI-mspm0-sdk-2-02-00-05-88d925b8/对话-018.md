# 📋 2025 电赛 H 题 — 车载平衡滚球运动控制系统 完整解读

## 一、题目概述

设计一辆**自动循迹小车**，车上装有一个**弧形摆杆轨道**，轨道内有一颗**钢球**。小车沿黑色轨道行驶的同时，需要通过控制摆杆角度使钢球稳定在指定位置。同时需要**摄像头图传**系统记录行驶过程。

```

│              赛道 (俯视)              │
│    B ═══════════════ C               │
│   ╱                    ╲             │
│  ╱    半圆 R=0.5m       ╲            │
│ A ═══════════════ D      │            │
│  ↑                                       │
│  停车线 (5cm)              1.5m           │
│                                 │
│ 黑线宽: 1.8cm (±0.2cm)         │
│ AB=CD=1.5m   BC弧=DA弧=π×0.5≈1.57m │
│ 总圈长 ≈ 6.14m                │
└──────────────────────────────────────┘
```

## 三、核心挑战分析

这道题本质上是**两个控制系统的叠加**：

### 控制层 1：小车循迹 (你已经在做)

```
灰度传感器 → 位置误差 → PID → 差速电机
```

- 8 路灰度传感器循迹（题目限制只能用灰度模块）
- 编码器速度反馈（可选，用于精确速度控制）
- 纯循迹已经能拿 16+5+20 = 41 分

### 控制层 2：滚球平衡 (新问题)

```
球位置传感器 → 位置误差 → PID → 舵机角度 → 摆杆倾斜 → 球滚动
                                    ↑
                           IMU/编码器(角度反馈)
```

这是**球-杆系统 (Ball-on-Beam)**，经典控制理论问题：
- 摆杆倾斜 → 重力分量 → 球滚动加速度
- 本质是**不稳定系统**（球会自己滚走），必须闭环
- 需要**串级 PID**：外环(球位置 → 目标倾角) + 内环(倾角 → 舵机PWM)
