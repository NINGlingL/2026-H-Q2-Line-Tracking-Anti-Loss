## IMU/陀螺仪的两个用途

### 用途 1：辅助循迹（航向角控制）

灰度传感器只能告诉你"线在车的左边还是右边"，但看不到**车的朝向**。陀螺仪能补这个盲区：

```
灰度传感器: "线偏左 3cm"  →  横向误差
陀螺仪:     "车头偏右 15°" →  角度误差

两者融合 → 更稳的循迹
```

**具体场景：**
- **急弯**：灰度传感器来不及反应 → 陀螺仪提前感知车在转弯 → 提前纠正
- **丢线**：过十字路口/断线时灰度全灭 → 陀螺仪维持最后航向 → 惯性导航直行
- **直角弯**：灰度看到一个方向，陀螺仪看到车已转够 90° → 精确停止转弯

24 年电赛很多队伍就用 `灰度 + 陀螺仪` 串级 PID：
```
外环(位置PID):  灰度误差 → 目标角速度
内环(角速度PID): 陀螺仪Z轴 → 电机差速
```

### 用途 2：H 题核心——摆杆角度反馈（滚球平衡）

这才是 H 题里 IMU **不可替代**的作用：

```
          ┌─── 摆杆 ───┐
         /              \
        /    ○ 钢球      \
       /                  \
舵机 ──┘                  └── 转轴
       ↑                  
  IMU 贴在这里, 测摆杆倾角 θ
```

- 舵机转动 → 摆杆倾斜角度 θ
- 重力沿摆杆分量 = g·sin(θ) → 球滚动
- IMU 实时测量 θ → PID 内环反馈
- 摄像头/传感器测球位置 x → PID 外环反馈

**串级 PID 结构：**
```
目标球位置 → [位置PID] → 目标倾角 → [倾角PID] → 舵机PWM → 摆杆
                 ↑                         ↑
           球位置反馈(OpenMV)          倾角反馈(IMU/陀螺仪)
```
