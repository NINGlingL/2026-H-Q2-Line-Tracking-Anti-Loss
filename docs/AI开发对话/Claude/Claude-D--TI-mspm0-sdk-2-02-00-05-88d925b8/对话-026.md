## 用户

notfound 20948怎么接线？

## 助手

标准 8Pin 模块接线：

```
ICM20948 模块          MSPM0 G3507
┌──────────┐          ┌──────────┐
│ VCC      │──────────│ 3.3V     │
│ GND      │──────────│ GND      │
│ SDA      │──────────│ PA0      │  ← 与 OLED 的 SDA 并在一起
│ SCL      │──────────│ PA1      │  ← 与 OLED 的 SCL 并在一起
│ AD0      │──────────│ GND      │  ← 地址 = 0x68
│ INT      │          │ 不接      │  (可悬空)
│ NCS      │──────────│ 3.3V     │  ← I2C 模式需拉高
│ FSYNC    │          │ 不接      │
└──────────┘          └──────────┘
```

**关键点：**
- SDA/SCL **直接并在 OLED 的 PA0/PA1 上**（同一条 I2C 总线）
- AD0 接 GND → 地址 0x68（与 OLED 的 0x3C 不冲突）
- NCS 必须接 3.3V（使能 I2C 模式，否则默认 SPI 模式）
