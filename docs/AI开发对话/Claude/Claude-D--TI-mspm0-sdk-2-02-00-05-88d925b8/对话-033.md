模块支持三种模式对比：

| 模式 | 协议 | 波特率 | 能获取 | 接线 |
|------|------|:--:|------|------|
| **IO** | GPIO 直读 | 无 | 数字值 (0/1) | 8 根线 |
| **I2C** | I2C 0x12 | 400kHz | 数字值 (0/1) | 2 根线 |
| **串口** | UART | **115200** | 数字 + 模拟值 | 2 根线 |

串口协议格式：
```
$校准,模拟,数字#
$1,0,0#  → 校准模式
$0,1,0#  → 读模拟值
$0,0,1#  → 读数字值
```

你用哪种模式？IO 最简单（8 根线直读），I2C 最省线（地址 0x12），串口能拿模拟值。
