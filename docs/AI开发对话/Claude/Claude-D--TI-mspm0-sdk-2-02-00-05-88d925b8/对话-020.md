## 舵机 vs 丝杆+步进 对比

| 维度 | 舵机 (MG996R) | 丝杆 + 步进 + TMC2208 |
|------|:--:|:--:|
| **角度精度** | 0.5°~1° (模拟电位器反馈) | **0.02°** (256微步进 × 丝杆传动比) |
| **响应速度** | 0.17s/60° (慢) | 由丝杆导程决定，通常**更快** |
| **保持力矩** | 堵转发热，抖舵 | 静止力矩大，**不抖** |
| **噪音** | 齿轮噪音 | TMC2208 静音驱动 (StealthChop2) |
| **闭环** | 内置(电位器) | 开环，但可用 `StallGuard` 失速检测 |
| **控制接口** | 1 个 PWM | 2 个 GPIO (STEP + DIR) |
| **寿命** | 塑料齿轮易磨损 | 丝杆 + 步进 = **长寿命** |
| **机械复杂度** | 直接装 | 需要连轴器/丝杆/滑台 |

## 为什么 TMC2208 适合这道题

```
磁编码器测摆杆角 ──→ MSPM0 PID ──→ STEP/DIR ──→ TMC2208 ──→ 步进电机
       ↑                                                    │
       └──────── 丝杆推拉 ── 摆杆倾斜 ── 球滚动 ──────────────┘
```

### 1. 精度碾压
- 步进电机一圈 200 步 × TMC2208 256 微步 = **51200 步/圈**
- 丝杆导程 2mm → 每步 = 0.00004mm 线性位移
- 换算到摆杆角度（假设丝杆距转轴 10cm）：每步约 **0.002°** 
- 对比舵机：0.5°~1° → **精度差 250 倍**

### 2. 控制简单
TIMG 输出 PWM 脉冲给 STEP 脚 + 一个 GPIO 控制 DIR 方向：
```c
// TIMA0 输出 STEP 脉冲 (10kHz), PB4=DIR
DL_TimerA_setPeriod(TIMA0, 800);  // 每步 80us
DL_GPIO_setPins(GPIOB, DIR_PIN);  // 方向
```

### 3. TMC2208 额外功能
- **StallGuard**：检测失速（球卡住、丝杆堵转）
- **StealthChop2**：超静音（比赛现场不吵）
- **UART 配置**：可在线调电流/微步数

## 磁编码器 AS5600 (测摆杆角度)

MSPM0 已有 I2C 接口，AS5600 直接挂上去：
```
AS5600 磁铁贴在摆杆转轴上
I2C → PA10/PA11 (与 OLED 共用 I2C0 总线)
地址: 0x36 (与 SSD1306 0x3C 不冲突)
输出: 12bit 角度 (0~360°, 分辨率 0.088°)
```

OLED + AS5600 + ICM20948 三个设备全挂 I2C0，地址全不冲突：
```
SSD1306: 0x3C
AS5600:  0x36  
ICM20948: 0x68
```

## 引脚占用

步进方案**只需要 2 个 GPIO**（比舵机的 1 个 PWM 多 1 个）：

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA2 | STEP | TIMG7 CCP0 输出脉冲 |
| PA3 | DIR | GPIO 方向 |
| PA10 | I2C0_SDA | 共用，接 AS5600 |
| PA11 | I2C0_SCL | 共用 |

PA2/PA3 还空着，完美。
