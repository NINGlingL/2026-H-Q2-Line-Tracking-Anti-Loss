## 🔧 关键问题和修复

### 问题分析
您说Roll/Pitch/Yaw在-100到+100之间大幅摆动，这表明：
1. **陀螺仪积分导致的漂移** - Mahony滤波器在没有磁力计的情况下，Yaw会无限漂移
2. **数据读取不同步** - 分开读取加速度和陀螺仪导致数据时间戳不一致
3. **DLPF配置不当** - 带宽过高导致噪声过大

### 核心修改

#### 1. **ICM20948驱动重写** (`icm20948.c`)
```c
// ✅ 添加Bank切换机制
static void switch_bank(uint8_t bank)

// ✅ 一次性读取12字节（加速度+陀螺仪）

// ✅ 使用最低噪声DLPF配置
_w(BANK_2, ICM20948_GYRO_CONFIG_1, 0x39);  // DLPF=6 (5Hz带宽)
_w(BANK_2, ICM20948_ACCEL_CONFIG, 0x39);   // DLPF=6 (5Hz带宽)
```

#### 2. **放弃陀螺仪融合，只用加速度计** (`empty.c`)
```c
// ✅ 不再使用IMU滤波器和陀螺仪积分
// ✅ 直接从加速度计计算Roll和Pitch
Calculate_Angles(imu_data.ax, imu_data.ay, imu_data.az, &roll, &pitch);
```

**为什么这样做？**
- 加速度计可以直接测量重力方向，计算出**绝对角度**
- 陀螺仪只能测量**角速度**，需要积分，会产生**漂移**
- 没有磁力计的情况下，Yaw无法稳定
- 对于静态或慢速运动，加速度计足够准确

#### 3. **极强的低通滤波**
```c
roll_smooth = 0.98f * roll_smooth + 0.02f * roll;  // 98%旧值
```

#### 4. **降低所有频率**
- 数据采集：**20Hz**（每50ms）
- 显示刷新：**5Hz**（每200ms）
