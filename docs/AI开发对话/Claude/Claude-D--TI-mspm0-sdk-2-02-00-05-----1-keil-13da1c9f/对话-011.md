## 🎯 题目理解

**车载平衡滚球** = 小车上有一个平台，平台上放一个球，需要：
1. **保持球在平台中心平衡**
2. **小车可能需要沿着轨道行驶**
3. **同时控制球不掉落**

这需要：
- **加速度计和陀螺仪**：检测平台倾斜角度（Roll/Pitch）
- **循迹传感器**：让小车沿轨道行驶
- **可能不需要Yaw**：除非需要知道小车行驶方向

所以您之前说的循迹，是指**小车循迹行驶，同时保持球平衡**！
