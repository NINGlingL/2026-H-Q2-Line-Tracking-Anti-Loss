## 🎯 正确理解

### 轨道特点
- **1.5m直线 + 0.5m弧线** 组成闭合图形
- **小车会转弯**（在弧线部分）

### 转弯时的问题
如果**只用循迹传感器Position**：
- 小车转弯时，可能会因为惯性冲出轨道
- 需要**提前减速**或**根据转弯速度调整**

### 是否需要陀螺仪GZ？

**有两种方案：**

#### 方案1：只用循迹（简单）
```c
if (ir_state.position != 0) {
    // 偏离了，修正方向
    adjust_direction(ir_state.position);
}
```
- 优点：简单
- 缺点：转弯可能不稳定

#### 方案2：循迹 + 陀螺仪GZ（更稳定）
```c
if (fabsf(gz) > 50) {
    // 正在转弯，减速
    reduce_speed();
}
if (ir_state.position != 0) {
    // 偏离了，修正
    adjust_direction(ir_state.position);
}
```
- 优点：可以检测转弯，提前减速
- 缺点：需要GZ工作正常
