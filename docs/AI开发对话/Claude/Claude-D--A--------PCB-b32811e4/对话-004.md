### 4. 蜂鸣器驱动电路

```
B08 → R13(560Ω) → Q1(SS8050)基极
                    ├─ E → GND
                    └─ C → BUZZER1(-)
                             BUZZER1(+) → 3.3V
                    D2(1N5819) 反向并联在蜂鸣器两端 (续流保护)
              R14(10kΩ) B-E 下拉 (防止浮空)
```

## ✅ 焊后检验步骤

### 阶段0：目视检查（通电前必须做！）

| 检查项 | 方法 |
|------|------|
| 所有焊点是否饱满光亮 | 肉眼 + 放大镜 |
| 有无连锡(短路) | 重点检查 IC 引脚、排针相邻脚 |
| 二极管/电容极性 | SS54阴极白线、铝电解负极灰条 |
| 芯片方向 | U2(SOIC-8) pin1 小圆点、U6(SOT-223)方向 |
| 三极管方向 | Q1 SOT-23 单脚端=基极 |
| 有无漏焊 | 对照 PCB 丝印逐个核对 |

---

### 阶段1：短路检查（万用表 — 最关键！）

**用万用表电阻档/蜂鸣档，量以下各电源轨对 GND 的电阻：**

| 测试点 | 正常值 (近似) | 异常 |
|------|------------|------|
| +12V ↔ GND | > 几十 kΩ | 短路=0Ω → **绝不能通电！** |
| VCC+5V ↔ GND | > 几 kΩ | 短路 → 检查C5/C6/C7/C8/C9极性 |
| VCC+3.3V ↔ GND | > 几 kΩ | 短路 → 检查C10/C11/U6 |

> 具体方法：红表笔接地，黑表笔接各电源轨。蜂鸣器响 = 短路，必须排除！

---

### 阶段2：分步上电

#### 2.1 空载通电 (不插天猛星开发板)

1. **用可调电源设为 12V/限流200mA**，接到 DC1 或 CN1
2. 打开 U4 开关
3. 观察有无冒烟、异常发热

#### 2.2 测量各电源轨电压

| 测量点 | 期望电压 | 允许范围 |
|------|---------|---------|
| +12V (H7 pin1/3/5) | 输入电压 | 略低于输入 |
| VCC+5V (H6 pin1/3/5) | **5.0V** | 4.75V ~ 5.25V |
| VCC+3.3V (H5 pin1/3/5) | **3.3V** | 3.2V ~ 3.4V |
| VCCA+3.3V | **3.3V** | ≈ VCC+3.3V |

#### 2.3 检查指示灯

| LED | 说明 |
|-----|------|
| LED1 (绿) | 3.3V 上电即亮 |
| LED2 (绿) | 5V 上电即亮 |

> 如果 LED 不亮：检查 LED 方向是否焊反、R5/R6 限流电阻是否焊好。

---

### 阶段3：关键电路逐项验证

#### 3.1 U7 防反接

- 量 U7 阴极(有条纹端)对 GND = 应有 12V
- 量 U7 阳极(无条纹端) = 输入电压

#### 3.2 U2 降压 (TPS5450)

| 引脚 | 功能 | 期望值 |
|------|------|--------|
| Pin7 (VIN) | 输入 | ≈ 12V |
| Pin8 (PH) | 开关节点 | 可用示波器看到 500kHz PWM波形 |
| Pin4 (VSENSE) | 反馈 | ≈ 1.221V (内部基准) |
| Pin6 (GND) | 地 | 0V |

> 输出电压公式：Vout = 1.221 × (1 + R3/R4) ≈ 1.221 × (1 + 10k/3.16k) ≈ 5.08V ✓

#### 3.3 U6 LDO (AMS1117-3.3)

| 引脚 | 功能 | 期望值 |
|------|------|--------|
| Pin3 (VIN) | 输入 | ≈ 5V |
| Pin2/4 (VOUT) | 输出 | **3.3V** |
| Pin1 (GND) | 地 | 0V |

#### 3.4 蜂鸣器电路

用杜邦线将 B08 接 3.3V，蜂鸣器应发声。没有声音则检查：
- Q1 方向是否正确
- R13 560Ω 是否焊好
- BUZZER1 极性

#### 3.5 电池检测分压

- R1(33K) 上端接 +12V，中间接 ADC_battery(B25)
- 分压比：Vadc = +12V × R2/(R1+R2) = 12 × 10k/43k ≈ **2.79V** (安全在3.3V以内)

#### 3.6 按键

- 未按下：KEY1~4 ↔ GND 应为高阻/上拉
- 按下：KEY1~4 ↔ GND = **0Ω (短路)**

#### 3.7 电位器

- R9 两端 = 3.3V ↔ GND
- 中间脚(CODER)电压旋转时应在 0~3.3V 之间变化
