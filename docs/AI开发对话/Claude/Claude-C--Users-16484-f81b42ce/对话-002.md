### 第三层：左右轮分别做速度 PID

左轮用左编码器闭环：

```c
left_pwm = PID_Left(left_target_speed, left_encoder_speed);
```

右轮用右编码器闭环：

```c
right_pwm = PID_Right(right_target_speed, right_encoder_speed);
```

最后输出 PWM：

```c
Motor_SetPWM(left_pwm, right_pwm);
```

这个结构才是比较标准的：

> 循迹环负责“往哪边走”，左右速度环负责“每个轮子真的达到目标速度”。

## 4. 只用右轮编码器什么时候勉强可以？

只用右轮编码器不是绝对不能用。以下情况可以勉强接受：

1. 比赛要求不高，只要能跑完全程；
2. 速度较低；
3. 路线简单，急弯少；
4. 左右电机差异较小；
5. 循迹传感器反馈足够强，可以不断纠偏；
6. 左轮 PWM 经过人工补偿，比如左轮天生慢，就给左轮多一点 PWM。

这种方案可以叫：

> 单轮速度闭环 + 循迹误差修正

例如：

```c
base_pwm = Speed_PID(target_speed, right_encoder_speed);

left_pwm  = base_pwm - turn_output + left_compensation;
right_pwm = base_pwm + turn_output;
```

或者：

```c
right_pwm = Speed_PID(target_speed, right_encoder_speed);
left_pwm  = right_pwm + left_compensation - turn_output;
right_pwm = right_pwm + turn_output;
```

但是这类方案的问题是：

- 参数很依赖现场环境；
- 电池电压变化后容易变；
- 地面摩擦变化后容易变；
- 换电机、换轮胎、换车架后要重新调；
- 高速时容易发散或蛇形摆动。

所以它是一个**能跑的简化方案**，不是一个**严谨可靠的控制方案**。

## 5. 对你这个“车载平衡滚球运动控制系统”来说，建议更谨慎

你这个题目不是普通循迹小车，而是：

> 车载平衡滚球运动控制系统

这类系统通常不只是让车沿线走，还要考虑：

- 小车运动是否平稳；
- 球是否会滑动、滚落或偏移；
- 加速度是否过大；
- 转弯是否太急；
- 底盘速度和球的位置控制是否耦合。

如果只看右轮编码器，可能出现：

> 右轮速度稳定，但车体实际产生偏航或横向扰动，导致球的平衡控制变差。

尤其是转弯时，如果左右轮速度不受控，小车姿态变化不平滑，球就更容易晃。

所以对于这个题，**我更建议左右轮编码器都接入控制**。

## 6. 我的结论

### 如果问“能不能用？”

可以，低速、简单路线、临时调试时能用。

### 如果问“比赛方案是否推荐？”

不推荐。
