## 7. 如果你现在只有右轮编码器，怎么办？

如果硬件上左轮编码器暂时不能用，可以先这样做：

1. **右轮速度 PID 控制基础速度；**
2. **循迹 PID 控制左右 PWM 差值；**
3. **给左轮加一个静态补偿系数；**
4. **速度不要太高；**
5. **转向输出限幅；**
6. **实际跑直线，观察是否偏航；**
7. **再跑弯道，观察是否蛇形震荡。**

例如：

```c
base_pwm = Speed_PID(target_speed, right_encoder_speed);

turn = Line_PID(line_error);

left_pwm  = base_pwm - turn + left_motor_compensation;
right_pwm = base_pwm + turn;

Motor_SetPWM(left_pwm, right_pwm);
```

但这只是过渡方案。

---

最终建议：

> **如果你的车有左右两个编码器，就不要只用右轮。循迹时只用右轮速度可以作为临时简化，但对于稳定循迹和平衡滚球控制，左右轮都做速度闭环才更可靠。**
