## 二、水管小球部分怎么弄

这是题目的**核心难点**。题目明确要求：
- 摆杆用**4分PPR水管**（外径2cm，壁厚0.34cm，长25cm）改造
- 钢球直径约1cm
- 凹槽内壁必须光滑，**不允许做任何增摩擦改造**
- **球位置检测必须用摄像头**

### 2.1 水管改造（机械结构）

```
视角：俯视图（顶视图）
    
    左端(铰链固定)          中心O         右端(连接舵机)
    |----+----+----+----+----|----+----+----+----|
    0                      12.5                     25cm
    
    水管上方开槽 → 钢球在槽内滚动
    
    截面图（摆杆截面放大）：
       ___________         ← 上方开槽口（约1.2cm宽，能让摄像头看到球）
      /           \
     |   O 钢球    |       ← 球在管道内滚动
      \___________/
      外径2cm，内径≈1.32cm（减去壁厚）
```

**具体改造步骤**：
1. 取25cm长的4分PPR水管
2. 在水管**正上方**沿轴线开一个**矩形槽**（宽度约1.2-1.5cm，略宽于钢球直径），让钢球从上方放进去，且摄像头能从上方看到球的实时位置
3. 槽口边沿贴刻度线（0.1cm间距），**贴在凹槽外面**不要贴里面
4. 内壁保持原样——PPR管内壁本来就光滑，钢球可以自由滚动
5. 左端用铰链/合页固定在车体上，高度h≥5cm
6. 右端通过连杆连接到**角度控制机构**

### 2.2 摆杆角度控制机构

你有两个选择：

| 方案 | 执行器 | 优点 | 缺点 |
|------|--------|------|------|
| **方案A：舵机直驱** | 大扭力舵机(如MG996R/DS3235) | 响应快，控制简单 | 精度取决于舵机 |
| **方案B：丝杆滑轨+步进** | T6丝杆+28步进+TMC2208 | 精度极高，你已有硬件 | 响应稍慢 |

**推荐方案A+B混合**：用你现有的**T6丝杆滑轨+28步进电机+TMC2208驱动**做摆杆角度控制！

```
结构示意（侧视图）：

    摄像头(向下拍摄)
         ↓
    ═══[钢球]═══════  ← PPR水管摆杆
   /                \
  铰链(左端, 固定)    连杆↓
   h≥5cm              步进电机+丝杆滑轨(垂直安装)
  ─────────────────────
        小车底板
```

步进电机驱动丝杆滑轨上的滑块上下运动 → 通过连杆推动摆杆右端上下 → 改变摆杆倾斜角度 → 钢球因重力滚动。

**步进电机+丝杆精度分析**：
- 步距角1.8°（28步进电机），TMC2208支持微步（最高256细分）
- 丝杆螺距2mm → 每步直线位移 = 2mm/200 = 0.01mm（整步）或更细
- **控制精度远超需求**（你只需要球位置±1cm）

### 2.3 摄像头选型和球位置检测

**题目强制要求用摄像头检测球位置**，不能用红外/超声波等替代。

最实用的方案是 **OpenMV Cam**（如OpenMV Cam H7 Plus）或 **ESP32-CAM**：

```
摄像头安装位置：摆杆凹槽正上方
视野要求：覆盖整个25cm摆杆，能清晰看到球和刻度线

选择一：OpenMV Cam H7 Plus
- 优点：内置图像处理库，find_blobs()直接获取球坐标，开发极快
- 通过UART把球的坐标(x,y)发给STM32主控
- 帧率可达30fps+

选择二：ESP32-CAM (OV2640)
- 优点：便宜，自带WiFi可做图传（符合题目要求1的图传功能！）
- 需要自己写图像处理或通过WiFi传图到笔记本处理
- 帧率较低（15fps JPEG）

选择三：普通OV7670/OV7725 + STM32处理
- 优点：最底层控制
- 缺点：图像处理代码量大，开发和调试周期长
```

**推荐ESP32-CAM**，因为它同时满足：
1. 球位置检测（通过简单的色块识别）
2. **题目要求1的图传功能**（WiFi视频流到笔记本/PAD存储和回放）

### 2.4 球位置检测算法

无论用哪个摄像头，核心步骤一样：

```python
# 以OpenMV为例伪代码
import sensor, image, time

sensor.reset()
sensor.set_pixformat(sensor.RGB565)
sensor.set_framesize(sensor.QVGA)  # 320×240
sensor.set_windowing((320, 100))   # ROI：拍25cm长的摆杆区域

# 钢球颜色阈值（深灰色/黑色球在白色PPR管内）
ball_threshold = (0, 40)  # LAB亮度阈值，根据实际光照调整

while True:
    img = sensor.snapshot()
    # 找最大色块 = 钢球
    blobs = img.find_blobs([ball_threshold], pixels_threshold=50, area_threshold=50)
    if blobs:
        ball = blobs[0]  # 取最大色块
        ball_x_pixel = ball.cx()  # 球在画面中的x像素坐标
