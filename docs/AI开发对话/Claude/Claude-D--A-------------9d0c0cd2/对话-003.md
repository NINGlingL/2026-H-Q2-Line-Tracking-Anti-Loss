### 2.5 核心控制算法：球-杆平衡PID

这是整个题目**最关键的部分**：

```
控制架构（串级PID）：

[目标球位置] → [位置环PID] → [期望摆杆角度] → [角度环PID] → [步进电机位置]
       ↑                                                              |
       |                        [IMU反馈实际角度]                      |
       +---------------- [摄像头反馈实际球位置] ←──────────────────────+
```

**物理模型**：
- 球在倾斜的凹槽内受重力分力加速：`a = g × sin(θ)`（θ为摆杆倾角）
- 摆杆倾角 = arctan(右端位移变化 / 25cm)
- 这是一个**二重积分**系统：角度→加速度→速度→位置

**串级PID代码框架**：

```c
// === 参数定义 ===
// 位置环：球位置 → 期望角度
float KP_POS = 2.0;   // 比例：位置偏差越大，期望倾角越大
float KD_POS = 0.5;   // 微分：抑制球的速度，防止过冲

// 角度环：角度 → 步进电机位置
float KP_ANGLE = 5.0;
float KI_ANGLE = 0.1;
float KD_ANGLE = 1.0;

// === 步进电机控制 ===
// 丝杆螺距2mm，设步进电机细分为16微步 = 3200步/转
// 每步 = 2mm / 3200 = 0.000625mm
// 摆杆右端位移1mm → 角度变化 ≈ arctan(1mm / 250mm) ≈ 0.23°

float ball_balance_control(float ball_target_cm, float ball_actual_cm, 
                           float beam_angle_deg) {
    static float last_ball_error = 0;
    static float angle_integral = 0;
    
    // ---- 位置环：计算期望角度 ----
    float ball_error = ball_target_cm - ball_actual_cm;  // cm
    float ball_deriv = ball_error - last_ball_error;
    last_ball_error = ball_error;
    
    // 期望摆杆倾角（度）
    float target_angle = KP_POS * ball_error + KD_POS * ball_deriv;
    // 限幅：摆杆角度不能太极端
    target_angle = constrain(target_angle, -15.0, 15.0);
    
    // ---- 角度环：计算步进电机位置 ----
    float angle_error = target_angle - beam_angle_deg;
    angle_integral += angle_error;
    angle_integral = constrain(angle_integral, -100, 100);
    
    float motor_command = KP_ANGLE * angle_error 
                        + KI_ANGLE * angle_integral
                        + KD_ANGLE * (angle_error - last_angle_error);
    
    // 转换为步进电机步数
    // 根据你的连杆机构几何关系换算
    int steps = angle_to_steps(motor_command);
    
    return steps;
}
```

### 2.6 关键难点：车运动时的扰动补偿

**这是决定你能不能拿高分的关键！**

车在行驶时（特别是加减速和转弯），钢球会受到额外的惯性力。解决方案：

**前馈补偿**（Feedforward）：
```c
// 用ICM20948 IMU检测车的加速度
float car_accel_x = imu_read_accel_x();  // 车前进方向的加速度
float car_accel_y = imu_read_accel_y();  // 横向加速度（转弯时）

// 车的加速度等效于摆杆多了一个虚拟倾角
// a = g * sin(θ) → 补偿角度 = arcsin(car_accel / g)
float compensate_angle_x = asin(car_accel_x / 9.8) * 180.0 / PI;
float compensate_angle_y = asin(car_accel_y / 9.8) * 180.0 / PI;

// 将补偿量叠加到角度环的期望值中
target_angle += compensate_angle_x;  // 加减速补偿
// 注意：转弯时钢球受到离心力，会向外侧滚动
// 需要让摆杆向内侧稍倾来抵消
```

**调参策略**：
1. **第一步**：车静止，只调球平衡PID → 完成要求3（球在±5cm间运动）
2. **第二步**：车慢速直行（AB段），加入扰动补偿 → 完成要求4
3. **第三步**：车走整圈，包含弯道补偿 → 完成要求5
4. **第四步**：球放在任意位置，验证最终目标 → 完成要求6
