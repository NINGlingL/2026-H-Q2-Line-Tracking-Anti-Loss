### 2. `UART/ti_msp_dl_config.c` — 添加外设初始化代码
- `SYSCFG_DL_initPower()`: 添加 I2C 和 UART 的 reset/enablePower
- `SYSCFG_DL_GPIO_init()`: 配置 I2C SDA/SCL (开漏/HiZ) 和 UART TX/RX 引脚

### 3. `UART/empty.c` — 主程序 (HC-05 接收 + OLED 显示)
- **中断接收**: `UART2_IRQHandler` 接收 HC-05 发来的字节，存入环形缓冲区
- **轮询兜底**: 主循环中同时轮询 RX FIFO，防止中断漏收
- **OLED 显示**: 4 行滚动显示区域, 自动换行/滚屏
- **SysTick**: 1ms 定时器, 用于运行计时和刷新节流
- 显示布局:

  | Page | 内容 |
  |------|------|
  | 0 | `HC-05 Bluetooth RX` 标题 |
  | 1 | 波特率 + 接收字节总数 |
  | 2 | 分隔线 |
  | 3-6 | 接收到的数据 (4行滚动) |
  | 7 | 运行时间 |

### 4. `UART/ssd1306.c` + `UART/ssd1306.h` — SSD1306 OLED 驱动 (复制自 OLED 项目)

## 修复内容

**根本问题**: UART 初始化不完整，缺少关键的「禁用→配置→启用」流程。

**修复前** (`SYSCFG_DL_UART_0_init` 中):
```c
DL_UART_Main_init(...);
DL_UART_Main_enable(UART_0_INST);   // ← UART 已启用
// 然后在 main() 中直接配置 FIFO 和中断（寄存器可能写不进去）
```

**修复后** (`main()` 中，参考已验证的 moto 项目):
```c
DL_UART_Main_disable(UART_0_INST);                         // 1. 先禁用
DL_UART_Main_configBaudRate(UART_0_INST, CPUCLK_FREQ, 9600); // 2. 配波特率
DL_UART_Main_setRXFIFOThreshold(...);                       // 3. 设 FIFO 阈值
DL_UART_Main_enableInterrupt(...);                          // 4. 开 RX 中断
DL_UART_Main_enable(UART_0_INST);                           // 5. 重新启用
NVIC_EnableIRQ(UART_0_INST_INT_IRQN);                       // 6. NVIC 使能
```

此外，ISR 中改用 `while(!isRXFIFOEmpty)` 循环一次读空 FIFO（防止 FIFO 中有多字节时只读一个导致溢出）。
