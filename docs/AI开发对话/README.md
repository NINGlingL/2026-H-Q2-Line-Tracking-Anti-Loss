# AI 开发对话

本目录保存与 2026 年电赛 H 题直接相关的 Codex、ChatGPT 和 Claude 开发记录，主要覆盖赛前方案、引脚规划、PCB、模块验证、第二问循迹、第三问滚球和赛后整合。

- `019fb683-第二问主控开发/`：此前已整理的第二问完整可见对话。
- `Codex/`：从本机 Codex 会话中筛选并导出的相关记录。
- `Claude/`：从本机 Claude 项目记录中按 H 题、MSPM0、MaixCAM、八路寻迹和 TMC2208 等关键词筛选的记录。

为便于 GitHub 阅读，长对话按不超过约 140 行拆分，并提供每个会话的 `总览.md`。归档排除了系统/开发者提示、内部推理、工具调用与工具结果；可能类似凭据字段的文本会被遮盖。

这些对话包含大量中间尝试、错误判断和被后续版本推翻的结论。它们的价值是呈现开发过程，而不是作为最终技术文档；最终事实请以仓库首页、复盘和实际代码为准。
