## AI 对话归档原则

- 只保留与电赛 H 题、MSPM0、模块验证、视觉、机械、控制和 Git 版本有关的内容。
- 排除系统提示、内部推理、工具原始输出、凭据和无关私人聊天。
- 附件与图片以文件名或说明引用，避免重复上传来源不明或含隐私的内容。
- 对话内容是开发过程记录，不保证其中每条中间结论都正确；最终事实以代码、测评结果和复盘为准。
