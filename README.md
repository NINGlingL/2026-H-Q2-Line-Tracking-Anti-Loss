# MSPM0G3507 车载循迹控制 V1

目标硬件为立创·天猛星 MSPM0G3507，使用 Keil、TI SysConfig 和
CMSIS-DAP。V1 已建立自动循迹与蓝牙检测双模式，但在电池监测分压和
低压阈值确认前，电机硬件锁保持开启。

## 已核对引脚

| 功能 | 引脚 |
| --- | --- |
| TB6612 PWMA（右轮 A） | PB0 / TIMA1_CCP0 |
| TB6612 PWMB（左轮 B） | PB1 / TIMA1_CCP1 |
| AIN1 / AIN2 | PA14 / PA15 |
| BIN1 / BIN2 | PA12 / PA13 |
| STBY | PB14 |
| 右轮编码器 QEI | PB10 / PB11 |
| 八路巡线 UART3 TX / RX | PB12 / PB13 |
| HC-05 UART2 TX / RX | PB15 / PB16 |
| ICM20948 I2C1 SCL / SDA | PB2 / PB3 |
| SSD1306 I2C0 SDA / SCL | PA0 / PA1 |
| 板载启动按键（低有效） | PB21 |
| D153C 板载 ADC 输出 → ADC0_A0_0 | PA27 |
| SWDIO / SWCLK | PA19 / PA20 |

PWM 时钟为 4 MHz，周期计数为 200，因此载波频率为
`4 MHz / 200 = 20 kHz`。软件和电机驱动入口都把最大输出限制为 80%。

## 模式与蓝牙命令

- 板载 PB21：在安全条件满足后启动自动循迹；再次按下停止。
- `A`：请求自动循迹。
- `D`：进入检测模式。
- `F/B/L/R`：检测模式下前进、后退、原地左转、原地右转。
- `S`：立即停止并拉低 STBY。
- `+/-`：以 5% 步进调整检测功率，范围 10% 至 80%。
- `I`：翻转八路巡线 x1-x8 左右顺序。
- `C`：请求巡线模块进入校准模式，随后仍需按模块板载按键采集黑白值。
- `G`：停止车辆并重新开始 ICM20948 陀螺仪静止零偏校准。
- `?`：返回命令帮助。

检测模式最长 30 秒，自动循迹最长 35 秒，超时均进入安全状态。
巡线帧超过 150 ms 未更新、持续丢线 50 ms、低电锁定或控制状态异常时，
固件会清零 PWM、拉低 STBY 并停止。

## OLED 页面

OLED 显示模式及硬件锁、八路巡线原始值/位置/有效探头数、右轮编码器增量
与累计值、ICM20948 Z 轴角速度、左右轮指令、电池 ADC、巡线通信统计和
最近命令。

## ICM20948

驱动会依次探测 7 位 I2C 地址 `0x68` 和 `0x69`，并要求
`WHO_AM_I == 0xEA`。陀螺仪使用 ±250 dps 量程，陀螺仪和加速度计约
100 Hz 采样并启用 51.2 Hz 数字低通。上电或收到蓝牙 `G` 后，小车必须
保持静止约 2 秒；OLED 此时显示 `IMU:CAL`，移动会使采样重新开始。
校准完成后显示 `IMU:OK`。自动循迹只允许在 IMU 数据有效、新鲜且校准
完成后进入，运行中 IMU 超时或失效会立即进入安全状态。

当前只采集并显示安装后的 Z 轴转向角速度，转向阻尼增益仍为零。需先在
车轮悬空的检测阶段确认“车体左转/右转”对应的 Z 轴正负号，再启用阻尼，
避免符号错误造成正反馈。PB2/PB3 是 3.3 V I/O；若所用板不是带电平兼容
电路的 ICM20948 模块而是裸芯片转接板，必须先核对其 VDDIO 和上拉电压。

## 当前硬件锁

`app_config.h` 中 `APP_MOTOR_HW_READY` 当前为 `0`，因此任何按键或蓝牙
命令都不能拉高 STBY。解除前需完成：

1. WHEELTEC D153C 模块的 `ADC` 输出直接接入 PA27，不再增加外部分压。
   D153C V1.0 使用 10 kOhm / 1 kOhm、V1.1 使用 100 kOhm / 10 kOhm，
   两种版本的 ADC 输出均为输入电压的 1/11。
2. 根据电池包串数填写 `APP_BATTERY_LOW_MV`，确认 OLED 电压读数。
3. 将车轮悬空，以低功率检测模式核对左右轮方向、编码器符号和巡线左右顺序。

PB14 可以直接连接 TB6612FNG 的 STBY。东芝数据手册标明 STBY 内部带
约 200 kOhm 下拉，因此主控复位或引脚高阻时驱动器默认处于待机状态。
若右轮接驱动 A 通道，则右轮编码器应使用 D153C 的 E1A/E1B 输出接
PB10/PB11。模块电源、MSPM0 和各传感器必须共地。

编码器每轮计数和轮距尚未提供，因此 V1 的编码器速度目标为 0，自动模式先
使用保守基础 PWM；获得参数后再启用右轮速度 PID，并标定 IMU 转向阻尼符号。
