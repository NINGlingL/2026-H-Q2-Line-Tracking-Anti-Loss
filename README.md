# 2026年电赛H题复盘

本仓库归档 2026 年电子设计竞赛 H 题“车载平衡滚球运动控制系统”的真实参赛过程。内容包括第二问循迹代码、第三问滚球控制尝试、独立模块验证、MaixCAM Pro 视觉端、题面与报告、现场照片，以及赛后形成的软硬件流程化经验。

## 实际完成情况

- 第二问：最好成绩 16.00 s，最终测评 16.25 s；停车误差 5.5 cm，未达到题目要求的 2 cm。
- 视觉链路：MaixCAM Pro 能稳定识别小球坐标，并通过串口准确发送给 MSPM0。
- 第三问：完成步进电机和丝杆运动，但未在比赛时间内实现稳定滚球闭环，未得分。
- 第四至第六问：未尝试。
- 报告正常提交，仓库保留原稿；其中部分完成度和测试数据未在正式测评中实现或复现，应以本复盘记录的实际结果为准。

## 最重要的结论

> 无论硬件还是软件，都必须建立流程化的搭建、验证和检查体系。出现异常时，应先按供电、接线、模块原始数据、驱动、控制算法的层次排查，而不是立即堆叠代码补丁。

本仓库是比赛现场状态与赛后经验的归档，不代表一套已经完整实现题目全部要求的参考方案。
