# 现场照片

本目录收录 9 张比赛现场照片，用于记录最终整车、滚球机械结构、洞洞板、控制板堆叠、OLED 诊断信息和现场接线状态。

公开处理原则：

- 可识别人脸已经模糊处理。
- 所有照片重新编码，未保留原始 EXIF 元数据。
- 图片最长边压缩至 1920 像素，原图不进入 Git 仓库。
- 图片仅作为过程记录，不表示照片中的临时接线或机械结构是推荐设计。

## 图片说明

1. `01-final-vehicle-anonymized.jpg`：完整车辆和滚球机构，背景人脸已匿名化。
2. `02-oled-diagnostics.jpg`：OLED 上的 UART、模式、编码器和故障状态。
3. `03-ball-mechanism-front.jpg`：滚球槽、丝杆和主控板正面结构。
4. `04-complete-vehicle.jpg`：装配后的完整车辆。
5. `05-control-board-stack.jpg`：主控、洞洞板、OLED 与步进电机接线。
6. `06-workbench-assembly.jpg`：工作台上的临时机械和电路装配。
7. `07-controller-wiring-a.jpg`：MSPM0G3507 扩展板接线细节。
8. `08-ball-mechanism-control.jpg`：滚球机构与控制板组合状态。
9. `09-controller-wiring-b.jpg`：MSPM0G3507 扩展板另一角度。
